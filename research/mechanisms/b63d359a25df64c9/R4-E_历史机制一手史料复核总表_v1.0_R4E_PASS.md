# 1. H01｜第92司法/羁押链

当前正文的核心机制是：
`旧单待辨 → 到署候问 → 因尚有事项待质而留置 → 家属/旧人按规矩送物 → 数轮问讯 → 范围收窄 → 普通释放。`

《大清律例》可直接支持“监候待质”、囚犯衣粮医药、亲属受控入视、送饮食验明转递，以及限制无关人员出入传话等制度背景。地方志又证明监内设置狱神庙/祠并非杜撰。

**裁定：机制可运行。**

需保持：
- 宝钗探视、衣食送入都要有门禁/验看；
- 小红“大得力”继续是找规则、找经手人、补证据链，而不是买通；
- 茜雪只作一次受控短话/送物接口；
- 狱神不得显灵，不得成为释放因果。

# 2. H02｜第89—93抄没链

曹家档案的“房产什物查清、造册封固”“管事拿讯”等，是与本项目时代、社会层级最接近的直接档案材料。

当前正文：
`官差入府 → 控制出入 → 柜箱/账册点看 → 造册/标记 → 只准有限日用物报取 → 旧单再核 → 宝玉被传问`
具有真实制度骨架。

**裁定：PASS。**

正文不能添加：
- 曹家奏折中的具体数字直接移植；
- 为了复制曹家而制造同罪名；
- “抄家必然等于所有人当天流落街头”。

# 3. H03｜第84—87丧制/婚姻

法典与会典共同证明：丧制确实会改变婚嫁的合法/礼制条件；妃薨又有宫廷体系的特殊规则。

当前正文并未把元春死后第二天就安排金玉婚，而是留出数月并继续明说“在服中，日子往后放”。

**裁定：PASS-BOUNDARY。**

不得锁精确日数；第87具体婚日仍C-placement。

# 4. H04｜第87—95居所/主婚权

现存法典可支持长辈主婚框架；曹家实案证明抄没后仍可能为家属留有限房屋/仆役度命；乾隆北京租契证明另赁房屋有充分城市制度背景。

当前：
`89临时借住 → 95另赁偏院`
以及
`贾母—王夫人—薛姨妈逐步形成婚议`
均可运行。

**裁定：PASS。**

具体院落、租价、房间数、最终主婚人的文学配置均保持C。

# 5. H05｜第91—99贫困日常

曹家档案中的“当票百余张”非常重要：它表明旧家衰败可经历长期典当，而非只有一次戏剧化破产。

当前贫困线采取：
`抄没后仍有少量资源 → 暂居 → 另租 → 饭量下降 → 炭药衣物开始算量 → 外援仅缓一时`
属于渐降模型，与史料相容。

**裁定：PASS。**

具体“两碗半”、某件衣、某一笔租金均属C/P-Lock文学细节，不能史料化。

# 6. H06｜薛家援助边界

清代婚姻家事档案显示出嫁女仍可能得到娘家保护、资源与诉讼支持，但没有足够依据建立“持续供养定额”。

当前正文没有让薛家大额救济把95以后贫困撤销，因此不冲突。

**裁定：PASS-SOFT。**

未来若增加薛家援助，只能：
- 有限；
- 可中断；
- 不逆转整体经济下降；
- 交代薛家自身资源与人际条件；
- 不把“给或不给”写成历史定律。
