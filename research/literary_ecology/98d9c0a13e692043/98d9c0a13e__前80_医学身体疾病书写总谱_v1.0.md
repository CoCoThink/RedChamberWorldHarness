## 0. 任务边界

按 v5.0 计划，本谱逐回检查：

- 脉案；
- 病名表达；
- 寒热虚实；
- 饮食禁忌；
- 药材；
- 丸散膏丹；
- 熬药；
- 请医；
- 诊金；
- 换方；
- 久病日常；
- 女性身体；
- 饮食与病；
- 情志与病；
- 临终；
- 死后料理。

本谱特别避免两个误区：

1. **药名索引化**：只搜到“人参、燕窝、茯苓”不等于掌握了《红楼梦》的医学书写；
2. **现代诊断倒灌**：不把文本中的古代症候、脉理、家常经验强行换算成现代病名。

本谱关心的是：

> **一个人病起来以后，身体、家属、婢女、医生、厨房、钱、药材、礼法和情绪怎样一起运转。**

## 1. 总结论

### 1.1 《红楼梦》的病不是“人物属性”，而是持续运行的生活系统

黛玉不是“体弱”两个字；她有从幼年开始的长期服药、换医、季节性咳嗽、食欲、燕窝、睡眠、情志诱因和照护网络。

凤姐也不是“后来病了”；她从小产、下红，到隐瞒病势、拒医、持续出血、调经丸药、人参短缺，形成清楚的身体长线。

所以后20写病时，第一原则是：

> **先找这个人物此前的身体史，再写本回病势。**

### 1.2 医生永远不是单独工作的

前80医疗链常是：

**家属发现 → 婢女汇报 → 请医 → 性别回避/诊脉 → 开方 → 付礼/诊金 → 抓药 → 煎药 → 婢女执行 → 病人肯不肯吃 → 饮食配合 → 换方/再诊。**

第51回甚至把陌生医生一次诊金、轿马钱和熟太医的年例礼都写出来。

因此后20凡写“请了太医，开方吃药”，原则上都不够。

### 1.3 女性身体是前80最重要的医学主轴之一

已有完整类型：
- 黛玉：先天不足、久病、嗽疾、睡眠与饮食；
- 秦可卿：停经、疑孕、脉诊与重症；
- 凤姐：小产、下红、持续出血；
- 尤二姐：妊娠、误诊、药物致流产、失血；
- 香菱：血分病、无孕、干血之症；
- 晴雯：外感、过劳、病中驱逐、疾病污名。

后20不能把女性病都写成“咳血—昏厥—脉弱”。

### 1.4 情志与病从来不是一句“忧思成疾”

曹雪芹常写成因果链：
- 秦钟：风寒 → 体弱 → 笞打 → 父死 → 症候叠加；
- 宝玉57回：离别恐惧 → 急痛迷心 → 痰壅 → 昏迷/惊醒；
- 宝玉79回：抄检、逐人、离散、晴雯死 → 悲惊 → 外感 → 卧病；
- 香菱80回：既有血分病 → 金桂折辱 → 气怒伤感 → 干血之症。

因此85—86黛玉病重也必须有“具体事件怎样打在身体上”，不能只写抽象忧伤。

### 1.5 食物与药物之间没有硬边界

燕窝粥、汤、粥、热酒、茯苓霜、玫瑰露等不断穿过：
**食物 / 补品 / 药物 / 礼物 / 赃物 / 经济品**多个身份。

这意味着第95回“真贫”尤其要检查：
- 病人吃不起什么；
- 什么药可以改成食疗；
- 谁舍不得倒掉；
- 谁把补品卖了或挪给别人。

### 1.6 诊断可以正确，也可以误导、失误甚至成为权力工具

三类尤其重要：

- **张友士—秦可卿**：细诊病源；
- **胡君荣—尤二姐**：错把胎气作瘀血，用虎狼药造成流产；
- **王夫人—晴雯“女儿痨”**：疾病标签与道德判断、驱逐、快速火化纠缠。

所以后20不应把医生写成全知权威。

### 1.7 疾病有钱的尺度

前80已经写：
- 请新医生要一次性钱；
- 熟太医走年例礼；
- 人参是昂贵库存；
- 燕窝可长期消耗；
- 药材会短缺；
- 药铺收购花草；
- 补品会被偷、送、藏。

家败后若医疗场景仍“名医随请、好参随用、燕窝不断”，就违背前80自身的经济逻辑。

### 1.8 死后身体的待遇最能显阶级

贾敬：
- 请太医验看；
- 观察尸体；
- 择日入殓；
- 寿木、道场、礼部等全部进入。

晴雯：
- 以“女儿痨不祥”为由；
- 十两烧埋银；
- 迅速入殓；
- 抬往化人场。

同为死亡，料理方式完全不同。

后20写香菱、迎春、凤姐、黛玉、李纨，不能只写“哭了一场，料理后事”。

## 3. 六条长线病史

### 3.1 黛玉：3 → 20/28 → 45 → 52/57/58 → 67 → 76

这是后20最不能重置的一条身体史。

已有要素：

- 幼年即“有不足之症”；
- 自会吃饮食起长期服药；
- 人参养荣丸等丸药长期化；
- 先天弱、易受风寒；
- 春分/秋分后易犯嗽疾；
- 药方会调整、会被亲友评论；
- 饮食不足影响精神气血；
- 燕窝冰糖粥被提出作长期食养；
- 长期睡眠极差；
- 思乡、忧虑、哭泣会加重旧病；
- 家庭为她请医、配药、送燕窝，形成持续照护网络。

**对85—86的硬约束：**

> 黛玉不能忽然患一种“剧情需要的绝症”。  
> 她只能在既有身体史上逐渐走到尽头。

尤其不能每一场都写：
“咳了一口血—众人惊慌—太医说脉弱”。

需要写睡眠、饮食、是否肯吃、燕窝还送不送得起、谁煎药、谁夜里守、谁瞒消息、谁怕她动气。

### 3.2 凤姐：55 → 72 → 75 → 77 → 后20

前80已经建立：

**小产 → 气血亏虚 → 下红 → 数月难愈 → 仍强行理事 → 持续经血不止 → 不愿承认病 → 调经养荣丸 → 上等人参短缺。**

因此90、93回必须把她写成一个：

> **身体早已被权力劳动透支，但仍拒绝退出权力中心的人。**

她临终不能只靠“病势沉重”四字完成。

应检查：
- 出血是否反复；
- 是否还要看账；
- 平儿怎样劝；
- 药钱和债务是否冲突；
- 有没有好参；
- 医者还来不来；
- 她在病中仍怎样控制信息和家务。

### 3.3 香菱：8/48诗命与身体 → 80干血之症 → 81

第80已经明写：

- 本来怯弱；
- 血分中有病；
- 数年无胎孕；
- 受金桂长期气怒折磨；
- 酿成干血之症；
- 日渐羸瘦作烧；
- 饮食懒进；
- 请医服药不效。

因此81的医学任务不是“替香菱设计一种病”。

真正要做的是：

> **把第80已经开始的慢性耗损写到生活末端。**

应优先写：
- 夜间发热还是白日；
- 能吃什么；
- 药是谁煎；
- 宝钗能照看多少；
- 薛家是否还肯花钱；
- 金桂如何继续干扰护理；
- 香菱自己是否还愿吃药；
- 诗稿与病榻怎样发生关系。

### 3.4 晴雯：51 → 52 → 74 → 77 → 78

晴雯线显示疾病如何被阶级和权力放大：

**受寒发病 → 不合适的处方 → 换医 → 病中强撑针线 → 久病未愈 → 抄检后被病中驱逐 → 死后被“女儿痨”污名化 → 快速火化。**

这里最值得后20学习的，不是“病得惨”，而是：

> **一个病人的待遇取决于她在家庭中的身份和谁愿意为她承担麻烦。**

这对袭人、巧姐、香菱等线都可作反照。

### 3.5 尤二姐：68—69

这是最完整的医疗事故样本：

**精神压迫/孕期脆弱 → 医生被替换 → 误诊 → 峻药 → 成形胎儿流产 → 大出血 → 元气重伤 → 医者逃走/追责 → 宗教祈祷与算命介入 → 最终自杀。**

对后20的约束：

- 不要把“庸医”写成简单笑话；
- 药误必须产生身体后果；
- 医疗失败后，家庭往往转向祈祷、算命、民间解释，而非立即换成现代式理性决策。

### 3.6 宝玉：25急症 → 33—35外伤 → 57心因急症 → 79长期卧病

宝玉身体史的特点不是“体弱”，而是：

- 身体极容易被情绪和关系打中；
- 父权暴力造成实伤；
- 对分离的恐惧会进入急性症状；
- 家庭资源会集中保护他；
- 恢复期可以长到一月、百日。

因此99“撒手”前若写身体变化，不宜突然赋予他一个方便剧情的重病。

## 4. 医疗生态类型学

### 4.1 医者进入内宅的礼法

第51回尤其清楚：

- 女子诊病需要回避；
- 陌生医生甚至可能误认病人身份；
- 诊脉隔着内外规矩；
- 新医生有单次礼钱；
- 熟太医按节有年例。

后20凡请医，都应问：

> 谁去请？从哪一道门进？谁陪？病人见不见脸？谁拿方子？谁付钱？

### 4.2 方子不是结局

一张方子后面至少还有：

- 抓药；
- 辨药；
- 熬药；
- 谁看火；
- 何时喝；
- 病人是否拒绝；
- 是否吐出；
- 饮食是否配合；
- 复诊是否改方。

第56回“取药、监派调服”尤其值得作为后20家务底板。

### 4.3 慢病的单位是“天、月、季节”

黛玉以春分秋分为节律；
凤姐以数月出血为节律；
宝玉79回甚至明确写一月渐愈、百日禁食出门。

所以85—86、90—93不能只按“场”写病。

### 4.4 病人有自己的判断

秦可卿知道自己“挨日子”；
凤姐不肯承认病；
晴雯仍要补裘；
黛玉会评估自己比往年重；
宝玉会否掉陌生医生的药。

病人不是被动的“病号”。

### 4.5 婢女是医疗系统的执行层

紫鹃催黛玉吃药；
麝月取钱付诊金；
袭人等安排睡眠；
平儿掌握凤姐隐秘出血；
奶娘、嬷嬷昼夜守宝玉。

后20医学写薄，最常见原因就是只写“医生—病人”，漏掉这一层。

### 4.6 病与权力

- 凤姐病倒，探春李纨宝钗接管家务；
- 晴雯生病时被驱逐；
- 尤二姐的医生可被人做手脚；
- 宝玉病时全府资源集中。

“谁病了”会改变组织结构。

## 5. 对81—100的直接接口

### 81｜香菱病亡
第一优先。

必须承接第80：
- 血分病；
- 干血之症；
- 羸瘦作烧；
- 饮食懒进；
- 医药无效。

新增重点应是**护理链和家庭反应**，不是新病名。

可写：
- 药渣、煎药味；
- 宝钗调整饮食；
- 金桂故意扰病；
- 夜热与口渴；
- 钱与药材；
- 病中诗稿。

### 84｜元春死
医学本身不必强写宫中病案，因为前80材料不足。

更适合写：
- “病亡消息”进入家门的层层转述；
- 家人知道多少、不知道多少；
- 礼制如何压过私人悲伤。

### 85—86｜黛玉
应整合3、28、45、57、58、67、76全部身体史。

至少要同时存在：
- 睡；
- 吃；
- 咳；
- 药；
- 情绪；
- 照料者；
- 钱/补品；
- 病人自知。

**不能只剩咳血。**

### 87｜金玉婚
婚礼期间要考虑：
- 宝玉此前身体是否完全恢复；
- 宝钗婚后如何处理他的饮食、作息和旧病；
- 新婚身体与礼俗，须克制而真实。

### 90｜宝钗/凤姐
凤姐身体线必须压过“账目女强人”单一写法。

账本与药碗应同处一室。

### 93｜凤姐死
应兑现55→72→77长线。

临终前可出现：
- 药越来越简；
- 好参已无；
- 平儿与债主/亲族同时进出；
- 她仍想问一件家务；
- 身体已经不能支持旧权力。

### 94｜巧姐
乡村医疗与贵族医疗应有阶层反差，但不能另开民俗百科。

可通过：
- 小伤小病；
- 草药/热汤；
- 劳动后身体；
- 谁舍不得花钱请医
自然出现。

### 95｜真贫
这是“医疗经济”重点回。

要问：
- 药能否停；
- 补品是否当卖；
- 米、炭、药谁优先；
- 生病是否意味着一家少一个劳力。

### 97｜妙玉/惜春
不宜强塞疾病；更适合身体纪律：
- 斋食；
- 睡眠；
- 劳作；
- 洁净；
- 苦行与病弱的区别。

### 99｜撒手
宝玉不能靠突发绝症帮助“出家”。

如果写身体变化，应来自长期精神/生活转向，而不是剧情方便。

### 100｜李纨
前80没有像黛玉、凤姐那样完整的李纨慢病底板。

因此100若写李纨病亡，必须明确属于**后20高概率生成/作者自由创造层**，不能伪装成前80已有硬证。

应从她的：
- 年龄；
- 长期寡居劳作；
- 家败后的营养/劳累；
- 兰桂功名后情绪与礼务
逐步生成，不应复制黛玉的咳嗽，也不应复制凤姐的下红。

## 6. 第33-D冻结规则

1. **病人先有身体史，再有本回病势。**
2. **同一人物不得反复发明互不相干的新病。**
3. **脉案/病机只写人物能听懂、场景需要的量。**
4. **医生不是全知者，允许误诊、换医、收费、逃责。**
5. **每个重大病场至少检查：谁发现、谁请医、谁取药、谁煎、谁喂、谁付钱、谁守夜。**
6. **食物与药物要联动；病人必须有实际食欲/忌口。**
7. **女性病不得统一写成‘气血两亏’四字。**
8. **情志致病必须写出具体事件链。**
9. **急病之后必须有恢复期，不能次回归零。**
10. **家败后医疗资源必须降级：名医、好参、燕窝、诊金都要受钱约束。**
11. **死亡后至少考虑：报丧、停放、入殓、钱、身份、时令、谁主持。**
12. **疾病标签可能带偏见；不可把王夫人式判断直接当作者真理。**
13. **若删除药名后场景毫无变化，说明药名多半是知识展示，应删。**
14. **若只写‘服药不效’而没有生活后果，病仍然写薄。**
15. **81香菱、85—86黛玉、90/93凤姐必须严格承接前80既有身体长线。**
