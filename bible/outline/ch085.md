# 第八十五回　丧仪渐歇深闺愈静　沉痼日侵弱质难支

## 时间

**T+1—5个月**。丧期成为日常；黛病不可逆

## 人物

- 主场：黛玉、紫鹃、雪雁、宝玉、宝钗
- 可自然进入：贾母问候、王夫人/李纨、医药与送饭小人物
- 场外或禁区：元春只以丧期背景存在
- 本回状态变化：黛玉仍活且有日常；不可从开头即“临终化”
- 增厚重点：写足宝玉来讲兰哥儿的新闻，黛玉学人取笑，他走后落泪；照料人轮换、吃饭、回话一两笔。
- 主线一笔：宝玉去后，黛玉为他落泪，泪已少（R10）。
- 家难次线：丧仪用银，凤姐叫平儿悄悄押东西（接72回鸳鸯借当）。

## 回末状态

- 谁知道了什么：紫鹃、宝钗都看出黛玉"一高兴就多说，过后便累"；紫鹃已私下告诉宝玉，只不当着黛玉说破。
- 要紧的东西在谁手里：《十独吟》稿与零稿夹在黛玉床边的旧集里；大夫的新方与紫鹃记饭药夜醒的小纸压在一处。
- 钱与日子：丧期成常例，门上来问的人渐少；紫鹃、雪雁分前后夜上夜；婆子在墙外说平儿又打发人从后角门抬了两只箱子出去，"前年也说挪"。

## 本回设计（增厚卡）

**软目标：** 6000—7000字，以长换短，不增

### 一、硬约束

黛玉沉痼加深；丧期余波仍在；不直接进入死亡日。

### 二、本回真正的戏剧问题

> 怎样写‘越来越坏’而不是重复写‘又病重了’？

### 三、轻重

- **写足（约三分之一）：** 宝玉来。他讲兰哥儿的新闻，一篇闲话（痴话、连着比下去，自己当真）；黛玉听着学人取笑，真笑一回。他走后，她问紫鹃一句他身上的小事，话没完泪已下来，只一两滴，随手抹了。泪处无言，紫鹃不劝、不解释。
- **次之：** 紫鹃、雪雁的“药铺账”与上夜分工；宝钗来先问丫头吃饭没有。
- **一两笔过：** 医药、丧期渐静、找稿；夜话只一轮。
- **回末：** 不动，紫鹃在小纸上添一行小字。

### 四、场景展开

1. 一日早起黛玉精神尚可，能说笑，甚至挑剔饭食。
2. 午后因一件小事耗神，恢复时间比从前长。
3. 紫鹃与雪雁对要不要再请医/换药有分歧。
4. 宝玉来时带一件外面的无关小事，黛玉仍会讥他。
    - 他去后、她说胸口累之前：问紫鹃一句他身上极小的事（如出去时可添了衣裳），话没完泪已下来；只一两滴，自己也觉比旧年少（第49回），随手抹了。只为牵挂他，不为自伤；不说“泪尽”，紫鹃不劝、不解释，宝玉不知道。
5. 宝钗后来来，先关心饭药与丫头是否吃饭。
6. 夜里丧期外头更静，但小丫头仍要上夜、传水、收碗。
7. 隔日黛玉好转一小截，让读者不至于把85当86预告。
8. 回末以一次‘恢复不过来’收（找稿一两句、夜话一轮，不预演86的改稿、等医），给86真正的最后日留空间。

### 五、章法配置

重复中的变化；不写之写；病中仍有生活；顿挫。

### 六、L层

- **L1可直接增加：** 药、米汤、被褥、灯、夜间差使。
- **L3禁止：** 明确绝症诊断、婚讯刺激、吐血暴死；整回变诗社回。无回前、回末诗。

## 保护锁（P1/P2）

- 必须保护：紫鹃用小纸记睡/醒/饭/药，雪雁笑成“药铺账”；热水、厨房、夜醒继续运转
- 允许增补：医疗生态、读写动作
- 禁止破坏：不把病回写成只有医生与病人；不让黛玉突然讲佛理

## 补完卡

### 硬节点

R10/R11：黛玉必须沉痼日深、为牵挂宝玉而泪尽夭亡；不许新造急性绝症。H03丧期仍在。

### 最强处 / 保留

起居纸与“药铺账”；睡眠、饭、药连续记录；热水、窗纱、旧集、紫鹃夜守；黛玉仍有玩笑与嫌闷；“明日看旧集”的普通明日感。

### 人物

紫鹃、雪雁、宝玉、宝钗、医者；避免家族轮流“探病打卡”。

### 诗文身份

A01《十独吟》题名存在为硬证；**85显题仅为C-main，作者与具体形制继续OPEN**。当前正文只让题名稿件出现在黛玉旧书/旧纸环境中，不以此宣布作者。作者、篇数、诗体要实写，先问作者。G01普通未成小诗可在85出现，作86诗稿接口，但86才最后停笔。C03《五美吟》只作结构远回声，不重引。

### 笑料

“听咳有功”“记账第一”等保持病中活声。

### 宗教/梦

低。黛玉不参禅、不梦警幻、不预言自己死期。

### 四链

钱仍E0；药、食养、热水、夜守有人力；信息以起居纸替代“她今日看着好些”的主观判断。

### 应删

“这是她最后一部作品”式作者标注；《十独吟》直接十首全读若压垮病日节奏，需要分段呈现。

### 前80同构

45风雨词、64五美吟：病/悲情中写作仍是人物行动。

### 章法 / 风险

丧常例变静 → 起居记录 → 一次短暂好转 → 探视受限 → 《十独吟》旧稿整理/成组 → 普通未成稿仍在 → 夜醒。  
**风险：**诗压过身体；把《十独吟》写成绝命组诗。
