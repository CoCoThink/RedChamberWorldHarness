# 第八十七回　薛宝钗随分谐金玉　贾宝玉还帖悼颦卿

## 时间

**T+10—16个月**。经礼俗与情感缓冲后金玉婚

## 人物

- 主场：宝玉、宝钗、贾母、王夫人、薛姨妈
- 可自然进入：袭人、麝月、李纨、平儿、看屋婆子；可有紫鹃/雪雁以遗物接口短现；贾兰只要帖、怪一句，不懂、不劝
- 场外或禁区：黛玉只通过空位、遗物、他人避谈存在
- 本回状态变化：正式成婚；宝钗妻位开始真实运行
- 黛玉灵柩：停过五七，暂寄铁槛寺；贾母说明年开春水路好走，再送回苏州同父母葬在一处（第12、15、64回例）。
- 主线一笔：对景悼颦儿。议婚后、择期前，宝玉连日在潇湘馆外徘徊不进去，有一日情不自禁吟成一歌（照79回紫菱洲），随后把没送到的旧帖还了贾兰。他应下亲事，是因为贾母开了口，是把自己给出去的头一回；不欢欣，是情还在潇湘馆。
- 增厚重点：写足议婚定局：几次小谈，贾母一篇，末了一句家常话定下；宝玉应下，是应贾母。对景一段有一首歌，歌前歌后仍短；还帖无言。婚后第一周有人情网，不写成二人婚姻短篇。
- 家难次线：婚事从简，贾政说"不宜张扬"；外头有人打听雨村。
- 薛家一句：薛姨妈话里带出宝琴已过门、随梅家上任去了，薛蝌同岫烟也完了婚、搬出去另过；只作家常，不展开。

## 回末状态

<!-- 本回结束时的事实，三至五行，供下一回接续。填了才会进上下文；分段通读会给出建议。 -->
- 谁知道了什么：贾母当着薛姨妈、王夫人说了一篇，末了只说“今年冬天宝玉那件大毛衣裳，叫宝丫头替他找出来”，亲事就此定下，宝玉为贾母应了；他在潇湘馆外吟过一首歌，只看屋婆子听见半截；宝玉、宝钗都在婚前被明白告知；婚后三四日夜里，上房来人说花家来人了，叫袭人明儿一早过去；袭人回屋只说“太太叫我明儿一早过去”，不说为什么；宝玉同意而不欢欣；湘云悄悄告诉宝钗史家已替她定了卫家，说是明年；薛姨妈告诉宝钗，宝琴已随梅家上任，薛蝌同岫烟完婚搬出另过，家里只剩她一个；惜春露一面便回去抄经。
- 要紧的东西在谁手里：旧帖已在择期前原样还给贾兰；通灵玉婚前由袭人从麝月处取来，重新给他系上；宝玉书架最下一格夹着一张旧素笺，他说"这个别动"，众人不问；针线匣在案角，砚台移到外手，第三盏灯不点。
- 钱与日子：婚事从简，贾政先说"不宜张扬"；薛蟠送亲；席间有门客问贾琏雨村被参的事；袭人仍掌宝玉衣食，宝钗不急着改旧规。

## 本回设计

**篇幅：** 7000—8000字（软目标）

### 要守的

- R12—R15：黛亡数月后真实成婚，婚前宝玉知情；夫妻生活与“意难平/累累忘情”并存。黛亡后的宝钗文字从本回婚后展开。
- R44：后文有“对景悼颦儿”一段。庚夹批在79回紫菱洲那一段上：宝玉天天徘徊，“情不自禁，乃信口吟成一歌”。放在本回、与“落叶萧萧”合场、吟歌、还帖都是C。
- “落叶萧萧，寒烟漠漠”是第26回甲夹所引的后文原字，须逐字出现。
- 丧期、主婚权、花费规模照清代制度写真实。黛亡到成婚的确切月数，贾母此时实权多高、死在何时，都仍开放。

### 本回的戏

> 怎样让这场婚姻既是真实婚姻，又不是对黛玉之死的简单替代？

### 轻重

- **写足（约三分之一）：** 议婚定局。王夫人、薛姨妈实办，几次小谈各有考虑；贾母说一篇（先反问，数眼前人的好处和自己老了减了多少，夹旧事、笑骂），不宣判婚事，末了一句家常话定下。宝钗与薛姨妈私下一段，不是一句顺从。
- **次之：** 连日对景，“不进去”。有一日情不自禁吟成一歌，才吟罢，看屋婆子拿家常话打断（79回香菱“你又发什么呆呢”的位置）。随后还帖给贾兰，无言，短。歌是全回唯一不克制的地方。
- **一两笔过：** 婚礼虚写；书架让镜奁、素笺“这个别动”；婚后第一顿饭、袭人麝月新分工，同类小事不连写。
- **回末：** 翻书与针线声里，上房来人在廊下悄声说花家来人了，叫袭人明儿一早过去，话说完。袭人回屋，宝玉问，她只说“太太叫我明儿一早过去”，仍替他剪了灯花。加一句回末套语，不与 85、88 同样。不断在半句上（接 88“袭人那夜听了这一句”）。

### 场次

1. 黛丧已过数月。开头带一笔贾兰催过旧帖（85、86回许给黛玉看、说“只拿一日”），宝玉只是拖着。
2. 从普通家务进入议婚，不从坟前直接切婚礼；多次小谈而非一次宣布：贾母名义认可，王夫人、薛姨妈实办，凤姐病中参与，各有各的考虑。
3. 宝钗与薛姨妈私下说，不是一句顺从。
4. 宝玉被明白告知。贾母那一句“大毛衣裳”说出口，他便应了：是应她。应时带一句痴话，叫读者看得出是为她：依了，只不许她再说“趁我还看得见”；贾母笑骂他讲价。不抗婚，也不欢欣。当日走到潇湘馆岔路，站住便回。
5. **连日袖帖而去**（照79回紫菱洲，反用26回）：顺脚走到院门外，落叶萧萧，寒烟漠漠，窗里没有声音。有一日情不自禁，信口吟成一歌。才吟罢，看屋婆子拿家常话打断，可如香菱无心带到他的喜事；他问谁住，仍不进去。
6. **还帖：** 帖原样还给贾兰。贾兰只怪他说过“只拿一日”，他不辩。然后两家才择期。
7. 婚礼虚写、从简；婚前房内安置要写，书架让镜奁，此时素笺一闪，旧物不生争吵。袭人从麝月处取来那块玉，替他重新系上，他由她，不说话。
8. 婚后第一顿饭、新分工，袭人、麝月都在；夫妻头一回为小事说话。同类小事不连写。
9. 回末先落在翻书与针线声，随即上房来人说花家来人了，叫袭人明儿一早过去；袭人回屋只说这一句；不总结婚姻。

### 章法

家长权力多声部；悼在婚前，一首歌，歌外仍短、静，宝钗文字在婚后而长、家常，互不抢戏；空位侧写；身份由称呼变化见出。宝钗一线参照第42回钗黛合写。本回接口多，婚仍须是生活，不写成论断。
丧期常态化 → 议婚 → 应贾母 → 岔路一站 → 连日对景 → 吟歌，婆子打断 → 还帖 → 择期 → 系玉 → 婚礼缩写 → 婚后空间重排 → 第一餐、针线声 → 花家来人，袭人只说明儿一早过去。

### 已写成、要保留的

- 几个月的缓冲。
- 悼的一段：“不进去”、看屋婆子、扫叶入筐。不哭、不独白；只吟一首歌；婆子、贾兰不替作者说伤心；宝钗不在场；帖里不夹字；不点破日后还书的呼应。还的是帖，人没有放下，也不是娶宝钗的条件。
- 书架让镜奁；素笺只说“这个别动”，须在还帖之后；宝钗不清、不问旧纸。
- 婚礼不铺张；小丫头怕黑；第一顿普通饭；针线茶水照常，收在翻书与针线声。
- 改不过口的“宝姑娘”；婚后理箱笼只留腰带、“旧纸”那一格、针线匣挪半尺、补袖口、第三盏灯，香盒棋子、酱菜、莺儿俏皮话已删（冷读第二轮）。
