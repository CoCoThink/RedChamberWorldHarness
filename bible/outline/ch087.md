# 第八十七回　薛宝钗随分谐金玉　贾宝玉还帖悼颦卿

## 时间

**T+10—16个月**。经礼俗与情感缓冲后金玉婚

## 人物

- 主场：宝玉、宝钗、贾母、王夫人、薛姨妈
- 可自然进入：袭人、麝月、李纨、平儿、看屋婆子；可有紫鹃/雪雁以遗物接口短现；贾兰只要帖、怪一句，不懂、不劝
- 场外或禁区：黛玉只通过空位、遗物、他人避谈存在
- 本回状态变化：正式成婚；宝钗妻位开始真实运行
- 黛玉灵柩：停过五七，暂寄铁槛寺；贾母说开春水路好走，再送回苏州同父母葬在一处（第12、15、64回例）。
- 主线一笔：对景悼颦儿。议婚后、择期前，宝玉连日过潇湘馆不进去，把没送到的旧帖还了贾兰。
- 增厚重点：写足议婚定局：几次小谈，贾母一篇，末了一句家常话定下；还帖无言，短。婚后第一周有人情网，不写成二人婚姻短篇。
- 家难次线：婚事从简，贾政说"不宜张扬"；外头有人打听雨村。
- 薛家一句：薛姨妈话里带出宝琴已过门、随梅家上任去了，薛蝌同岫烟也完了婚、搬出去另过；只作家常，不展开。

## 回末状态

<!-- 本回结束时的事实，三至五行，供下一回接续。填了才会进上下文；分段通读会给出建议。 -->
- 谁知道了什么：贾母当着薛姨妈、王夫人说了一篇，末了只说“今年冬天宝玉那件大毛衣裳，叫宝丫头替他找出来”，亲事就此定下；宝玉、宝钗都在婚前被明白告知；婚后三四日夜里，上房来人说花家来人了，叫袭人明儿一早过去，话没说完；宝玉同意而不欢欣；湘云悄悄告诉宝钗史家已替她定了卫家，说是明年；薛姨妈告诉宝钗，宝琴已随梅家上任，薛蝌同岫烟完婚搬出另过，家里只剩她一个；惜春露一面便回去抄经。
- 要紧的东西在谁手里：旧帖已在择期前原样还给贾兰；宝玉书架最下一格夹着一张旧素笺，他说"这个别动"，众人不问；针线匣在案角，砚台移到外手，第三盏灯不点。
- 钱与日子：婚事从简，贾政先说"不宜张扬"；薛蟠送亲；席间有门客问贾琏雨村被参的事；袭人仍掌宝玉衣食，宝钗不急着改旧规。

## 本回设计（增厚卡）

**软目标：** 7000—8000字，以长换短，不增

### 一、硬约束

- R12—R15：黛亡数月后真实成婚，婚前宝玉知情；夫妻生活与“意难平/累累忘情”并存。黛亡后的宝钗文字从本回婚后展开。
- R44：后文有“对景悼颦儿”一段。放在本回、与“落叶萧萧”合场、还帖、无诗都是C。
- “落叶萧萧，寒烟漠漠”是第26回甲夹所引的后文原字，须逐字出现。
- H03/H04：丧期、主婚权、花费规模须真实。O01/O09仍开放。

### 二、本回真正的戏剧问题

> 怎样让这场婚姻既是真实婚姻，又不是对黛玉之死的简单替代？

### 三、轻重

- **写足（约三分之一）：** 议婚定局。王夫人、薛姨妈实办，几次小谈各有考虑；贾母说一篇（先反问，数眼前人的好处和自己老了减了多少，夹旧事、笑骂），不宣判婚事，末了一句家常话定下。宝钗与薛姨妈私下一段，不是一句顺从。
- **次之：** 连日对景，“不进去”，还帖给贾兰。无言，短。
- **一两笔过：** 婚礼虚写；书架让镜奁、素笺“这个别动”；婚后第一顿饭、袭人麝月新分工，同类小事不连写。
- **回末：** 改断：翻书与针线声里，上房来人传话，说花家来人了，话未完（接88）。

### 四、场景展开

1. 黛丧已过数月。开头带一笔贾兰催过旧帖（85、86回许给黛玉看、说“只拿一日”），宝玉只是拖着。
2. 从普通家务进入议婚，不从坟前直接切婚礼；多次小谈而非一次宣布：贾母名义认可，王夫人、薛姨妈实办，凤姐病中参与，各有各的考虑。
3. 宝钗与薛姨妈私下说，不是一句顺从。
4. 宝玉被明白告知，反应克制，不抗婚。当日走到潇湘馆岔路，站住便回。
5. **连日袖帖而去**（照79回紫菱洲，反用26回）：顺脚走到院门外，落叶萧萧，寒烟漠漠，窗里没有声音。看屋婆子拿家常话打断，可如香菱无心带到他的喜事；他问谁住，仍不进去。
6. **还帖：** 帖原样还给贾兰。贾兰只怪他说过“只拿一日”，他不辩。然后两家才择期。
7. 婚礼虚写、从简；婚前房内安置要写，书架让镜奁，此时素笺一闪，旧物不生争吵。
8. 婚后第一顿饭、新分工，袭人、麝月都在；夫妻头一回为小事说话。同类小事不连写。
9. 回末先落在翻书与针线声，随即上房来人说花家来人了，话未完；不总结婚姻。

### 五、章法配置

家长权力多声部；悼在婚前而短、静，宝钗文字在婚后而长、家常，互不抢戏；空位侧写；身份由称呼变化见出。宝钗一线参照第42回钗黛合写。本回接口多，婚仍须是生活，不写成论断。
丧期常态化 → 议婚 → 岔路一站 → 连日对景 → 还帖 → 择期 → 婚礼缩写 → 婚后空间重排 → 第一餐、针线声。

### 六、诗词/书信

无悼诗。扫叶入筐暗回《葬花吟》。素笺匿名。

### 七、四链与闲笔

- 钱：尚能支撑，因丧期与连续支出压缩。物：布、被褥、妆奁、旧书、饭。信：婚议先内宅，后仆役得知。
- 媒礼、裁缝、针线房、厨房只露工序，不做婚俗博览。笑料：改不过口的“宝姑娘”、麝月拌嘴、香盒里的棋子。

## 保护锁（P1/P2）

- 必须保护：几个月缓冲；“不进去”、看屋婆子、扫叶入筐；书架让镜奁；素笺只说“这个别动”，须在还帖之后；宝钗不清、不问旧纸；婚礼不铺张；小丫头怕黑；第一顿普通饭；针线茶水照常，收在翻书与针线声
- 悼的一段：不哭、不独白、不吟诗；婆子、贾兰不替作者说伤心；宝钗不在场；帖里不夹字；不点破日后还书的呼应。还的是帖，人没有放下，也不是娶宝钗的条件
- 允许增补：议婚、主婚、婚俗、礼单、婚后文化生活
- 禁止破坏：冲喜、骗婚、掉包、失智、大闹、婚礼大哭；盛大排场；三位长辈说同一种话；现代婚姻谈判、现代腔的钗黛裁判；“悼黛即否定宝钗”；进馆翻遗物、馆变祭坛；仙人解释前缘；发现《续庄子》；把素笺身份解释满
