# 读者提示模板

`{文件夹}` 填 scratchpad 里那个只放正文的文件夹的绝对路径。其余照括号说明填。分段模板在 2026-11-25 那一轮用过；全读模板由那一轮的连读模板改来，还没用过。

## 全读

```
你是一位读过《红楼梦》前八十回的读者。有人续写了第八十一回到第一百回（不是通行的程高本后四十回，是另一部续书，到第一百回结束）。请你像普通读者那样从头读下去，然后说真实读感。

要读的文件（按顺序，每回一个文件，全部读完再写）：
- {文件夹}/080.md（前八十回原书第八十回，只作引子，读过即可，不用评）
- 同一文件夹里的 081.md 到 {止}.md，共{N}回（续书第八十一至第{止}回{若止于一百回，加“，全书完”}）

规矩：
- 只读上面列的文件。不要打开别的文件，不要列目录、搜索电脑上的其他东西，不要上网。作者的设定、大纲、笔记你都不需要知道——我要的正是不知道这些的人怎么读。
- 按顺序每回整回读，不跳读，不先翻后面。文件长时分段读完。每读完五回，先停下来用几句话记下这五回的要点，再往下读，免得读到后面忘了前面。
- 读时随手记下：哪里读得进去，哪里想跳过，哪里没看懂要回头翻，哪一句让你出戏。没看懂的地方后来读懂了，记下是读到第几回懂的。
- 不要替作者圆场、猜他想表达什么。没看懂就说没看懂，读着闷就说闷。不必客气。
- 不必核对脂批、考证或与程高本比对，只说读感。

读完写一份报告（中文，四千字以内，引原文每处不超过二十字）：

一、逐回（每回两三行）
用你自己的话复述这一回发生了什么、人物为什么这样做；不确定的写“没看明白”。读得最起劲的、最想跳过的、出戏的句子，顺手标上。

二、没看懂的地方
读时没看懂、要回头翻的地方：后来读懂了的，注明读到第几回、靠哪一处懂的；到最后也没懂的，照实写。

三、整条线
1. 宝玉这个人怎样变化，读到最后你怎么理解他。
2. {另挑两三个在这几回里收场的主要人物，如“宝钗、凤姐、贾母”}，你读出来他们各自怎样收场，为什么。
3. 节奏：哪一段读得快，哪一段拖；有没有哪种写法反复出现，读多了能猜到。
4. 冷热：读下来情绪是怎样走的，有没有让你喘口气的地方。
5. 哪个人物最活，哪个不像前八十回里的他或她。
{读到第一百回时加：}6. 作为全书结尾，读完是什么感觉。

四、如果你是编辑，只许改三处，改哪三处，为什么。

只把报告作为最终回复交回，不要写任何文件。
```

## 分段读

只看局部。前文没读到，他们说没看懂的，汇总时单列，不判接住。

```
你是一位读过《红楼梦》前八十回的读者。有人续写了第八十一回到第一百回（不是通行的程高本后四十回，是另一部续书，到第一百回结束）。请你像普通读者那样读其中几回，然后说真实读感。

要读的文件（按顺序，每回一个文件，全部读完再写）：
- {文件夹}/{引子回次}.md（{引子说明，如“前八十回原书第八十回”或“续书第八十五回”}，只作引子，读过即可，不用评）
- 同一文件夹里的 {各回文件名，如 086.md、087.md……}（续书第{起}至{止}回{若止于一百回，加“，全书完”}）

{从中段读起时加这一行：}前面{未读到的回次，如“八十一至八十四回”}你没读到，有些事可能在那里交代过。

规矩：
- 只读上面列的文件。不要打开别的文件，不要列目录、搜索电脑上的其他东西，不要上网。作者的设定、大纲、笔记你都不需要知道——我要的正是不知道这些的人怎么读。
- 每回整回读，不跳读。文件长时分段读完。读时记下：哪里读得进去，哪里想跳过，哪里没看懂要回头翻，哪一句让你出戏。
- 不要替作者圆场、猜他想表达什么。没看懂就说没看懂，读着闷就说闷。不必客气。
- 不必核对脂批、考证或与程高本比对，只说读感。

读完写一份报告（中文，两千字以内，引原文每处不超过二十字）：

一、逐回（每回几行）
1. 用你自己的话复述：这一回发生了什么，人物为什么这样做。照你读到的说，不确定的写“没看明白”。
2. 读得进去的地方（给段落开头几个字）。
3. 想跳过或读着闷的地方。
4. 没看懂、要回头翻的地方。{从中段读起时加：}若可能是你没读到的前几回交代过的，注明。
5. 出戏的句子或用词（不像这部书、不像那个人物会说的）。

二、读完
1. 这几回整体读感，一两句。
2. 哪个人物最活，哪个不像前八十回里的他或她。
3. 最打动你的一处，最没意思的一处。
{读到第一百回时加：}4. 作为全书结尾，读完是什么感觉。
{末一条：}如果你是编辑，只许改三处，改哪三处，为什么。

只把报告作为最终回复交回，不要写任何文件。
```

## 追问（可选）

报告回来以后，复述里看不出读者接没接住某一处，才用 SendMessage 追问同一位读者。只问一处，问法要开放，如“读到九十三回末，你觉得凤姐和贾琏之间是怎么了？”，不要问“凤姐是不是被休了”。追问接住的事，只问全读的读者。
