# v3之后的工作顺序与完成标准

本页记录本轮读者实际发现的后续工作，不把研究版采用当作缺陷已经消失。当前冻结正文不得就地覆盖；改稿要另建候选、选择器、请求及受影响的审阅任务。

1. **先处理两个中央因果缺口。** 84—87须让实际承担决定的人面对正式回话未齐，给出其已知范围及继续成婚的选择；从简、时间流逝和“两家议定”不足以单独回答正文自己提出的问题。不能凭空编造史制许可。92—93须以人物可知的有限事项或交接变化连接留置与准返，并协调92末韵句的完成感和93才实过门的安排；不能用虚造罪名或完整案情来凑闭环。两处分别做跨回联合新读和文学比较。
2. **处理明确未兑现的规划细目。** 83的船上直接回叙与R4“只经家书或传闻”仍有字面张力，应选择改写为有经手人的转述，或正式版本化修改该C级规划并审读影响。85第五项观察仍缺，不能把四项改称完成；先查是否有依据，没有则保留缺项并裁定规划。85揉肩代词应明确所指。89旧薄书是否就是所选规划的《庄子》须在实际取书处建立可识别性，不能由98倒证。
3. **再作有范围的文学压缩。** 94可合并一轮鞋、鸡、褥边的故障，并处理“定数天工”等旁注感与小曲问答。95保留劳动不满但减少三次直说同一道理，单独评估“门快关”的说话人选择。98及100各择一组重复纠错/照料动作压缩，保护归玉后的日常后果、母子照护转折和临终突出性。96新增粥碗回想也有解释负担，不因比较偏好新版就排除再修。
4. **追踪开放状态而不补造终局。** 巧姐原说几日而跨季延住、平儿收到新地址、若兰缺席原因与归期、88药盒和89药包是否同物，均有未交代处。99佩玉到100归石没有现实实体交接证明；神话层转换可作为C级选择保留，但不得据此登记全链物流已闭合。宝玉终年、宝钗麝月后事及开放榜评也未由本轮补完。
5. **独立人工工作。** 依最终产物索引准备来源原页复核、全语料人工覆盖审计、独立掌管映射的P9文学盲评。材料准备不计人工意见，不代填资格，不主动发送外部消息。生产及stable按现有准入条件另验收。
6. **依赖模型的后续工程。** 当前已将历史谱系与治理兼容性分开，但所选跨回world文件仍是实际整体依赖。只有确需修改这些数据时才设计版本化事件/对象投影及读集：投影须可复原、拒绝漏依赖，并用真实跨回影响用例验证，不能靠忽略SHA变化来缩小复审范围。
