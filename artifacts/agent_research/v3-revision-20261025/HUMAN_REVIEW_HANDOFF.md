# 独立人工工作的材料与完成标准

当前只准备交接材料，尚未启动或取得任何人工审阅。v3的正式研究产物以最终request/manifest及实际build为准；本轮模型比较与原生同行意见不替代下面的资格。

1. **来源复核**：`human-material-index.json`索引所选共享来源的记录、固定载体、定位和图像；按现有真人工作流另建真实身份及意见，不复用模型assignment身份。逐条区分原文、现代汇校、数字录文、代理转录和推断，实际检查载体与相邻原页、版本归属及引文边界。不能查看的材料明确未读，不能用摘要一致充校勘结论。红玉甲戌归属、会典替代载体和适用范围须保留现有纠错痕迹。
2. **全语料人工审计**：同一索引列出当前模型采样与固定carrier，仅是定位入口。人工全量完成须另列全体分段和逐段实际阅读覆盖、未读/不可读范围、转录与分段错误及纠正版本。当前模型采样通过不充作全语料已经人工读过；发现变化后新建数据版本，再计算所选输入的影响范围。
3. **P9文学盲评**：使用冻结候选和最终hash另建正式盲评材料，由与写作者、编辑者和模型协调者相独立的人掌管映射；预先确定比较问题、评者资格和分歧处理。保留原始意见及弃评/未读范围，不以本轮A/B模型偏好代填。重点仍是人物声口、章回节奏、普通生活与情节压力的关系，不能只核对合同。
4. **生产与稳定版**：分别按现有准入条件验收，上述未完成项和实际文本缺陷必须可见。研究采用、技术门控PASS、模型比较完成都不自动更动stable/ACTIVE。任何后续改稿或来源/规划变化另建绑定，变化范围重新审读。

本轮不向外部审阅者发送材料或代填真人意见。实际可复核的独立意见、全量覆盖记录和所有者决定到齐以后，才有相应资格依据；不是给研究版增加一套临时许可流程。

最终冻结产物另见 [human-final-release-index.json](human-final-release-index.json)，绑定最终请求、manifest、读本、20回候选、实际模型比较与处置台账。原准备索引保持不变。此索引本身不增加人工阅读信用。
