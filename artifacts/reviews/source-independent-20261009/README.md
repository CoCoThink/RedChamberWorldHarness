本目录是旧版材料；当前独立复核请使用 ../source-independent-v2-20261009/，绑定协议v2。旧ZIP保持原字节。

本目录是代理准备的材料，尚无独立人工意见。source-contexts.json 固定九条代理摘录更正和三条曹家档案缺口的当前记录；空白表不构成 Review，也不赋予证据权威。

这是公开出处的史料核验，不采用盲评、匿名 A/B 或文学打分。曹家三个 Source 引用同一份奏折的三处文字，版本核验与录文校勘应展示题名、日期、版次和原件位置。独立复核检查代理更正及其依据；P9 小说原稿／修订稿盲评另见 `artifacts/reviews/p9-preparation-20261009/`。已登记的 ZIP 保留原字节，本说明补充在当前阅读入口。

九条更正须复核载体、逐字摘录、见证与 tier，以及更正对已有 Claim／Decision 的影响。实际 Locator v2 与更正 review_asset 引用均在 Source 中，读取这些资产及对应 span 即可重取。相关说明见 docs/reviews/SOURCE_EXCERPT_CORRECTIONS_20261009.md。

曹家三条使用同一档案题名、日期的候选载体，但尚未确立原引用版本。cao-carrier-physical-page-0121.png/txt 来自已登记 PDF 的物理页121，提供可审阅的录文；不能用页图反向证明其出版版本。需要可核查版次的正文／原档影像，确认姓名字形、床几／床杌及家属留房录文。缺口不因网页近似录文或 OCR 推测而关闭。

请提供真实的独立复核记录与原始意见；程序的逐字定位成功仍不等于文献学或 Claim 推理获得独立认可。

独立评审者填写原始 JSON 后接收为 REVIEW_RECORD。结构化记录增加 schema_version: 1、唯一 id、raw_review: {asset_ref, sha256} 与 authority_effect: NONE，存入 data/provenance/audits/reviews/，并用路径／完整摘要选择到 selection.json。原始声明和评审项必须逐字段一致；可以先提交九条已定位更正的意见，未覆盖的来源继续 PENDING。Source、协议或下游 Claim／Decision／Implementation／Axis 变化均使相关复核失效。对于新取得的曹家版本，应先完成独立载体／摘录更正，更新协议为新版本，再提交对应复核。
