# 43-0 / 第86回压力测试｜C 小段试写：强压下限版

> 这是故意向强压方向推进的下限实验，用来测试日常肌理删到哪里开始变薄；不是推荐稿。

宝钗去了。紫鹃回来时，见黛玉闭着眼，便悄悄把小炉上的药又温了。

到傍晚，黛玉仍吃不下去。药喂一口便偏过头，米汤也只沾了沾唇。雪雁要催大夫，紫鹃说已经叫过，只是一时来不得。

黛玉听见，道：“我又没有添出新病来给他看。”话未说完，便嫌窗上亮。紫鹃放下帘子，拿温帕替她敷眼。黛玉只容了一会，道：“罢了，越发涩得疼。”紫鹃见她眼角干干的，心里发紧。

掌灯时，送药的婆子来问明日还照今日的分量抓不抓。雪雁正心烦，要她明日再来。黛玉隔帘听见，只道：“明儿的事，明儿再问。”又劝雪雁：“人家也是当差。”

天黑后，大夫仍只传话叫照旧方。紫鹃原想回老太太那边，又想起从前也有夜里病重、第二日缓过来的时候，便迟了一刻。

黛玉听她们在外头低声说话，只问：“又为我跑什么？”紫鹃说炉里炭不够。黛玉道：“从前自然不值什么。如今什么都要人走一趟。”

她一句话要分几口气说完。紫鹃摸她的手，已经冰凉，忙问要不要水。黛玉看了她一会，道：“你今日怎么这样烦？”

少时，黛玉忽问：“宝玉走了么？”紫鹃说早走了。她又问：“他那本书拿走了没有？”紫鹃道：“拿走了。姑娘还怕赖在咱们头上呢。”黛玉嘴角略动了一动。

紫鹃这才叫雪雁去回老太太、太太，又叫人告诉宝玉。

屋里只剩一盏灯。黛玉呼吸时长时短。许久，她极轻地说：“水。”紫鹃拿小匙喂到唇边，她只抿一点便摇头。灯花爆了一下，紫鹃起身剪去，再回头时，床上已经静了。

她叫一声“姑娘”，没有应。又叫一声，仍没有应。伸手去摸，黛玉的手软软任她握着。紫鹃伏到床沿，半晌才哑声叫道：“姑娘！”

雪雁和婆子赶回来，随后李纨、王夫人、贾母也到了。屋里添灯、取衣、预备热水，转眼全是人。紫鹃却只护住小几上的药碗：“这个别动。”

宝玉听说“林姑娘不好”，还当同往日一样，一路问大夫到了没有。走进潇湘馆，见院里有人哭，才慌起来。

他到床前叫了两声“妹妹”，又碰黛玉的手，才挨着便缩回来：“怎么这么凉？紫鹃，怎么不把手炉拿来？”

无人答他。

宝玉看见小几上那盏药，道：“药不是还没吃么？再温一温。今儿早起她还说药苦。”

屋里仍无人答他。
