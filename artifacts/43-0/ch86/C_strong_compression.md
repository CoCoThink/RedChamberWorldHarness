# 43-0 / 第86回压力测试｜C 小段试写：强压下限版

> 在B基础上继续压去外界跑腿与一部分死后家务层，用来测试小说是否会因此过于洁净、过于“为死亡服务”。

宝钗去了。紫鹃回来时，见黛玉闭着眼，便悄悄把小炉上的药又温了。

谁知这一回直到傍晚，黛玉竟没有再吃。紫鹃先拿小匙喂了一口，她皱着眉咽下，第二口便含不住，忙偏过头去。紫鹃只得拿帕子擦了，又换米汤。米汤也不过沾了沾唇。雪雁见她两颊比午间更白，心里发慌，道：“姐姐，还是叫人去请大夫罢。”紫鹃道：“已经叫去了。才门上回话，说那边一时不得空，晚些再来。你别在姑娘跟前乱。”

黛玉却听见了，道：“什么晚些再来？”紫鹃只得道：“大夫说晚些过来。”黛玉道：“白跑这一趟作什么。我又没有添出新病来给他看。”紫鹃勉强笑道：“姑娘嫌他，他倒未必敢嫌姑娘。”黛玉也不答，只道：“窗上怎么这样亮？”雪雁道：“外头天还没黑尽呢。”黛玉道：“我只觉得刺眼。”

紫鹃忙把帘子放下一半，又拿温帕替她敷眼。黛玉只容了一会便拿开，道：“罢了，越发涩得疼。”雪雁问还添不添热水，黛玉道：“你们今儿只同水过不去了。”说两句话，便要停一停才接得上。紫鹃心里发紧，却仍把灯、药、帕子照常收拾。



天黑后，大夫仍只传话叫照旧方。紫鹃原想回老太太那边，又想起从前也有夜里病重、第二日缓过来的时候，便迟了一刻。

雪雁急道：“还等？你瞧姑娘这会子说话——”紫鹃瞪她一眼。雪雁忙住口。黛玉在床上却听见了，问道：“你们两个嘀咕什么？”紫鹃忙过去道：“雪雁说炉里炭不够，问要不要再取些。”黛玉道：“一晚上能用多少。别为我又满园子跑。”紫鹃心里一酸，笑道：“姑娘只管歇着，炭又不值什么。”

黛玉道：“从前自然不值什么。如今什么都要人走一趟。”说完闭了眼。紫鹃见她一句话分作两三口气才说完，再不敢等。她伸手摸黛玉额上，并不很热，只是手指冰凉。忙俯身叫道：“姑娘，喝一口水罢？”黛玉睁开眼，看了她一会，仿佛认了认，才道：“你今日怎么这样烦？”

紫鹃强笑道：“姑娘嫌我烦，明儿我躲出去一天。”黛玉道：“你躲得了才怪。”这句话声音极轻，紫鹃却听得清清楚楚。她鼻中一酸，忙背过脸去倒水。

又过了一会，黛玉忽问：“宝玉走了么？”紫鹃一怔，道：“早走了。姑娘忘了？老太太那边叫去的。”黛玉道：“哦。”紫鹃等她再说，却没有下文。半晌，黛玉只道：“他那本书拿走了没有？”紫鹃道：“拿走了。姑娘还怕赖在咱们头上呢。”黛玉嘴角略动了一动，像要笑，却没笑出来。

紫鹃这才真正慌了，走到外间一把拉住雪雁，低声道：“你这会子就去。先回老太太、太太，说姑娘今夜很不好，请人来瞧。再打发人告诉宝二爷。别在路上哭，也别逢人就嚷，快去快回。”雪雁脸一下白了，道：“姐姐——”紫鹃道：“还不快去！”雪雁忙披了衣裳，正要走，紫鹃又追出来道：“老太太若问什么时候坏的，就说黄昏后吃不进药，方才气更短。别说别的。”

雪雁点头，匆匆去了。门帘一响，黛玉睁眼问：“雪雁呢？”紫鹃回到床边，道：“我叫她出去取点东西。”黛玉看了她一眼，也不知信不信，竟没有再问。少时只道：“帘子放下些。”紫鹃依言把床前帘子放低。屋里顿时暗了许多，只剩案上一盏灯。灯花结得老长，火苗一跳一跳的。紫鹃坐回床边，握着黛玉的手。黛玉似睡非睡，呼吸时长时短，偶尔眉尖轻轻皱一下。

紫鹃不敢叫她，只用手指轻轻摩着她的掌心。许久，黛玉忽然极轻地说了一句：“水。”紫鹃忙扶她起来一点，拿小匙喂到唇边。黛玉只抿了一点，便摇头。紫鹃把她放回枕上，替她擦了唇角。外头似有脚步声，紫鹃以为雪雁回来了，起身去听，却又没有。正要转身，只见灯花又爆了一下。她便拿剪子剪去灯花，回头时，床上静得出奇。

紫鹃心里一沉，忙走过去，低声叫：“姑娘。”黛玉没有应。她俯下身，又叫了一声：“姑娘？”仍不应。紫鹃伸手去摸她的手，方才虽凉，尚有一点活气，此时却软软的任她握着。紫鹃怔了一怔，像是不明白，忙把耳朵凑近，又把手放在她胸前，半晌才猛地直起身来。她张了张口，竟没出声。过了一会才伏在床沿，哑着嗓子叫了一声：“姑娘！”

这一声才出口，外头恰好一阵脚步急响。雪雁先冲进来，后面跟着两个婆子、小丫头。雪雁一见紫鹃的样子，脚下一软，扶住门框。婆子忙上前看了一眼，便说：“快回老太太！”一人转身又跑了出去。雪雁扑到床前要哭，紫鹃忽一把捂住她的嘴，道：“别嚷！”说完自己却再也忍不住，眼泪一串串落下来。

不多时李纨、王夫人先后赶来。添灯的添灯，预备热水的预备热水，又有人问黛玉素日衣裳在那里。紫鹃坐着像没听见，半晌才抬头四下一看：不过一刻工夫，屋里已经同方才全不一样；床前却还是那张床、那方帕子、那只小几。她忽然伸手把药碗护住：“这个别动。”李纨道：“先搁着。”

贾母随后也到了，屋里这才真正起了哭声。

却说宝玉先前到了贾母房里，被留着吃了些东西，又听老太太问了几句话。后来见人进进出出，他也没在意，只当外头仍有家事。雪雁赶来时，恰被门上的人拦了一下，叫先回王夫人那边。及至消息传到宝玉耳内，只有一句“林姑娘不好，快过去”，宝玉还道同往日一般，忙披了衣裳便来，一路还问：“大夫到了没有？老太太过去了没有？”麝月跟在后头，只答“都去了”。

走到潇湘馆门口，宝玉见平日静悄悄的院子此时站了许多人，有人哭，有人端水，心里才猛地发慌。掀帘进去，又见贾母坐在那里哭，王夫人、李纨都在，紫鹃伏在床边。他脚下一停，竟不敢再走。麝月在后面轻轻推了他一下。宝玉才慢慢走到床前，看见黛玉安安静静躺着，脸上竟比这几日病中还平和些。他怔怔看了半日，仿佛还等她睁眼说一句“你今儿又来得早”。

忽然他俯下身去，叫道：“妹妹。”无人应他。他又叫了一声。紫鹃听见这声音，身子猛地一颤，却没有抬头。宝玉伸手想碰黛玉的手，才挨着便缩了回来，嘴里道：“怎么这么凉？紫鹃，怎么不把手炉拿来？”紫鹃这才抬头看他，眼睛已哭肿了，张口欲言，却一句也说不出。

宝玉又看见小几上那盏药，像忽然想起什么，道：“药不是还没吃么？再温一温。今儿早起她还说药苦。”屋里竟没有一个人答他。
