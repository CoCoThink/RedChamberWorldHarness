# 43-0 / 第86回压力测试｜功能结构与压力点拆分 v1.0

## 目标

本轮不把稳定第86回视为“有缺陷待修复”的稿件，而把它视为已经通过R4的文学基线，专门测试：

1. 病程是否因为日常照料与跑腿过密而稀释后半回的收束；
2. 冷药链是否仍是全回真正的终端力量；
3. 宝玉来迟是否仍以“普通病中动作”承受死亡，而非传奇感应；
4. 黛玉最后文学动作是否保持“改字—删字—未成”，不生成完整绝命诗。

## A基线的完整功能序列

A0｜清晨病中日常  
药吊、米汤、火箸、笑语，先证明黛玉仍在活人的时间里。

A1｜宝玉早访  
旧砚、旧书、窗帘、借帖、丢东西等无关紧要小事，建立“明日还会有”的生活错觉。

A2｜宝钗午访  
饭、药、糖、丫鬟吃饭等照料，把病体放回家常关系。

A3｜未成诗稿  
“小院苔痕留宿雨”；“怯”删去，“试”又圈去。最后文学动作是判断与删除，不是绝命诗。

A4｜傍晚恶化  
吃不进药、眼涩、温帕、添水、等大夫。

A5｜外界日常继续撞入  
药铺补药、问明日分量与钱；误送素点心。作用是证明病危时世界仍不围着一个人停转。

A6｜是否报上房的迟疑  
紫鹃因多年“重了又缓”而不敢立刻把这次认作最后一次。

A7｜宝玉/旧书回声  
黛玉问宝玉走了没有，又问他的书拿走没有。没有诀别，只把早晨闲话轻轻回扣。

A8｜最后的水与死亡  
“水”是最后明确需求；灯花、手、呼吸完成身体层终止。

A9｜死亡后的家务接管  
添灯、热水、衣裳、钥匙、炉子、药碗。死亡不使物质世界停止。

A10｜宝玉来迟  
宝玉先问大夫、手炉、药，并说“再温一温”，说明他仍按普通病程理解眼前世界。

A11｜天明冷药终句  
药汁倒去、炉火熄灭、诗稿归匣，最后剩“那盏药早已冷透，再没有人去温。”

## 压力点

当前最值得测试的是 A4—A6。

这里有三类信息连续出现：

- 病体信息：咽不下、眼涩、气短、手冷；
- 照料信息：帕子、热水、药、小炉、大夫；
- 外界摩擦：药铺补药/欠款、误送点心、上房是否惊动。

这些都有效，但叠加后可能产生一个风险：

> 读者在到达“宝玉问书—最后一口水—死亡”前，已经连续处理太多照料与跑腿信息。

因此只测试“密度”，不测试“是否删除日常机制”。

## B｜轻压原则

只压重复，不压机制：

- 保留一次“大夫来不得”；
- 保留眼涩/温帕，作为身体恶化的非抽象信号；
- 保留一次外界日常闯入，但压缩药钱对话；
- 删除误送素点心这一第二个外界插曲；
- 缩短“再等一刻”的解释，但保留紫鹃为何误判；
- 保留“从前自然不值什么。如今什么都要人走一趟”；
- 保留问宝玉、问旧书、最后要水、死亡、药碗、宝玉“再温一温”。

预期效果：后半回更集中，冷药链更早形成持续压力。

## C｜强压下限原则

继续保留硬文学接口，但主动测试“压到哪里开始变薄”：

- 药铺婆子与误送点心全部删去；
- 大夫延误只留一句带过；
- 把温帕、添水、报上房迟疑合并；
- 快速推进到问宝玉/问书、最后一口水与死亡。

预期风险：

- 病死过程可能过于洁净、诗化；
- 紫鹃的误判可能失去生活根据；
- “世界仍照常办差”的冷意被削弱；
- 宝玉来迟虽更集中，却可能因前段太干净而显得被作者刻意安排。

## 当前阶段裁定

本阶段不裁定A/B/C优胜。

只确认：

- A是稳定基线；
- B是“轻压候选方向”；
- C是“强压下限实验”；
- 三者都不得覆盖稳定ACTIVE；
- 下一阶段才进入六字段回归、P-Lock回归和盲读。
