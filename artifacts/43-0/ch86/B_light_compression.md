# 43-0 / 第86回压力测试｜B 小段试写：冷药聚焦轻压版

> 这是替换 A 基线中“宝钗离去—宝玉来迟见药碗”区段的压力试写，不是正式新正文。目标是压重复而不压日常机制。

宝钗去了。紫鹃回来时，见黛玉闭着眼，便悄悄把小炉上的药又温了。

谁知这一回直到傍晚，黛玉竟没有再吃。紫鹃拿小匙喂了一口，她皱着眉咽下，第二口便含不住，忙偏过头去。米汤也只沾了沾唇。雪雁见她两颊比午间更白，低声道：“姐姐，还是叫人去请大夫罢。”紫鹃道：“已经叫去了。门上说那边一时不得空，晚些再来。你别在姑娘跟前乱。”

黛玉听见了，道：“什么晚些再来？”紫鹃只得说大夫稍后便来。黛玉道：“白跑这一趟作什么。我又没有添出新病来给他看。”说完却闭了闭眼，道：“窗上怎么这样亮？”

紫鹃忙把帘子放下一半，又拿温帕替她敷眼。黛玉只容了一会，便抬手拿开，道：“罢了，越发涩得疼。”紫鹃接过帕子，见她眼角干干的，心中一跳，低头把帕子在盆里洗了又洗。

雪雁问还要不要添热水。黛玉听见，轻声道：“你们今儿只同水过不去了。”紫鹃道：“姑娘若肯喝两口，我们就不折腾水了。”黛玉微微摇头。说两句话，便要停一停才接得上。紫鹃只装作寻常，把灯、药、帕子一样样收拾停当。

掌灯时，送药的婆子拿来补齐的两包药，又问明日还照今日的分量抓不抓。雪雁正心烦，道：“明儿再来问罢。”婆子为难道铺里等回话。里间黛玉听见，问是谁。紫鹃道：“送药的问明儿的药。”黛玉停了一停，道：“明儿的事，明儿再问。”

那婆子忙应声退了。雪雁还要抱怨，黛玉道：“人家也是当差。她若知道什么时候该来，倒不在门上跑腿了。”紫鹃劝她歇着，黛玉果然不再说。

天黑透了，园中偶有门响。大夫到底没来，只叫小学徒带话，说前一处病人绊住了，太晚便仍照旧方。紫鹃听了低声道：“早上说好些不必请，如今请了又来不得。”

雪雁道：“我再去催？”紫鹃摇头，先说要回老太太那边，话出口又迟疑。黛玉这些年也有病重一夜、第二日缓过来的时候。紫鹃怕平白惊动老人，只道：“再等一刻。若药能吃下去，就先不惊动。”

黛玉在床上听见，问她们嘀咕什么。紫鹃只说炉里炭不够。黛玉道：“一晚上能用多少。别为我又满园子跑。”紫鹃笑道：“炭又不值什么。”

黛玉道：“从前自然不值什么。如今什么都要人走一趟。”一句话分作两三口气才说完。紫鹃再不敢等，摸她额上并不很热，手指却冰凉，忙问：“姑娘，喝一口水罢？”

黛玉睁眼看了她一会，道：“你今日怎么这样烦？”紫鹃强笑：“姑娘嫌我烦，明儿我躲出去一天。”黛玉道：“你躲得了才怪。”声音极轻，紫鹃背过脸去倒水。

又过了一会，黛玉忽问：“宝玉走了么？”紫鹃一怔，道：“早走了。老太太那边叫去的。”黛玉“哦”了一声。半晌又道：“他那本书拿走了没有？”紫鹃道：“拿走了。姑娘还怕赖在咱们头上呢。”黛玉嘴角略动了一动，像要笑，却没笑出来。

紫鹃这才真正慌了，拉雪雁到外间，低声道：“你这会子就去。先回老太太、太太，说姑娘今夜很不好，请人来瞧；再打发人告诉宝二爷。别在路上哭，也别逢人就嚷，快去快回。”雪雁披了衣裳要走，紫鹃又追出来道：“老太太若问什么时候坏的，就说黄昏后吃不进药，方才气更短。别说别的。”

雪雁去了。门帘一响，黛玉问：“雪雁呢？”紫鹃道：“我叫她出去取点东西。”黛玉看了她一眼，没有再问，只说把帘子放低些。屋里剩案上一盏灯。紫鹃坐回床边，握着她的手。黛玉似睡非睡，呼吸时长时短。

许久，黛玉极轻地说了一句：“水。”紫鹃忙扶她起来，拿小匙喂到唇边。黛玉只抿了一点，便摇头。外头仿佛有脚步，紫鹃起身去听，却又没有。她转身时，灯花爆了一下，便拿剪子剪去。再回头，床上忽然静得出奇。

紫鹃忙走过去，低声叫：“姑娘。”没有应。又叫一声，仍没有应。她摸黛玉的手，方才虽凉，尚有一点活气，此时却软软任她握着。紫鹃怔住，俯身听了半晌，才猛地直起身来。张了张口，竟没有声音；过了一会，才伏在床沿哑声叫道：“姑娘！”

外头脚步急响。雪雁先冲进来，后面跟着两个婆子、小丫头。雪雁一见紫鹃的样子，脚下一软。婆子忙上前看了一眼，便说：“快回老太太！”雪雁扑到床前要哭，紫鹃忽然一把捂住她的嘴：“别嚷！”自己却已一串串落下泪来。

李纨先赶到，衣裳都没换齐，只披着外衣。她在床前站了一站，低声问：“什么时候？”紫鹃半日才道：“才……才刚。方才还要水。”李纨红了眼，却先问老太太、太太都知道没有，又吩咐外头别一窝蜂挤进来，添灯，预备热水，取黛玉素日常穿的衣裳。

王夫人随后也到了。屋里不过一刻工夫，已经同方才全不一样：有人添灯，有人收盆，有人挪小炉，有人问热水往那里放；床前却还是那张床、那方帕子、那只小几。紫鹃忽然伸手把小几上的药碗护住，道：“这个别动。”李纨看了一眼，道：“先搁着。”

贾母由鸳鸯等扶进来，一见床上便哭道：“我的玉儿！”屋里这才真正起了哭声。

却说宝玉先前到了贾母房里，被留着吃东西、说话，后来见人进进出出，也只当仍有家事。消息传到耳内，不过一句“林姑娘不好，快过去”，宝玉还道同往日一般，披了衣裳便来，一路问：“大夫到了没有？老太太过去了没有？”

到了潇湘馆门口，见平日静悄悄的院子此时站了许多人，有人哭，有人端水，他心里才猛地发慌。掀帘进去，又见贾母坐在那里哭，王夫人、李纨都在，紫鹃伏在床边，他脚下一停，竟不敢再走。

宝玉慢慢到床前，看见黛玉安安静静躺着，怔怔看了半日，仿佛还等她睁眼说一句“你今儿又来得早”。

他俯下身叫：“妹妹。”无人应。又叫一声。伸手去碰黛玉的手，才挨着便缩回来，道：“怎么这么凉？紫鹃，怎么不把手炉拿来？”

紫鹃抬头看他，眼睛已经哭肿了，一句话也说不出。

宝玉又看见小几上那盏药，像忽然想起什么，道：“药不是还没吃么？再温一温。今儿早起她还说药苦。”

屋里竟没有一个人答他。
