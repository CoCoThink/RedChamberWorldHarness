# 43-0 / 第89回压力测试｜功能结构与压力点拆分 v1.0

## 目标

第89回的问题不是“抄没机制写得不对”，而是测试：

1. 前半回程序信息是否过密，形成制度展示；
2. 大事件是否持续被菜、粥、钥匙、药盒、衣裳、车钱、脚钱、热水等小生活吸收；
3. 贾芸的能力是否表现为跑车、谈价、找脚夫，而不是作者宣布“仗义能干”；
4. 迁居后的共井、小灶、误拿衣物、借针线，是否仍是全回真正的落点；
5. 回末“谁家的水桶还在井边？”是否保持P1终端力量。

## 全回功能序列

A0｜迎春死后余波与钥匙转手  
袭人的旧药盒仍在，衣柜钥匙已到麝月腰间。先以物件交代人事变动。

A1｜官差到门  
扫地、热粥、菜挑、夜香车先出现；抄没从门洞里的普通劳动被打断开始，而不是从制度说明开始。

A2｜消息失真与内宅自乱  
“封府”“拿人”、私包袱、公私难分。制度先变成恐慌。

A3｜凤姐建立最低秩序  
不问案情，只先问药、衣、铺盖、老人今晚怎么睡；同时制止烧账藏账。

A4｜贾母的生活尺度  
“人总要睡，总要吃药。”把大事压回身体与夜晚。

A5｜宝玉房被点看  
钥匙、卡住的锁、旧药盒、领物单子、厚夹袍。个人所有感第一次失灵。

A6｜众人私物样本  
老妈妈的小木匣、旧钱、银簪、锁片、橘皮；“一辈子的东西”在制度目光里只是一只小匣。

A7｜凤姐过载  
账、钥匙、儿子早饭、车、问话不断涌入；她的“强英雄”尚未到第90回标题，但能力已由杂务承重。

A8｜贾芸在门外跑  
找车、谈风险、等候钱、脚钱、不要大柜。功能必须通过市场摩擦体现。

A9｜厨房与私钱  
饭做多少、库米够不够、小丫头几百钱算不算私藏——抄没落在吃饭与私产边界。

A10｜准话下来  
可移老人病人内眷；只许随身衣物、铺盖、药物。程序只在此形成真正改变生活的边界。

A11｜“只能拿几样”的选择  
厚褥、药包、书、厚夹袍；宝玉第一次知道自己的柜门不是想开便开。

A12｜妙玉米炭  
制度波及寺居，但只写成“还有多少”“先省着烧”。

A13｜贾芸搬人  
车钱、脚钱、铺盖卷、药包，行动层承担“救急”。

A14｜借住院  
房间变窄、共井、小灶、热水排班、隔壁咳嗽听得见。

A15｜物件开始混用  
剪子、针线、枕头、衣裳、药盒、钥匙；大家从“大宅私域”进入“共享小院”。

A16｜回末共井  
麝月排队打水，与隔壁老婆子争桶；最后一句“谁家的水桶还在井边？”把抄没彻底翻译成第二天清晨的生活。

## 主要压力点

最值得施压的是 A1—A10。

现稿优点是程序始终有人物、物件与劳务承载；风险是同一原则（不许乱动、逐项报明、公私要看清）经过多个场景重复出现，可能让读者在真正迁居前已经感到“规则说明充分”。

因此测试方向不是删除制度约束，而是：

> 每一项制度原则只需被一个最有文学承重力的生活场景证明。

## B｜轻压原则

- 门口保留菜挑，不再展开第二层相似例子；
- 凤姐/贾母保留药、铺盖与“人总要睡，总要吃药”；
- 宝玉房保留钥匙、卡锁、旧药盒、书纸被拿走；
- 私人物件只保留老妈妈小木匣这一例；
- 贾芸找车、谈价、等候钱完整保留；
- 厨房米与小丫头私钱二选一压缩，而非都铺长；
- 午后“准话”必须留下，作为程序真正改变生活的单一边界。

目标：减少规则复述，保留最多小生活承重。

## C｜强压下限原则

- 官差到门后快速进入凤姐与宝玉房；
- 老妈妈私物、厨房私钱等旁例大幅削去；
- 贾芸车价保留骨架；
- “准话”尽快到来。

预期风险：

- 抄没会显得过于顺滑；
- “公私边界一时无法分清”的生活感变薄；
- 凤姐和贾芸的能力可能被剧情功能化；
- 后半回借住小院虽仍成立，但从大宅到小院的社会摩擦不够。

## 当前阶段

不裁定A/B/C优胜。

只把B、C作为第89回的压力方向，稳定ACTIVE仍为v1.4。
