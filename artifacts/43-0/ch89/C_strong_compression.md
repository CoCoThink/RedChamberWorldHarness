# 43-0 / 第89回压力测试｜C 小段试写：程序强压下限版

> 强压实验。保留制度真正改变生活的节点，但主动削去若干旁例，用来测试抄没是否因此过于顺滑。

天才大亮，荣府门上小厮正扫台阶，想着扫完去吃热粥，街口便来了书办、差役。差役只叫先看住门，车轿箱笼不要出去。恰有送菜挑子堵在门洞，挑夫急说菜要蔫，差役道：“日用菜蔬送进去，挑子出来。别夹带箱包。”

消息传进去已变成“封府”“拿人”。一个婆子抱自己的衣包往外走，被平儿拦住。婆子说不是公中的，平儿道：“如今谁有工夫替你分公中私下？先放回去。”

凤姐身上不好，听说箱柜账册先别动，不问没听准的案情，只叫平儿去问老人病人的药、衣裳和今夜铺盖能不能先留，又吩咐账房一张也不许烧藏。

贾母听完，只道：“人总要睡，总要吃药。”

宝玉房里，麝月腰上正带着衣柜钥匙。书办来叫开柜，平日一拧便开的锁偏转不开。宝钗叫她把柜门往里推，才开了。听说日用药可先取，麝月忙抱出袭人留下的旧药盒。昨日还嫌它占地方，今日却先抱得紧紧的。

书办又把几束园里旧单子拿去核看。宝玉想说话，宝钗只道：“问什么答什么就是。”人走后，宝玉伸手摸柜门，想起“不要擅动”，又把手收回来。

凤姐那里问话仍一件接一件，连有人在外头没吃早饭也来问。凤姐只道门口若放送饭便送一碗，不放也饿不坏半日。听说府里的车不能动，她便叫人找贾芸：“进不来才好叫他在外头跑。”

贾芸果然在门外。他去街口找车，车夫怕靠近官差惹麻烦，贾芸便说车只在街口候，真走不了也照给等候钱。又找脚夫搬铺盖，先说定只搬准许搬的。

晌午厨房来问饭怎么送。库门既看住，米只够今日。凤姐道：“那就先吃今日。明日的事明日问。”

午后终于有了准话：老人、病人及内眷可以先移出暂住；随身衣物、当夜铺盖、日常药物逐件报明后取；箱柜大件、账册文书仍留原处。早晨是不知道怎么办，如今知道只能拿有限几样，人人便都觉得自己那一样最要紧。
