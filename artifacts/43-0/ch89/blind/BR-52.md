# 第89回盲读候选｜BR-52

# 第八十九回　荣府抄没封旧院门　贾芸奔走急迁诸眷

话说迎春死信到后，荣府上下又乱了几日。邢夫人那边自然另有一番伤心忙乱，贾母年高，经不得接二连三的消息，众人只拣要紧的话回她。宝玉自听见迎春没了，也闷了两日；宝钗并不多劝，仍照常叫麝月收衣、送饭、问安。袭人留下的那只旧药盒还搁在抽屉里，衣柜钥匙却换到麝月腰间。麝月起初总觉那串钥匙碍事，走路叮当乱响，一日还向宝钗笑道：“早知拿着这个这样累，当日该叫袭人姐姐把柜子一道搬走。”宝钗道：“柜子搬走，你又要找地方放衣裳。”麝月道：“横竖如今什么都挤在一处，也不差它。”

说话之间，又过了一阵。这日天才大亮，荣府门上两个值夜小厮正交班，一个扫台阶，只想着扫完好去吃热粥。街口忽来骑马的人，后面跟着书办、差役。扫地的小厮才把笤帚靠下，前头便叫：“门上人都在这里，不要乱走。”

老苍头上前通禀，差役只道先看住门，车轿箱笼不要出去。传话的人跑得太急，险些绊在门槛上，差役道：“慢些。摔断腿，我们还得等你。”

正巧送菜的挑子已经进来，堵在门洞里，急说菜再闷就蔫。差役看一眼，道：“日用菜蔬送进去，挑子出来。别夹带箱包。”挑夫一面往里挪，一面低声道：“早说不就完了。”

消息传到内里时，已经有人说“封了府”，也有人说“老爷们都要拿了”。一个婆子抱着自己的旧衣包往外走，被平儿拦住。婆子说不是公中的，平儿道：“如今谁有工夫替你分公中私下？先放回原处，等问明白再说。”

凤姐昨夜身上便不好，早起只吃两口粥，听平儿说门关了、箱柜账册先别动，便先问老太太那边。她道：“案情听不准的先别传。只去问一句：老人病人的药、衣裳、今夜铺盖，能不能先留出来。别只顾乱，到晚上连被褥都没有。”又吩咐账房原样放着，谁也不许烧一张藏一张。

王夫人到了贾母上房。平儿只把听准的说了。贾母没有立刻哭，先问人要不要出去。听说凤姐正在问老人病人的铺盖药物，便道：“这个问得是。人总要睡，总要吃药。”

宝玉、宝钗这边，麝月正拿着衣柜钥匙，听见各处箱柜别开，只道：“这倒巧，我才想把昨儿洗的衣裳收进去。”宝玉要出去问，宝钗先叫他把鞋穿好，又叫麝月记住日常药、两身换洗衣裳和今夜铺盖。

不多时书办、差役到了院门。麝月下意识把钥匙往衣襟里掖了一下，又自己拿出来。平日一拧便开的锁，偏转两次不开。差役道：“慢慢开，又没人抢你钥匙。”宝钗叫她先把柜门往里推，锁才开了。

书办记下衣柜杂柜，说眼前穿用可报急用，余下先别动。麝月忙问病人的药，听说日用药可先取，赶紧抱出袭人留下的旧药盒。盒盖有一处磕痕，昨日还嫌占地方，今日倒先抱得紧紧的。

另一个书办抽出几束园里旧单子。宝玉要解释，宝钗只道：“问什么答什么就是。”几束有各房名目的纸被拿去核看。人走后，宝玉伸手摸柜门，想起方才的话，又把手收回来。

前头点看一处，内宅便乱一处。有个老妈妈死死抱着一只小木匣，说是一辈子的东西。打开不过几枚旧钱、两根银簪、一块磨白的锁片，还有一包晒干的橘皮。差役看过便叫她合上。她仍问今日能不能带走，听说先放自己屋里，才念叨着“看过了便好”离开。

凤姐房里问话不断：旧账放哪里，钥匙在谁手里，外头的儿子还能不能进来。凤姐脸色发白，一件件回。听见有婆子只惦记儿子没吃早饭，反停一停：“门口若放人送饭，就给他送一碗；不放，也饿不坏半日。”

贾琏托话进来，叫里头先照准许的名目收拾。凤姐只叫平儿找贾芸：“他若听见消息，多半会来。进不来才好叫他在外头跑。”

果然未到午时，贾芸已在门外候着。守门人隔门缝说里头恐怕要移几房人，府里的车却不能随意用。贾芸转身去找车。街口有车行不敢应，也有趁忙报高价的。车夫怕车进去被扣，贾芸道：“不叫你进去，只在街口候。真不让走，一文钱也不短你的等候钱。”说定两辆，又找脚夫搬铺盖。有人笑问“搬出府还是抄进去”，贾芸道：“只搬准许搬的。多问也不给你们多钱。”

到了晌午，厨房也来问饭怎么送。库门看住了，现有的米只够今日。凤姐道：“那就先吃今日。老太太那边仍做软烂些。明日的事明日问。”说完咳了两声。平儿给她水，她道：“我少说一句，她们就多跑两趟。”

又有人来问小丫头自己攒的几百钱缝在腰带里算不算私藏。凤姐闭眼道：“她自己的钱叫她自己带着。只是别这会子当人面拆腰带数钱。这个也来问我，我今日活该累死。”

午后终于有了准话：老人、病人及内眷可以先移出暂住；随身衣物、当夜铺盖、日常药物逐件报明后取；箱柜大件、账册文书仍留原处。早晨是不知道怎么办，如今知道只能拿有限几样，人人便都觉得自己那一样最要紧。

王夫人先命人去问贾母的铺盖和常用药。李纨只要贾兰的几本正在读的书并两套衣裳，偏那书放在另一处，叫人来回跑了两趟才报明。邢夫人那边也有人来争，说一只旧箱里有她自己的东西，为什么不能一道抬走。平儿只得叫她先把要用的名目写清，能取多少再说。凤姐听见“写名目”，叫平儿把纸拿来，自己口述：“老太太——厚褥一床，盖被一床，常用药一包，衣两套；太太——”说到这里咳起来。平儿忙接过道：“我来写，奶奶说慢些。”

凤姐道：“你字写快些，别一笔一画绣花。”平儿道：“这会子还嫌我字慢。”凤姐道：“平日叫你写个帖子，半日写得像刻出来的；今日倒要的是腿，不是字。”平儿嘴里应着，笔下果然快了。轮到宝玉、宝钗这边，麝月早已把药盒、两套衣服、一床较厚的被褥、一只小针线包放在床上。宝玉见自己常看的几本书还在案上，问：“书不能带？”

宝钗道：“眼下先拿该用的。”宝玉道：“书也该用。”麝月道：“晚上你若冷了，书替你盖脚不成？”宝玉道：“少拿一件衣裳也就是了。”宝钗没有同他争，只从案上拣了一本最薄的，道：“这一册夹在衣包里。其余先放着。”宝玉看她一眼，道：“为何只这一册？”

宝钗道：“因为它薄。”宝玉听了竟笑了一下，也不再说。麝月又去开衣柜，要拿那件厚夹袍。谁知外头已有人来催，说这一处刚才点过，若再开柜须叫书办来看。麝月只得拿钥匙出去问。守在廊下的差役道：“方才不是已经取了两套？”麝月道：“还有一件厚的，晚上怕冷。”

差役道：“报了没有？”“才想起来。”差役看她一眼，道：“先记着。今日人多，等这边点完再说。若赶不及，明日按名目回来取。”麝月急道：“可今夜——”宝钗从里头出来，道：“算了。先拿这床被。”麝月只得回来，嘴里道：“这钥匙如今倒成摆设了。”她把钥匙往腰上一塞，叮的一声撞在药盒铜扣上。

宝玉站在门口，向屋里望了半日。那张案、书架、针线匣都还照旧，只是柜门已经重新合上，角上多了记号。一个上午以前，他若要哪一本书、哪件衣裳，只须开口叫人拿；这会子连自己衣柜里的一件夹袍，也只能“记着”。他走回桌边，想把那方旧砚装进去，手伸到一半又停住。

宝钗问：“你要拿什么？”宝玉道：“不拿了。”宝钗也不问。园中各处亦是如此。潇湘馆早已空下大半，仍要点门点物；蘅芜苑旧物也一一封存。栊翠庵那边原由府里送的米、炭、灯油，今日无人敢照旧开领。一个管事婆子赶去说明，说往后几日恐怕不能再按旧例送，要等外头重新定。妙玉听完，只问：“现有的米还有多少？”

小丫头道：“约莫够几日。”“炭呢？”“还有小半筐。”

妙玉道：“先省着烧。明日再问。”说完仍去看案上的经卷。那婆子本以为她要发作，等了片刻不见别话，只得退出来。走到门外还对同来的媳妇低声道：“往常这位最嫌咱们送来的东西沾手，如今倒先问有多少。”媳妇扯她一把，道：“你少说一句，自己还不知明日在那里呢。”两人便匆匆去了。

到了未时以后，外头准许第一批人移出。贾芸已叫两辆车候在街口，又找了三四个脚夫。门上先把老太太的铺盖、药包送出来，再是王夫人等人的小包。大件一概没有。脚夫见包裹比想的多，便嘟囔车装不下。贾芸把其中两床薄铺盖重新卷紧，道：“这不是搬家铺房，不过先住几日。你们把软的压上头，别把药包挤碎。”

一个脚夫道：“爷说得轻巧，这被卷这样大。”贾芸道：“嫌大你背一床。”那人笑道：“背便背，只另算脚钱。”贾芸道：“你倒一刻不忘钱。”“我们出来不为钱，难道为看热闹？”贾芸听了也笑：“好，等送到再算，少不了你的。”里头贾母由鸳鸯等扶出来时，到了二门竟停了一停。她住了这些年，平日出门自有轿、有随从、有一层层人先开路，今日却见门边站着不相识的人，自己家的小厮反退在一旁。鸳鸯低声道：“老太太，车就在外头。”

贾母只问：“凤丫头出来没有？”平儿在后头答：“奶奶坐后头一辆，马上来。”贾母点头，便不再看门，慢慢上车。王夫人、李纨等随后出来。凤姐本要自己走到车边，才下台阶便腿软，平儿和一个媳妇扶住。她还骂道：“扶稳些，别叫人以为我已经死了。”平儿道：“你若少说两句，倒更像活人。”

凤姐瞪她一眼，到底由她扶上了车。宝玉、宝钗出来得稍晚。麝月背着一只包袱，手里抱药盒，另一只手还提着一个不大的被卷。宝玉要接，麝月道：“你拿那包书罢，别回头又说我压坏了。”宝玉果然抱着一个小包，里头除了衣物，只夹着那本薄书。走到园门附近，他下意识往怡红院方向望。路口已经有人守着，不能再过去。麝月道：“二爷快些，后头还有人。”

宝玉走了两步，又问：“那件厚衣真不能拿？”麝月没好气道：“方才叫你多拿一件，你说一件衣裳罢了。”宝玉道：“我只是问问。”宝钗在旁道：“记在名目上，明日若准取再来。”三人便随众往外走。

二门到外门这一段路，平日从没有人觉得长。这一日却处处要停。前头有箱包要验，后头有人找不到自己的家人；一个小丫头哭着说自己的鞋包落在屋里，婆子骂她：“两双鞋值得你这会子回头？”小丫头道：“那双是我娘新做的。”婆子嘴上骂着，听了这句又不说了，只道：“明日若能进去再取。”

门边另有两个旧仆站着商量。其中一个说家里老娘病着，既然府里用不了这么多人，想趁今日请出去；另一个却道：“工钱还欠着两个月，走了找谁要？”两人争了几句，谁也拿不定主意。平儿经过听见，只说：“今日别堵门。要走要留，等明日有人管这个再说。”两人只得闪到一边。

到了外头，街上已经围了些闲人，见车出来便探头看。贾芸喝道：“让一让，车要转。”车夫也扬鞭嚷人。宝玉从门内出来时，听见有人低声说“这是宝二爷”，也有人问“怎么只带这点东西”。贾芸回头看了那几个人一眼，那些人便散开些。

借住的院子离荣府不算太远，是早先一处旧交情暂时腾出来的小院。地方不大，正屋三间，靠东有一间窄屋，院角搭着个小灶房，水井却在隔壁共用的一条夹道里。原先说只是暂住几日，谁也没有来得及细分房间。贾芸先赶过去看了一遍，叫人把正中一间收拾给贾母，东边较暖的一间给王夫人；凤姐身子不好，只得在靠东的窄屋先安一张床。李纨同贾兰暂挤西边，宝玉宝钗则在院后临时借出的一间小屋里安置。跟来的人一下少了大半，各处只有最贴身的几个留下。

麝月一进院，第一件事便是问水在那里，第二件事问灶在那里。管院子的老妇人指给她看，说：“井在夹道过去，白日好打，夜里门一关，得先叫我们开。”麝月道：“那热水呢？”老妇人道：“自己烧。灶小，两口锅挤不开。”麝月听了看宝钗一眼，道：“这倒好，往后连烧水也要排班。”

老妇人笑道：“姑娘住两日就熟了。这里原不是大宅门，一口灶够一家子用，你们人多，自然嫌窄。”说完便去帮着扫屋。宝钗没有多说，只先叫麝月把药盒放在干燥处，又将带来的衣物分开。宝玉站在门里，看这一间屋不过一张旧炕、一张方桌、两把椅子，窗纸还有一角补过。外头脚步声、说话声比怡红院近得多，隔壁凤姐咳一声，这边都听得见。

宝玉道：“我们今晚就住这里？”宝钗道：“不然住车上？”宝玉道：“我不过问一句。”麝月抱着铺盖进来，道：“二爷今日问的话都没有用。先帮我把这床褥子抬上去。”宝玉果真去抬，两人一人一头，谁知褥子卷得太紧，绳结偏卡住。麝月用牙咬不开，宝玉拿手乱扯，越扯越死。宝钗看了一会，道：“剪开罢。”

麝月道：“剪开明日怎么捆？”宝钗便从针线包里找出一根旧簪子，挑了几下，结竟松了。麝月笑道：“奶奶这会子连绳结也管。”宝钗道：“我不管，你两个预备抱着它睡？”三个人都笑了一下。笑声才起，隔壁便有人来借剪子，说凤姐那边包袱绳解不开。麝月把剪子递出去，叹道：“早知道一把剪子也该写在名目上多带两把。”

那人道：“你还有一把便是富户了。老太太那边正找针呢。”宝钗听见，便从针线包里分了一根针和一小轴线叫她带去。麝月道：“这才半日，咱们这匣子就要拆散了。”宝钗道：“记得谁拿了就是。”麝月道：“如今还能记得，过两日只怕连谁睡那里都忘了。”外头天色渐暗，饭却迟迟没有来。原来原府厨房不能照旧送，临时只叫人在附近买了些米和菜，由借住院的小灶熬粥。一个婆子忙得满头汗，端着盆进来道：“先给老太太送了，剩下的各屋分。菜只有两样，别问我那碟是谁的。”

麝月接过来看，笑道：“谁敢问你。今日有热的就好。”婆子道：“这才是明白人。方才还有个小丫头问有没有甜汤，我险些拿锅铲拍她。”宝玉听见，问：“谁要甜汤？”婆子道：“二爷别替她问了，她自己已经吓得躲起来。”说着端盆往别处去。宝钗给宝玉盛了半碗粥，又给麝月盛一碗。麝月忙道：“我待会儿同她们吃。”

宝钗道：“待会儿灶上只剩锅巴。先吃。”麝月这才坐在门边吃。宝玉吃了两口，听见院里有人搬箱子，便问：“还有人来？”宝钗道：“大约是老太太的东西。”一会儿平儿掀帘进来，手里拿着一张从旧账纸背面裁下来的小纸，道：“你们这里缺什么，若是今晚非用不可的告诉我。明日能不能回去取还不知道。”

那纸已经写了几行：老太太一栏记“厚褥已带，药包已带”；王夫人一栏写着“脚炉一只”；凤姐名下只记“药已带”；下面还有两三处空着。字写得快，有的只够自己认。

麝月立刻道：“二爷一件厚夹袍。”宝玉道：“不急。”麝月道：“方才路上是谁又问？”平儿一面写“厚夹袍一件”，一面道：“先记上。别的呢？”宝钗道：“暂时够了。倒是凤姐姐那边药齐不齐？”平儿道：“药带来了，靠枕只带一个，她嫌矮，正骂人。”隔壁像是听见似的，凤姐声音隐隐传来：“谁说我骂人？”

平儿忙扬声道：“没人说你，我说我自己。”

那边没再应。屋里几个人都忍住笑。平儿在“脚炉一只”后面点了一个小圈，把纸折起，道：“老太太那里眼前够，太太这只脚炉明日若准取，再一并报。你们这件厚袍也放在一处，省得各房另写。”话才说完，贾兰抱着一只枕头站在门口，问道：“这是不是二叔这里的？我们那边包袱里多出来一个，母亲叫我送来。”麝月接过一看，摇头道：“不是我们的。上头这块蓝布我没见过。”

贾兰道：“那又是谁的？”平儿笑道：“今日谁也别认枕头了，先拿到我那里。少了的来领，多了的也送来。再这样一屋屋问，到天亮还问不完。”贾兰答应着，又把枕头抱走。才到院里，李纨隔着窗叫他：“送个枕头也送半日，明早书还念不念了？”贾兰回道：“书都压在箱底了。”

李纨道：“那也先把你自己找回来。”院里几个忙着铺床的人听了，都笑了一声。贾兰也笑，抱着枕头跑了。宝钗问：“外头还有多少人没挪？”“还有几房人和下人留着候话。二爷他们也未必今晚都过来。贾芸还在外头跑，说车钱已经先给了一半，明早若再用还得去找。”

宝钗点头。平儿又匆匆走了。

夜深以后，小院渐渐静些，却不是荣府从前那种静。这里屋近人近，东屋翻身能听见床板响，院门一开，整院都知道有人出去。隔壁井边还有别人打水，木桶碰井栏的声音一阵阵传来。宝玉躺下许久没有睡，忽问：“麝月在那里？”外间麝月答道：“在这里呢。”“你那串钥匙还带着？”

“带着。”宝玉道：“如今也没有柜子给你开。”麝月沉默一会，道：“明日兴许还要回去取东西。”宝玉便不说了。

宝钗在旁也没说话，只伸手把被角往里掖了一点。过了半晌，外头有人轻轻敲门。麝月披衣起来，原来是王夫人那边来借热水。灶火已经快灭了，麝月只得同那丫头一道去添柴。宝玉听见她们在院里低声争论那两根柴该留到明早还是今晚烧完，忽然笑道：“从前何曾听见为两根柴争半日。”

宝钗道：“你若睡不着，明早自己去劈两根。”宝玉道：“我会劈么？”宝钗道：“不会便别管人家怎么争。”宝玉听了，又静下来。

次日天刚亮，院里比荣府醒得早。共用的井边已有两家人在打水，麝月排了半日才提回一桶，进门便抱怨：“才住一夜，我已经认得隔壁三个老婆子了。一个嫌我们水打得多，一个嫌我们的桶占地方，还有一个只问咱们几时搬走。”宝钗道：“那你怎么回？”麝月道：“我说我也想知道。”

宝玉笑了一声。正吃早饭，贾芸来了。他一夜几乎没怎么歇，眼下发青，却仍先把昨日车脚的账同平儿交代明白，才过来告诉宝玉：“旧府那边还在点账。园里旧年的一些单子也拿去问了。我在门上听见有人提了一句怡红院，说有几张领物的单子写着二叔这里。”宝玉道：“我那些账从来不管。”

贾芸道：“我知道。只是先来告诉二叔一声，省得后来真有人来问，忽然听见自己的名字倒慌。”宝钗道：“他们问的是账，知道的就说知道，不知道的说不知道。别自己先替纸上添话。”贾芸点头道：“我也是这个意思。”麝月从旁问：“今日能不能进去拿衣裳？”贾芸道：“门上说还得等名目。昨日带出来的先用着。若准取，自然会叫。”

麝月摸了摸腰间钥匙，道：“好容易我有钥匙了，偏又轮不到我开门。”贾芸听了笑道：“钥匙先留着。说不定哪日还用得上。”他说完又去凤姐那边回话。才走到院中，一个从旧府来的婆子也赶到，说园里栊翠庵那边问往后的米炭怎么办。平儿正从凤姐屋里出来，听了道：“这会子先顾住这边老人病人。庵里现有什么先用什么；等外头准了，再想法子送。”

婆子道：“妙玉姑娘只叫我来问一句，也没催。”平儿道：“那就回她，今日还没有准话。”婆子应着去了。凤姐隔窗叫平儿：“又是什么事？”平儿进屋道：“没什么，园里问米炭。”凤姐靠在枕上，道：“这才头一日，问的事倒比从前一个月还多。”平儿道：“奶奶昨儿还说少一句人家就多跑两趟，今日可不许再逞能。”

凤姐道：“我不说，你替我说。”平儿道：“我说便我说。你先把药吃了。”凤姐看一眼那碗药，嫌道：“才吃两口粥，又灌这个。”平儿道：“从前你催别人吃药，如今也轮着别人催你。”凤姐瞪她，却到底把碗接了。

到了晚间，旧府又送来话：次日仍要点看；以后若许回去取物，也须按报明的名目进去，不得自行开门开柜。平儿把话传到各屋。麝月正在灯下拆昨日匆忙卷来的衣包，里头一件旧袍压得全是褶，一条夹裤却不知是谁误塞进来的。她抖开看了半日，道：“这不是二爷的。”

宝钗接过来看，道：“像是兰哥儿那边的。明日叫人送过去。”麝月道：“咱们倒拿了人家的，他那边别也拿了咱们的。”宝玉道：“横竖都在这个院里，换回来就是。”麝月道：“如今你倒说得容易。昨日在自己屋里，一件衣裳少半日都要问三遍。”宝玉笑道：“那会子还在自己屋里呢。”

宝钗听见这句，抬头看了他一眼，像想起从前什么话，却没有说，只把衣包重新理开。几件衣服一件件摊在炕上，有新的，也有半旧的；其中一件青布夹衣袖口已经磨白，麝月道：“这个明儿得补一补，再不补就真破了。”宝钗把那件衣服放在一边，道：“先别收。明早有亮再看。”

麝月应了，又把袭人留下的药盒挪到桌角。腰间那串钥匙随着她弯身，轻轻碰在桌沿上，响了一声。麝月摸了摸腰间那串钥匙，仍旧塞回衣带里。院外有人喊了一句：“谁家的水桶还在井边？”麝月忙起身道：“又是我的。”提着灯便出去了。
