# 《第085回：文学复原剧情增厚卡》v1.0

**工作回目：** 丧仪渐歇深闺愈静　沉痼日侵弱质难支  
**软目标：** 6500—7500字  
**前80参照簇：** 第10、第45、第51、第57回

## 一、硬约束

黛玉沉痼加深；丧期余波仍在；不直接进入死亡日。

## 二、本回真正的戏剧问题

> 怎样写‘越来越坏’而不是重复写‘又病重了’？

## 三、三线结构

- **A线：** 黛玉恢复窗口缩短：吃、睡、药、说话耐力逐日下降。
- **B线：** 紫鹃雪雁的护理分工与疲惫；宝钗、宝玉来访的日常差异。
- **C线/闲笔：** 外头丧期生活渐静，园中仍有人过日子。

## 四、场景展开

1. 一日早起黛玉精神尚可，能说笑，甚至挑剔饭食。
2. 午后因一件小事耗神，恢复时间比从前长。
3. 紫鹃与雪雁对要不要再请医/换药有分歧。
4. 宝玉来时带一件外面的无关小事，黛玉仍会讥他。
5. 宝钗后来来，先关心饭药与丫头是否吃饭。
6. 夜里丧期外头更静，但小丫头仍要上夜、传水、收碗。
7. 隔日黛玉好转一小截，让读者不至于把85当86预告。
8. 回末以一次‘恢复不过来’收，给86真正的最后日留空间。

## 五、章法配置

重复中的变化；不写之写；病中仍有生活；顿挫。

## 六、L层

- **L1可直接增加：** 药、米汤、被褥、灯、夜间差使。
- **L2写后复审：** 一次医药意见分歧；宝钗与紫鹃护理关系。
- **L3禁止：** 明确绝症诊断、婚讯刺激、吐血暴死。

## 七、诗词/书信/文书接口

可埋86诗稿接口，但本回不必正式写诗。

## 八、验收条件

- 不少于5个完整场景；核心回按卡中实际场数执行；
- 至少2条线在主事件之外仍有自己的行动逻辑；
- 至少1处生活闲笔不是为了推进硬节点；
- 至少1处物件或动作能够在相邻回继续回声；
- 主要人物对白必须可区分身份与关系；
- 不修改R/P硬锁；
- 不以L3新增重大事故解决章法问题；
- 写成后即使删去回目，读者仍能从人物和生活读出本回中心。
