# 2. 链A / 链B差分

主表除“家庭权威”外基本共用。两条链的核心差异只放在87—90，避免为了比较而生成两套故事。

## 链A：贾母仍在且有实权

- 87：贾母保留最高家内认可/批准地位；贾政、王夫人承担具体操办。
- 88：袭人离位、麝月留下仍在贾母可知/可容许的家庭秩序内发生。
- 89：事败后贾母的“有实权”迅速受外部查抄和资源丧失限制。
- 90以后：即使贾母仍在，也不能再靠她恢复旧日物质秩序。

### 优点
- 主婚机制最省解释。
- 不需新增贾母死亡与新丧期。
- 87婚姻发生时家庭仍有足够制度性权威。

### 风险
- 必须解释为什么“有实权”的贾母在89之后也不能阻止家势崩塌；答案应来自外部司法/财产现实，而非人物突然无能。

---

## 链B：贾母仍在但实权下降

- 87：贾母保留名义最高认可；贾政、王夫人实际决定和操办权更强。
- 88：内宅角色调整更多由王夫人/宝钗一侧现实处理。
- 89：家败使“名义权威—实际资源”分离更加明显。
- 90以后：小家庭实际生活管理逐渐下沉到宝钗等人。

### 优点
- 更容易解释从大族权威到小家庭生存权威的连续过渡。
- 有利于90以后“宝钗真正管日子”的现实化。

### 风险
- 不能为了方便而无证提前削弱贾母；必须通过年龄、家败、资源收缩、行政查抄等可见条件来表现“实权下降”。

---

## 缺口L2：89→95贫困下降速度
目前只建立状态方向：
> 财产/居所不稳 → 缩减支出 → 典当/裁人 → 饭药炭不稳 → 稳定贫困

但具体：
- 现银能撑多久；
- 典当如何发生；
- 谁还能留下；
- 是否需要搬迁；
- 什么时候开始缺炭/缺药；

必须由 H05 核查。

---

## 缺口L3：薛家为什么不能长期托底
如果宝钗是薛家女儿，单说“娘家不管”过于便利；但写成薛家也整体覆亡又没有硬证。

因此 H06 必须解释：
- 援助为何只能一次性/阶段性/有限；
- 谁掌薛家资源；
- 为什么援助不能恢复旧日生活；
- 如何不把薛家写成突然绝情。

---

## 缺口L4：89后的具体居所
H04只证明“临时安置→低成本居所逐步下降”可运行，但没有证明具体住：
- 族房；
- 姻亲处；
- 租屋；
- 某处未入官房产。

本表故意不锁。H05/H06与场次设计后再择最低成本案。
