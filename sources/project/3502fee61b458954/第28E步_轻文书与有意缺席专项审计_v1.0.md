# 一、第85回｜病情小记、药方、旧诗纸

## 原状态

85已经有三类纸：

1. 紫鹃记睡眠、饭量、服药的小纸；
2. 大夫新旧药方；
3. 黛玉翻出的旧诗纸。

前两类完全成立。

问题出在第三类：

原稿在85已经完整演了一次：

> 找诗纸 → 嫌一字不好 → 拿笔 → 改一个字 → 紫鹃收砚。

而第86回经过28C-R以后，已经锁成：

> 黛玉病中翻残稿 → “怯”已勾 → 试“试” → 仍嫌不好 → 一格继续空着。

若两回连续都写“黛玉病中改一字”，86的S级场景会从“人物最后仍是诗人”下降为“上一回动作的重复”。

## 本轮修订

85改为：

> 找到诗纸 → 看一处字 → 说“这个字也不好” → 雪雁问哪里不好 → 黛玉说“若说得出来，早改了” → 紫鹃把砚推开 → 黛玉没有落笔。

并把“半首旧诗”降成“几行旧诗”。

因此85只做接口：

> **她仍会看诗、仍会嫌字。**

真正“落笔炼字”的动作只留给86。

### 锁定
- 病情小纸：KEEP；
- 药方：KEEP；
- 旧诗纸：KEEP AS INTERFACE；
- 新增完整黛玉诗：NO；
- 85再写改字动作：NO。

**结论：FIXED → PASS。**

# 四、第90回｜饭人数单、冬衣名目

90是轻文书回里文字数量最多的一回，但无需削减。

原因：
它不是把文字当文学件，而是让“搬离大宅以后的人数、饭量、铺盖、冬衣”都必须重新计算。

现有：
- 饭人数单；
- 冬衣急用名目；
- 补窗旧布的口头汇总；
- 平儿反复核人数；
- 结尾重新送取物名目。

最重要的是：
> 三十七与三十九对不上。

这让“人数单”不是完美管理工具，而会错、会漏、会因临时跑腿人和新搬来的孩子变化。

同时此回直接接89并导向91，因此这些纸有跨回功能。

## 本轮明确不新增
- 宝钗“治家”条规；
- 凤姐病中家政遗训；
- 搬迁总账；
- 贫困预算表；
- 宝钗劝世诗。

**结论：PASS / LOCK。**

# 五、第94回｜乡间口头小曲

当前只有两句：

> 线儿长，莫着忙；  
> 手一急，线先伤。

而且马上安排巧姐记成“断”，乡妇回答：

> “断也使得，本来就是哄手慢些的，哪有定词。”

这是最正确的地方。

因为它明确告诉读者：

> 这不是作者精心写好的“巧姐命运谶歌”，只是乡间干活时可以随口改的节拍话。

## 本轮明确禁止精修
不补：
- 后两句；
- 四句整歌；
- 押韵完善；
- “纺绩命运”暗示；
- 刘姥姥田园诗。

**这两句越不完整，越对。**

**结论：PASS / LOCK。**

三组文字互不重复：
- 家庭等待；

现状只写：

- 归期未定；
- 家中诸事烦湘云照管；

不能新增：

这比再写一封大信更有效。

# 七、第99回｜无告别文

99是本轮最重要的“有意缺席”。

现稿有：
- 主动归还借书；
- 买米纸、书签等旧纸；
- 95延续来的当票；
- 甄宝玉暂留的旧钞。

但是没有：
- 诀别信；
- 留给宝钗的书信；
- 留给麝月的字条；
- 出家偈；
- 遗诗；
- 题壁；
- 寺院度牒式展示。

这必须保持。

## 为什么

98还是一回高度“书札化”的小说：
- 拜帖；
- 题签；
- 转书札；
- 亲启封面。

到了99，最重要的人却什么都不留下。

这种缺席本身才有重量。

宝钗只能从：
- 还书；
- 不再问残本；
- 对明日饭食不表态；
- 整理书签；
- 不让她继续补旧衣

这些动作里慢慢认出他在离开。

如果宝玉留下一封写得极好的信，
这些前面几千字的“逐步退出”都会被那封信解释掉。

## 锁定
**99永久禁止在第28步加入诀别文字。**

若未来第29—31步总装有人觉得“这里少一篇东西”，
第一反应应当是：
> 正因为少，才成立。

**结论：PASS / HARD LOCK。**

# 十、总判断

第28E证明：

> **诗文生态成熟的标志，不是每个人物都有作品，而是作者知道什么时候不让人物写。**

前面的第28步主要是在恢复“文字社会”；
到这一轮，真正需要恢复的是：

> **文字社会里的沉默。**

尤其99：
一个人人都写帖、看单、收信、留题签的世界，
到了宝玉真正离开时，
偏偏没有留下一张纸。

这比补一篇名作更高。
