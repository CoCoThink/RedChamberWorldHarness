# 第28G-D3步｜《警幻情榜》首选体例规范 C★ v1.0

## 总纲

> **六十芳全录，评随证据。**

### 必须完整
- 正册12芳名；
- 副册12芳名；
- 又副12芳名；
- 三副12芳名；
- 四副12芳名。

### 不强制整齐
每人允许四种榜面状态：

1. **正评**：独立短评；
2. **联评**：两人/少数人物因文本关系共用一组评语，但芳名各列；
3. **点评**：只点一项可证行动，不冒充终身定义；
4. **录名**：只列芳讳，不强造情性。

# 分册规格

## 正册
**目标：12/12正评。**

理由：
- 叙事充分；
- 第五回已有完整判命；
- 末回应完成“命→情”的首尾镜像。

## 副册
**目标：以逐评为主。**

优先正评：
香菱、平儿、宝琴、岫烟、尤二姐、尤三姐、鸳鸯、紫鹃、夏金桂、龄官。

李纹、李绮：
- 先试独评；
- 若无法真正区分，改用联评；
- 不为了整齐硬拆。

## 又副
**目标：大多数正评。**

晴雯、袭人、麝月、小红、金钏、玉钏、司棋、莺儿、柳五儿、芳官均有较充分行为基础。

茜雪：
- 芳名必列；
- 因狱神庙关键正文已佚，允许点评/录名。

待书：
- 芳名可列；
- 若后续仍无独立情性，允许点评/录名。

## 三副
**正评、联评、点评混用。**

可优先逐评：
入画、春燕、彩云、藕官、蕊官、秋桐、宝珠。

重点测试：
- 雪雁；
- 翠缕；
- 绣橘；
- 文官；
- 瑞珠。

## 四副
**芳名为主体，评语从严。**

可重点评：
智能儿、四儿、佳蕙、彩霞、银蝶、豆官。

其余人物若无充分证据：
- 录名优于硬评。

菂官：
- 原则上不得把藕官之情写作她自己的情目。

# 宝玉

宝玉不计入五册六十芳。

五册全部卷毕后另列：

> **贾宝玉——情不情。**

这是总情，不是第六十一席。

---

# 榜面节奏

> **越往下，解释渐少；越往下，名字渐重。**

正册：
- 读人物之“情”。

副、又副：
- 看人物之间情法分叉。

三副：
- 看群体生活中各自一瞬。

四副：
- 看那些最容易失去名字的人重新得到名字。

---

# 禁止事项

- 禁止60条全部“情+一字”；
- 禁止把第五回判词换字重写；
- 禁止用“贤/烈/贞/妒/恶”当道德奖惩；
- 禁止因为人物难评就从芳名册删掉；
- 禁止因为要凑整齐而给菂官、茜雪等虚构失传人格；
- 禁止警幻逐条解释；
- 禁止榜后再由旁白总结“此即众生之情”。
