# 0. 第40步总原则

前80的社会密度，不来自“多写几个职业名词”，而来自：

> **每件事都真的有人办、要花钱、要搬东西、要等消息；  
> 每个人又只知道自己那一小段。**

因此后20以后不允许只写：

- “派人去请”；
- “命人买来”；
- “官府查抄”；
- “家中无钱”；
- “刘姥姥带走巧姐”；
- “袭人送来些东西”；
- “甄家送还宝玉”。

每一个此类句子都必须至少能回答四个问题：

1. **谁去办？**
2. **钱怎么来？**
3. **东西怎么来？**
4. **消息经过几只手？**

但第40步也不追求“全流程全写”。

原则是：

> **只把最能显人物、显阶级、显制度、显败落的那个环节写出来。**

# 1. 后20社会经济五阶段

## E0｜81—88：旧家体系尚能运行，但支出结构已变

特征：
- 医药、丧仪、远适、婚嫁仍能动用旧府资源；
- 仆役、针线、厨房、车船、请医等系统仍完整；
- 但凤姐病、元春死、黛玉死、探春远适、袭人出阁不断抽空人力。

钱的形态：
- 仍有“按例”“照旧”“从账上支”的余威；
- 但不宜再写无限现金。

职业侧重点：
- 医者；
- 针线；
- 车船；
- 婚嫁中介；
- 丧务人手；
- 家内管事。

---

## E1｜89—91：财产控制期

特征：
- 旧府不再是自由使用的家；
- 物仍在，但不能随便拿；
- 人仍在，但开始散；
- 现金仍有残余，但不再由一个中枢自由调拨。

钱的形态：
- 欠薪；
- 搬家车脚；
- 临时买米买菜；
- 人情借住；
- 准取旧物节省新购。

职业侧重点：
- 官差；
- 书办；
- 门上看守；
- 车脚；
- 旧仆；
- 债主/讨账人。

---

## E2｜92—94：制度与保护网崩塌期

特征：
- 宝玉被留质；
- 凤姐病亡；
- 巧姐保护网断裂；
- “有人肯跑腿”比“大额现金”更重要。

钱的形态：
- 送饭、递衣、脚费；
- 凤姐丧务小额开支；
- 巧姐转移路费；
- 旧亲之间有限帮忙。

职业侧重点：
- 狱卒、小役、书办；
- 丧务杂役；
- 媒人；
- 车脚；
- 乡村邻里。

---

## E3｜95：稳定真贫

特征：
- 不是“一时没钱”，而是支出长期小额化；
- 房、炭、米、药、衣都要取舍；
- 仆役极少，主仆边界在劳动层面缩短。

钱的形态：
- 典当；
- 小额借贷；
- 零买；
- 赊欠；
- 不赎当票。

职业侧重点：
- 房东/中间找房者；
- 当铺；
- 米铺；
- 炭贩；
- 邻妇；
- 小贩。

---

## E4｜96—99：贫困中有零散外援，但结构不逆转

特征：
- 袭人蒋玉菡可送米炭碎银；
- 旧人可帮找人、送信、指路；
- 但宝玉家庭仍是低成本小户生活。

钱的形态：
- 小额赠与；
- 礼物替代现金；
- 仍需量米、算炭、看赎期。

职业侧重点：
- 艺人；
- 抄书/书摊；
- 尼庵劳务；
- 寺院日常；
- 车脚、渡口、路人。

---

## E5｜100：名位回升，不等于家业回升

特征：
- 贾兰得官；
- 李纨因子得荣；
- 可以重新有礼务、冠服、贺客；
- 但旧府、旧庄地、旧仆役体系不能自动恢复。

钱的形态：
- 官身带来的新收入/礼仪压力；
- 亲友贺礼；
- 丧务；
- 新名位与旧贫寒并置。

职业侧重点：
- 报录/递信者；
- 裁缝/冠服制作；
- 厨役或临时帮工；
- 医者；
- 丧务；
- 文书/抄录。

# 2. 职业人物使用纪律

允许新增职业人，但不允许“工具人”。

每个新增职业人物至少有一项自己的现实：

- 正在赶下一家生意；
- 嫌钱少；
- 怕担责任；
- 记错话；
- 只认规矩不认人；
- 有自己的吃饭时间；
- 有自己的亲戚/徒弟；
- 借此多挣几文；
- 只愿帮到某一步；
- 对贾家并无特殊敬畏。

## 2.1 优先使用“重复出现的职业人”

比起一回一个新人，更建议少数职业人跨回变义：

- 贾芸：找房、跑腿、联络；
- 小红：问规则、传消息；
- 某熟识车脚/雇脚人：82/89/94不同阶层使用；
- 某旧医者/药铺：81/85—86/90—93不同病人接触；
- 某书办/看守：89—92形成官面连续性；
- 某米炭小贩：95—96让贫困有价格记忆；
- 某旧书摊/抄书人：98—99形成书物流。

重复人物的价值是：

> **同一个社会人在不同阶段对贾家的态度会变。**

### 人链
现有核心：

- 薛蟠；

建议补一名“家中惯办白事/杂事的婆子或旧仆妇”，只负责：
- 问衣裳；
- 问热水；
- 问暂厝/烧埋；
- 不发表感想。

### 钱链
按顺序表现：
1. 继续看病是否值得再花钱；
2. 死后第一笔支出；
3. 香菱身份决定后事规格不会高；
4. 薛蟠可能愿意说“该花就花”，但实际办理仍由薛姨妈/宝钗压住尺度。

### 物链
药材 → 药碗 → 净布/衣裳 → 灯油/热水 → 简单棺殓用品 → 诗稿匣。

> 诗稿必须晚于身体处理进入。

### 信息链
近身人先知病危  
→ 薛姨妈/宝钗判断  
→ 薛蟠/金桂房得知  
→ 外院再知死讯。

### 职业/社会接口
- 医者；
- 药铺/抓药人；
- 白事杂役。

### 第40步新增建议
只补“谁能真正把后事办起来”。

禁止：
- 新增大批吊客；
- 把香菱后事写成小姐级丧仪。

## 第89回｜抄没

### 第40步第一重点回

### 人链
必须至少分六种角色：
1. 主持查办者；
2. 书办/登记者；
3. 门口执行限制者；
4. 贾府管事；
5. 各房主子；
6. 仆役与搬运人。

可出现：
- 讨欠薪的旧仆；
- 想先走的下人；
- 来问账的债主；
- 找临时住处的贾芸。

### 钱链
不要写“所有钱立刻归零”。

应写：
- 账上钱受限；
- 手头零散钱尚有；
- 欠薪暴露；
- 搬家要另出车脚；
- 借住本身欠人情；
- 小灶重新买米菜。

### 物链
封识  
→ 账本  
→ 箱笼  
→ 允许随身衣被  
→ 锅/米/水桶  
→ 搬到小院。

### 信息链
官面话往往短  
→ 管事自己解释  
→ 各房误解/追问  
→ 仆役得到的又是第三版。

### 职业世界细化

#### 书办
不需奸诈。
他的基本性格可以只是：
- 怕漏项；
- 写字慢；
- 要人一件件说清。

#### 门上执行者
只认：
> 谁能进、谁不能出。

#### 搬运人/车脚
不关心贾府兴亡，只关心：
- 几趟；
- 哪件太重；
- 谁付钱。

#### 债主/讨账人
不要大群围门。
一两个“听见风声来问”的就足够。

### P-Lock
结尾水桶仍必须压倒宏大感。

# 10. 第40步结论

后20从这一刻起，不再允许出现“悬空大事”。

所谓“悬空大事”，就是：

> 有结果，没有办理它的人；  
> 有贫困，没有反复发生的小额交换；  
> 有婚丧，没有劳务；  
> 有狱案，没有狱中规则；  
> 有乡村，没有劳动与邻里；  
> 有寺庵，没有米油与香火；  
> 有书，没有借、抄、还；  
> 有名位，没有相应礼务和成本。

第40步冻结后的总原则是：

> **社会基础设施不是背景。  
> 它决定人物此刻究竟能做什么、做不起什么、必须求谁、必须等多久。**
