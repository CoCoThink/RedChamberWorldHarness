# 《81—100空间网络表》v1.0

**用途：** 第20步生活世界总表之二。  
**原则：** 空间不是布景，而是权限系统。每个空间都必须回答：
> 谁能进？谁能留？谁能拿东西？谁在门外等？饭、药、灯从哪里进来？

## 一、81—100的空间下降链

```text
薛家 / 荣府 / 大观园（仍有完整主仆系统）
        ↓
探春离开：车—江岸—船
        ↓
荣府被官面重新定义为“受控旧府”
        ↓
第一处借住院落（临时）
        ↓
监所 / 刘家乡居 / 小庵 / 尼庵 等分流空间
        ↓
第二处低成本住处（稳定贫居）
        ↓
宝玉转入城外寺院
        ↓
多年后的狭小旧居
        ↓
太虚 / 青埂峰外框
```

真正的“家败”不是一回发生，而是：
> 人物对空间的支配权不断减少。

## 二、文学复原的空间硬规则

1. **人物移动必须有路径。** 不再写“宝玉去看了一回”就瞬移。
2. **空间变小，人物摩擦必然变多。** 89以后住房压缩应自然增加听见、打扰、共用灶具等生活细节。
3. **同一空间要跨回记忆。** S09在95、96、98、99必须是同一个有记忆的贫居，不可每回重新生成。
4. **受控空间先写门。** 91旧府、92监所、97尼庵、99寺院都要先明确谁能进去。
5. **外框空间与现实空间换文体。** 100太虚/青埂峰不使用89—99的写实家务笔法。

## 三、下一阶段需要补画的四张“平面草图”

剧情增厚卡开始前，至少为以下空间做文字草图：

- S06第一处借住院落；
- S07监所/狱神庙；
- S08刘姥姥乡居；
- S09第二处低成本住处。

每张只需回答：
- 门；
- 两三个房间；
- 灶；
- 水；
- 谁住哪里；
- 谁从哪里进出。
