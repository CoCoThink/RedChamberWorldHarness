# 0.1 第42步统一施工规则

## 0.1 P-Lock不是“待润色项”
凡列入P-Lock的：
- 结尾；
- 小笑料；
- 物件；
- 日常动作；
- 信息差；
- 已成熟文化场；

后续重写默认**原功能原位置保护**。只有发现逻辑冲突才调整，不因为“还能写得更华丽”而覆盖。

## 0.2 新增内容统一分四级
- **L0｜不增**：只校字、接口、连续性。
- **L1｜轻嵌**：数句至一小段，不改变回型。
- **L2｜补桥**：补一个被压缩的形成过程或社会过程。
- **L3｜结构重做**：重排场次、交叉线或信息次序，但不改变硬结局。

## 0.3 诗文证据身份
每回必须区分：
- **A**：可确认存在的后文文本；
- **B**：可确认后文场景/语句/文本伏线；
- **C**：前80旧作后文兑现；
- **Q-X**：已审但不得承重；
- **G**：自由创作容器。

任何G层内容都不得在证据版写成“原稿事实”。

## 0.4 社会基础设施四链
重大事件至少能回答：
- **人链**：谁来办、谁能办、谁不办；
- **钱链**：谁出钱、钱够不够、谁先拿不到；
- **物链**：药、米、炭、布、车、书、棺、纸从哪里来；
- **信息链**：谁先知、谁后知、谁误解、谁只知一半。

## 0.5 宗教哲学七问
每回若出现宗教/梦/命运语言，必须标：
1. 制度宗教 / 民间信仰 / 人物精神 / 梦阈 / 外框；
2. 人物信不信；
3. 要不要钱、时间、劳动；
4. 有没有第二种解释；
5. 删掉后人物行为是否受损；
6. 是否替现实因果卸责；
7. 是否替作者把答案说完。
