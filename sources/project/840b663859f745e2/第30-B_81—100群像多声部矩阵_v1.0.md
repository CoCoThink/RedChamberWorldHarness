# 第30-B步｜81—100群像多声部矩阵 v1.0

## 判据

群像不是“出场人数多”，而是同一件事里至少存在两种以上不同的局部关切：

- 有人知道，有人不知道；
- 有人伤心，有人只顾饭衣药钱；
- 有人急，有人嫌麻烦；
- 有人替主人公担心，也有人根本不把主人公当中心；
- 次要人物有自己的钱、路、饭、工钱、规矩、面子、身体和时间。
