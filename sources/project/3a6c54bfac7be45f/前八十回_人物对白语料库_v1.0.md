## 对白施工的六条具体规则

1. **先定对谁说，再定说什么。** 同一句意思，宝钗对黛玉、对王夫人、对宝玉不应是同一种句法。
2. **允许语法不完满。** 前80大量真实对白靠省略、重复、半截话成立，不能全部修成书面完整句。
3. **笑不是情绪标签。** “笑道”常常是遮掩、顶嘴、转圜、讥刺，后20不能只在轻松时才笑。
4. **身份越近，话越不说全。** 贴身主仆、夫妻、姐妹之间尤其如此。
5. **下人不是同一种声音。** 平儿、小红、袭人、麝月、紫鹃、晴雯的“能干”完全不同。
6. **悲剧阶段也必须保留旧声口。** 黛玉病重仍能尖，凤姐病重仍能快，湘云悲时仍有爽利底色。

## 第86回直接调用

黛玉、紫鹃、宝钗、宝玉四人的对话不能都压成“少说话”的临终腔：

- 黛玉至少要有一处真正的俏/尖；
- 紫鹃至少要有一处主动判断和一处急话；
- 宝玉至少要有一段不知大限将至的日常废话；
- 宝钗应从吃饭、被角、外头事情之类具体处入手，不先谈生死。

**第19B对白语料库：PASS。**
