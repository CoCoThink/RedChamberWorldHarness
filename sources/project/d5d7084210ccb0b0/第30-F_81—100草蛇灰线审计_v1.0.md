# 三、三类灰线必须区分

## G1｜真正伏线
如：
- 金麒麟；
- 药盒；
- 厚袜；
- 当票；
- 甄家旧钞。

特点：
> 后一次出现时，读者会重新理解前一次。

## G2｜生活承载物
如：
- 针线匣；
- 小木碗；
- 旧毡。

它们不是伏笔，
而是因为人物一直在过日子，所以反复使用。

这种反而更重要：
> **不是每件东西都必须“有寓意”。**

## G3｜母题线
如：
- 女子旧稿；
- 门 / 门内外。

它们不是同一物件，
只能说结构回声，不能强认物理连续。

# 四、本轮唯一正文修订

第93回厚袜线。

原：

> “不是心疼袜子，是人家辛苦做的。”

改：

> **“不是心疼袜子。”**

随后：
> 麝月看他一眼，便不再笑。

理由：

动作已经写明：
- 宝玉不许重搓；
- 怕粗线洗开；
- 后面还持续穿用；
- 99麝月又由此想起带袜。

再把“是人家辛苦做的”说出来，
会把原本可以留在物件里的情，
重新翻译成人物说明。

改后：
> **半句比完整解释更像宝玉。**

# 六、最关键的反例：通灵玉

98玉归以后，
99没有再用玉触发宝玉撒手。

这是草蛇灰线审计中的正面结果：

> **真正成熟的伏线控制，也包括知道什么时候不再调用伏线。**

> 玉归 → 神示 → 悟道 → 出家

的机械传奇链。

当前没有。
