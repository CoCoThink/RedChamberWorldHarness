# 0. 本轮操作口径

为避免“硬字”与“硬事”再次混淆，本轮采用以下工作定义：

- **D0-SEEN**：批者明示见过稿件、誊清本、正文标目等，见稿行为本身是证言内容。
- **D1-ASSERT**：现存批语对未来文本/事件作明确断言或直接引述，但不以“我见某稿”的见稿过程为命题中心。
- **D2-INFER**：批者以“想、疑、未必”等方式推测。
- **D3-W2**：只有失传原本的单线转录，字面只能按“收到的转录”保存。

Literal Target继续严格分层：

- **NOVEL-EXACT**：有充分理由要求失稿正文/回目中原字成立；
- **NAME-EXACT**：作品名本身可锁；
- **SOURCE-EXACT**：只能要求证据台账准确保存批语/稿称原字，小说不必照抄；
- **SEM**：只锁事件、功能或结构语义；
- **BOUNDARY**：明确锁住“不得多推什么”；
- **NEG**：用于阻止已经发生过的错误硬化。

> 核心原则：**批语原字不自动等于小说原字；“某某一回”也不自动等于正式回目。**

# 3. 五个最重要的B层边界

## 3.1 只有三类字面可进入“小说逐字硬锁”

本轮审完后，真正达到 **NOVEL-EXACT / NAME-EXACT** 的高风险对象只有：

- 完整未来回目：`薛宝钗借词含讽谏　王熙凤知命强英雄`；
- 局部正文标目：`花袭人有始有终`；
- 作品名：`十独吟`（只锁题名）；
- 未来残语：`落叶萧萧，寒烟漠漠`；
- 未来人物话语：`好歹留着麝月`；
- 情榜评语：`宝玉情不情`、`黛玉情情`。

其中`十独吟`是 **NAME-EXACT**，不是要求某一回正文必须出现；位置属于R4-C。

## 3.2 “一回”不足以升为正式回目

`误窃`、`悬崖撒手`虽然都有“一回”，但角色仍是 **CHAPTER-CALL / T2候选**；`狱神庙慰宝玉`甚至只是批者曾见誊清稿时的稿件称呼。三者都只能 **SOURCE-EXACT + SEM**。

这一步是R4-B最重要的反硬化结果之一。

## 3.3 “警幻情榜”与“末回情榜”必须拆成两个对象

- **末回有情榜并具正/副/再副/三副/四副层级**：STRUCTURE / SEM，硬。
- **正式榜首就题作“警幻情榜”**：没有小说内题名见证，不硬。

因此`警幻情榜`四字只在证据层 **SOURCE-EXACT**，并承担“批者如何称呼这一系统”的功能。

## 3.4 W2只能保“收到的字”，不能保“原稿的字”

`对景悼颦儿`当前最多能说：

> 毛国瑶转录文本中有“先为对景悼颦儿作引”。

不能说：

> 原本必然精确写作这七字，且后文一定存在一个可独立承重的“对景悼颦儿”场景。

因此本轮把Literal Target进一步收紧为 **SOURCE-EXACT（received transcript）+ BOUNDARY**。

## 3.5 情状短语与未来残语不是同一种证据

- `落叶萧萧，寒烟漠漠`：批者明确引未来文字 → **NOVEL-EXACT**。
- `寒冬噎酸虀，雪夜围破毡`：批者说“后数十回……等处” → **SOURCE-EXACT + SEM**。

二者都“像文学句子”，但证据角色完全不同，今后不得因为文采形式相似而互相升级。
