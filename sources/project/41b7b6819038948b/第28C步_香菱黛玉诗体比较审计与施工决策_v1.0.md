**PASS。两人的笔下声口已经可以分开施工。**

# 三、为什么两人不能互写

## 3.1 香菱不能写成黛玉

若给香菱补一首：
- 满纸帘影；
- 自怜；
- 花魂；
- 问花；
- 复杂典故；
- 句句都像命运自况；

会失去她最重要的“认真学会”的路径。

香菱的成熟应该仍带着：
> **从实景中得诗。**

---

## 3.2 黛玉不能写成“高级香菱”

若86只补一首：
- 工稳七律；
- 景对景；
- 对仗漂亮；
- 无观看者；
- 无句势回旋；
- 无一点自我挑剔；

即使格律再好，也只是“会作诗的人”，不是黛玉。

# 四、前80证据形成的两条硬文学约束

## 4.1 香菱：真正的“完成”已经发生在第49回

第三稿被评为：
> “不但好，而且新巧有意趣。”

所以81不应再给她补一个“更高峰”。

否则会把第48—49回完整的学诗弧线削弱成：
> “那只是初级作品，真正名作在佚稿里。”

没有必要。

---

## 4.2 黛玉：诗才不需要靠临终绝唱证明

前80已经有：
- 海棠诗；
- 菊花诗；
- 《秋窗风雨夕》；
- 《桃花行》；
- 《唐多令》等。

她的诗人身份无需86再办一次“最后发表”。

86需要证明的是：

> **病到这一天，她看见旧稿仍会嫌一个字不好。**

这比新添一首“绝世遗篇”更高。

# 五、第81回施工判决

## 判决：**OLD TEXT REUSE / 不新增诗**

推荐把旧稿具体化为：

1. 第一张：改抹最多，可认出“玉镜”“冰盘”等旧词；
2. 第二张：较用力，香菱当年自以为好的稿；
3. 第三张：誊得较清楚；
4. 若必须露诗，只露成熟稿一联：
   > 一片砧敲千里白，半轮鸡唱五更残。
5. 宝钗收起，不作总评。

### 建议删除/改写
- “林姑娘亲笔改字”可降为“这页当年拿给林姑娘看过”；
- “诗若一眼便看尽……”改成具体旧批记忆；
- “半首未完的新诗”建议取消。

### 理由
第81回的余味应来自：
> **她曾经真正学会过诗。**
而不是：
> **她还有一首没写完的天才绝笔。**

# 六、第86回施工判决

## 判决：**FRAGMENT / 两句未定稿**

### 保留结构
- 诗稿夹掉出；
- 黛玉翻到；
- 嫌一个字；
- 改；
- 仍嫌不好；
- 夹回旧书。

### 不补
- 完整七律；
- 绝句；
- 长歌；
- 死亡主题。

### 下一轮唯一允许的新写作
为当前两句做 **A/B/C三个两句方案**。

只比较：
1. 像不像黛玉；
2. 是否真实可写于病中旧稿；
3. 是否不带绝命感；
4. 动词能否自然成为她修改的焦点。

# 七、格律审计策略

## 香菱81
若复用前80旧句：
- 不重新“修正”曹本原诗；
- 不为了今人近体规范擅改字；
- 原诗作为小说内既成文本处理。

## 黛玉86
因为只是残稿：
- 两句应基本符合七言诗节奏；
- 若设计为律诗中间联，须注意对仗；
- 但不需要先确定整首韵脚；
- 不应为了严格平仄把语气磨成死句。

核心仍是黛玉自己第48回教香菱的原则：

> **第一立意要紧，不以词害意。**

第86回的“意”不是死亡，
而是：
> 雨后新晴时，她隔着帘仍在看、仍在改。

# 八、意象配额

为了避免“后80古风词库化”，81和86分别限制：

## 81香菱
可用：
- 月；
- 砧；
- 鸡；
- 江；
- 笛；
- 楼；
- 栏。

但因为都是**旧稿回收**，正文中新写叙述不再额外堆“香魂、残月、孤灯”。

## 86黛玉
两句中最多使用以下组别中的2—3项：
- 院 / 帘 / 窗；
- 雨 / 晴；
- 苔 / 花 / 竹；
- 光 / 香 / 影。

禁把：
> 泪、魂、梦、愁、残、冷、瘦
一次塞入。

# 九、文学高度判断

“曹雪芹式”的高，不等于：
> 每一个将死之人都留一首压卷诗。

真正高的可能恰恰是：

### 香菱
年轻时费尽心力学会的那几张纸，
多年后从旧箱底重新翻出来。

### 黛玉
已经写过《葬花吟》《秋窗风雨夕》《桃花行》的人，
生命最后一天只是嫌一个普通动词“不好”。

这两个处理一“完成”、一“未完成”，彼此不重复。
