# 第30-D步｜81—100闲笔与冷笔逐回矩阵 v1.0

判据不是“有没有笑话”，而是：
> **每回能否找到一段严格说没有推进硬节点，删了却会少掉人物生活；悲事中是否仍有人只顾自己的饭、鞋、工钱、杯子、窗、钥匙。**

## 结论
- 20/20回都能找到不可删闲笔；
- 没有出现连续两回“只剩硬节点”的情况；
- 84—100没有连续数回无人说笑；
- 86、89、92、94、99、100等重悲回均有有效冷笔；
- 因此本轮不需要为了“补生活”新增任何场面。
