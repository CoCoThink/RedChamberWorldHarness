# 第31-D步｜语言词法与标点终校矩阵 v1.0

## 一、本轮原则

> **不做“古词替换运动”；只删真正现代化、工程化、抽象化的表述。**

特别避免两种误区：
- 看到“立刻、机会、普通”就误判为现代词；
- 为了“古”把自然白话全部换成文言。

本轮对照现稿与前80用语习惯后，只处理确有明显现代句法或工程痕迹的项目。

## 三、最重要的四类问题


### D1｜工程残影
发现唯一一处正文直接写：
> `想起89那日……`

这是施工阶段的回次索引漏进小说正文。
已改：
> `想起前番……`

这是本轮最必须修的一处。

### D2｜现代过程动词
现稿有9处`继续`、3处`开始`。
它们并非每一处都“不合法”，但整体语感明显比前80叙述系统偏现代。
本轮全部改为具体动作：
- 又低头理线；
- 仍要点看；
- 补抄完；
- 往下看；
- 又动笔；
- 晕起来；
- 渐渐有人走动。

### D3｜现代抽象名词
清除：
- `筋骨问题`；
- `实际官身`；
- `具体交接`；
- `内容`；
- `反应过来`；
- `不正常的红`。

原则：
> **能写人眼前所见所做，就不写抽象类别词。**

### D4｜现代副词化结构
处理：
- `习惯性舀米` → `照旧舀米`；
- `习惯地伸手` → `照旧伸手`；
- `直接倒进` → `顺手倒进`；
- `简单挽着` → `草草挽着`。
