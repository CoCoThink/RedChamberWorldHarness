# 《正文时代语汇与称谓表》v0.1

**性质：** 八十回后正文施工用语转换表  
**依据：** 前八十回正文声口、当前H01—H07机制结论、81—100场次卡。  
**目的：** 把工作台术语转换成小说中人物能听懂、能说出口、能看见的表达。  
**警告：** 本表不是“清代词典”；没有必要精确到某一官署名称的地方，一律不为了古雅而硬造专名。

---

# 一、总规则

## 工作台术语可以存在于：
- 场次卡；
- 回链日志；
- 审计；
- 决策台账。

## 小说正文尽量不用：
- 状态；
- 机制；
- 资源；
- 风险；
- 现金流；
- 法律身份；
- 价值排序；
- 信息差；
- 心理创伤；
- 功能递换；
- 长期依赖；
- 执行链。

正文要写：
> 人在做什么，东西在哪里，钱还剩多少，谁能作主，谁进得去，谁见不着。

# 二、司法与官事

| 工作台词 | 正文优先表达 | 备注 |
|---|---|---|
| 待质 | “叫去问话”“暂且留下等对质”“还要等一等问明白” | 不必人物自己说“待质” |
| 暂押 / 羁押 | “先收下”“留在这里”“一时不得回去” | 叙述层可谨慎用“收禁” |
| 释放 | “放出来”“准他回去”“叫家里领回” | 不写现代“撤销羁押” |
| 传讯 | “叫人来传”“叫宝玉过去问话”“有人来传话” | 具体文书名不锁 |
| 对质 | “叫来当面问”“两边话对一对” | 官面叙述可稍正式 |
| 探视 | “进去见一面”“托人带东西进去”“只许隔着见” | 按H01边界 |
| 送物 | “送衣裳饭食”“递进去”“托守门的转交” | 小红重点 |
| 案件牵连 | “那件事问到他身上”“账上/口供里提到他” | 不讲“法律接口” |
| 无个人重责 | “问明白与他无大干系”“没有再留下他的缘故” | 不替官府总结法理 |
| 大案仍在 | “家里的事还没完”“东西仍封着”“官司并未结” | 释放≠翻案 |

### 第92回称谓
- 官面人物若无硬证：`官差`、`书办/书吏`、`守门人`、`管监的人`等低专名表达；
- 不随意创造某“某司某堂某狱官”；
- 宝玉对官面人物多用敬称/含混称呼，少让他准确报职衔。

# 三、查抄、居所与财产

| 工作台词 | 正文写法 |
|---|---|
| 财产支配权下降 | “这间不能进”“那箱先封着”“这件不许拿” |

| 封存 | “贴了封条”“叫先别动” |

- “所有权”
- “居住权”
- “系统性清退”

# 四、钱、饭、药、炭

| 工作台词 | 正文优先写法 |
|---|---|
| 现金流断裂 | “手里现钱不够”“账上没得支”“银子一时接不上” |
| 短期周转 | “先典了这件应几日”“先挪这几两” |
| 持续贫困 | 不说；让饭药炭连续缩水 |
| 有援助但不逆转 | “这几样够吃几日”“先把药钱顶过去” |
| 药物短缺 | “还缺一味”“药铺要现钱”“先抓一半” |
| 炭不足 | “这盆省着些”“夜里早封火” |
| 饭食下降 | “只这一碟”“粥多饭少”“酸齑就饭” |
| 衣物不足 | “翻面再做”“旧棉添补”“拆这件补那件” |
| 典当 | “拿去当铺”“先典几日”“赎不赎以后再说” |

### 宝钗说钱的方式
宜说：
> “这个先别动，药铺那里还等着。”
> “炭少添些，明早还要用。”

不宜说：
> “我们现在必须控制预算。”

# 五、婚姻、妻婢与家内权威

## 宝玉—宝钗

87以后：
- 叙述层可称“宝钗”“宝玉”；
- 仆人对宝钗称谓应按场景自然变化，可用“奶奶”等家内称呼，但正式正文开工时需在具体场景统一，不在本表先锁唯一称法；
- 宝玉与宝钗私人对白不必频繁互称“妻”“夫”。

### 禁止
现代对白：
- “我们的婚姻”
- “夫妻关系”
- “我尊重你的选择”
- “你需要空间”

应通过：
- 睡处；
- 饭药；
- 进出；
- 谁替谁收衣；
- 谁问“还回来么”。

---

## 贾母败后

当前O09-JM1：
- 仍可称“老太太”“老祖宗”（视说话人）；
- 89后她仍有名义尊位，但不再事事发令。

正文不要说：
> “老太太已经失去行政权。”

只写：
- 人先去回她；
- 她点头；
- 具体搬东西仍是别人办。

# 六、亲属与巧姐线

## 王仁
可用：
- “舅舅”
- “娘舅家”
- “王家那边”

不让人物自己说“狠舅”。

## 刘姥姥
说：
- “先到我们那里住些日子”
- “乡下虽粗，饭总有一口”

不说：
- “先脱离危险环境”
- “亲族有经济动机”

## 平儿
她的角色通过：
- 听；
- 问；
- 收；
- 回；
- 交给长辈；
表现，不自称“我来安排”。

# 七、病与身体

## 不优先使用
- 慢性病恶化；
- 病理性；
- 心肺；
- 贫血；
- 应激；
- 心理状态。

## 优先
- 咳；
- 喘；
- 夜里睡不稳；
- 一顿只吃几口；
- 药喝不下；
- 手冷；
- 发热；
- 身子沉；
- 走几步要歇；
- 帕子上有泪/已经无泪。

### 黛玉
“泪尽”不写：
> “她的情绪已经枯竭。”

写：
> 眼里有涩意，却再没有泪下来。

# 九、出家

## 惜春
可写：
- 剃度；
- 缁衣；
- 入庵；
- 留下。

不必锁：
- 正式戒名；
- 受戒层级；
- 寺庵专名。

## 宝玉
99只需证明：
- 离家；
- 数日后已剃发；
- 随僧众生活；
- 明确不回。

不必写：
- 度牒细节；
- 完整受戒法律手续；
- 高僧传法；
- 神秘接引。

# 十、情榜与外框

可用：
- 芳讳；
- 正、副、再副等层级；
- 情榜；
- 警幻；
- 石归本质。

禁止人物在现实层说：
- “我的判词应验了”
- “我属于副册”
- “他是情不情”

情榜评语只按专项证据矩阵写。

# 十一、各人物常用称谓提醒

| 说话人 | 对象 | 正文优先称谓方向 |
|---|---|---|
| 宝玉 | 贾母 | 老太太 / 老祖宗（按场景） |
| 宝玉 | 宝钗 | 宝姐姐（婚后是否继续使用须按场景审）/名字省略 | 
| 宝钗 | 宝玉 | 宝兄弟等旧称在婚后需谨慎；私人场景可多省称谓 |
| 袭人/麝月 | 宝玉 | 二爷等旧家内称谓可保留 |
| 平儿 | 凤姐 | 奶奶 |
| 平儿 | 巧姐 | 巧姐儿/姑娘（按年龄与家内习惯） |
| 刘姥姥 | 贾母 | 老太太 |
| 刘姥姥 | 凤姐 | 姑奶奶/二奶奶等需按原有关系场景核实 |
| 贾芸 | 宝玉 | 叔叔等旧有亲族称谓 |
| 小红 | 宝玉 | 二爷 |
| 官差 | 宝玉 | 公子/姓名/叫人等不宜统一，正文时按场景定 |

**原则：** 不为了“古味”强行每句带称谓。  
前八十回很多连续对白根本不重复叫人。

# 十二、分析语→正文语速查

| 分析语 | 正文不要说 | 可以写成 |
|---|---|---|
| 资源不足 | “资源不足” | 米只剩几升、炭只够两日 |
| 角色功能 | “她承担照料功能” | 她把药接过去、夜里仍守着 |
| 风险 | “有风险” | 这时候送去怕再接不回来 |
| 信息准确 | “确认信息” | 先问清谁说的、什么时候来的 |
| 身份下降 | “阶层下降” | 从前坐车，如今雇车/步行 |
| 权威真空 | “权威真空” | 人人都来问，没人肯作主 |
| 现金流 | “现金流” | 账上支不出、当铺的钱还没到 |
| 持续贫困 | “持续贫困” | 第二个冬天仍旧缺炭缺药 |
| 婚姻真实化 | “夫妻关系建立” | 同屋、同桌、同一笔家用 |
| 不可箴 | “价值观无法改变” | 听懂了，仍照自己的意思做 |

# 十三、第92回专用禁词

正式正文v0.1中先主动搜索并删除以下词：
- 司法程序
- 待质状态
- 法律身份
- 核验
- 信息渠道
- 物流
- 风险
- 资源
- 权力
- 系统
- 机制
- 流程
- 证据链

如果叙述确实需要表达这些意思，先改成动作。
