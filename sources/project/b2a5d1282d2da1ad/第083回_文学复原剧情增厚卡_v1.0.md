# 《第083回：文学复原剧情增厚卡》v1.0

**工作回目：** 若兰射圃佩金麒麟　湘云闻讯问旧麒麟  
**软目标：** 5500—6500字  
**前80参照簇：** 第24、第31、第40、第62回

## 一、硬约束

卫若兰射圃佩同一大金麒麟；湘云线进入现实婚缘。

## 二、本回真正的戏剧问题

> 怎样让‘金麒麟’先是一件年轻人身上的玩物，后来才显出命运重量？

## 三、三线结构

- **A线：** 城外射圃中卫若兰通过行为先立人，再偶露麒麟。
- **B线：** 宝玉与射圃中一群少年互动，不是专程来认伏笔。
- **C线/闲笔：** 回府后袭人/宝钗/湘云围绕射箭闲谈，婚事信息自然冒出。

## 四、场景展开

1. 宝玉随一群相熟子弟出城，先写路上玩笑与谁射得好。
2. 卫若兰出场先以射艺、性情、与同伴笑骂立住。
3. 中途一场小输赢或弓具故障，让宝玉注意他。
4. 衣襟一动露麒麟，宝玉才觉得眼熟；认物不超过整个射圃场的十分之一。
5. 回程众人仍谈射箭，宝玉把麒麟放在心里，不立刻总结。
6. 数日后湘云来，袭人先从卫家婚事一句轻话引出若兰。
7. 宝玉提麒麟，湘云表面打岔，实则多问一处细节。
8. 宝钗/袭人把话岔开，回末不作命运预言。

## 五、章法配置

草蛇灰线；随机跳脱；群像先于物件；背面傅粉。

## 六、L层

- **L1可直接增加：** 弓、箭、马、衣带、茶水、少年笑闹。
- **L2写后复审：** 射圃小输赢；湘云的欲问还休。
- **L3禁止：** 麒麟转手来历解释、婚礼锁定、白首双星自我解释。

## 七、诗词/书信/文书接口

无新增诗词。

## 八、验收条件

- 不少于5个完整场景；核心回按卡中实际场数执行；
- 至少2条线在主事件之外仍有自己的行动逻辑；
- 至少1处生活闲笔不是为了推进硬节点；
- 至少1处物件或动作能够在相邻回继续回声；
- 主要人物对白必须可区分身份与关系；
- 不修改R/P硬锁；
- 不以L3新增重大事故解决章法问题；
- 写成后即使删去回目，读者仍能从人物和生活读出本回中心。
