# 2. 末回情榜应怎样锁

强锁：

1. **末回有情榜系统；**
2. 有正、副、再副、三副、四副芳讳层级；
3. `宝玉情不情`
4. `黛玉情情`

不能锁：

- 榜首正式题名一定是四字`警幻情榜`；
- 一定重开五本册子；
- 每层必十二人；
- 一定60人；
- 大多数人物必须有“情X”评语。

所以旧：

> `VL-012 警幻情榜｜N-EXACT｜末回榜名硬锁`

正式废止。

新：

> `VL-012｜批语以“警幻情榜”称末回情榜系统｜SOURCE-EXACT + SEM`

强锁：

不锁：

- 一定第85；
