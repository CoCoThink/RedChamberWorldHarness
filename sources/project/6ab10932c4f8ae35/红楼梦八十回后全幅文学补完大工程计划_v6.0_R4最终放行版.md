# 0. 工程目标

本工程不证明存在唯一可还原的八十回后原稿，而是在前80正文、脂批、批者见稿信息、早期转录材料和必要历史机制所允许的边界内，建立一个：

- 不反硬证；
- 不把弱证写硬；
- 不把事件证据冒充回目证据；
- 不把批语原字机械回灌成小说原字；
- 不让正文中的C方案反过来成为证据；
- 社会、身体、礼俗、文化、诗文、宗教与章法能够互相咬合；
- 在证据缺失处仍保留含混、冷笔、闲笔与多义性

的81—100文学补完体系。

总原则保持不变：

> **证据是地板，不是天花板。**  
> **硬事不可反，硬字不可乱认；开放处尽可写，证据角色不可偷换。**  
> **写进正文不等于写成史实，更不等于写成原稿。**
