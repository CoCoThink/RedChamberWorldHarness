## 每回最低章法配置

文学复原稿每回在剧情增厚卡中至少明确：

- 1种**结构转折技法**：顿挫 / 横云断山 / 接笔；
- 1种**群像或侧写技法**：不写之写 / 背面傅粉 / 同事件变奏；
- 1种**长线技法**：草蛇灰线 / 物件带路 / 隔回回收；
- 若有诗文，再明确**宾主关系**。

不是要求把术语写进正文，而是要求写作者知道：
> 这一回为什么不能从A顺写到B再顺写到C。

## 反面判定

出现以下情况，即判“章法仍是梗概”：

1. 每场都只推进主线；
2. 所有人知道同样的信息；
3. 物件只出现一次；
4. 主事件一结束本回立即结束；
5. 诗文一出现所有人只负责称赞；
6. 每个悲剧都以“沉默/流泪/不言语”同构收束。

**第19E结论：PASS。**
