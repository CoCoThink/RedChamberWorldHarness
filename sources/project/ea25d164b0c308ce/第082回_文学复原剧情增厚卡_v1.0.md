# 《第082回：文学复原剧情增厚卡》v1.0

**工作回目：** 敏探春整装辞骨肉　一江风送故园渐遥  
**软目标：** 6500—7500字  
**前80参照簇：** 第37、第55、第56、第62、第74回

## 一、硬约束

探春远适，且早于家败；夫家、地点、政治性质不锁。

## 二、本回真正的戏剧问题

> 最会管理家务的人，在真正离开这个家时，会怎样处理那些自己再也管不到的事？

## 三、三线结构

- **A线：** 探春整箱、交割、辞别、出二门、登船。
- **B线：** 赵姨娘、贾环、王夫人、贾母、姐妹对远适有完全不同的反应。
- **C线/闲笔：** 侍书、小丫头、车夫、码头人与行李构成真实迁徙。

## 四、场景展开

1. 秋爽斋清箱笼：探春先分‘带走/留下/送人’，仍以办事开始。
2. 赵姨娘来闹或哭，不写大冲突，重点是说错话、想带东西、又舍不得女儿。
3. 贾环来得尴尬，探春给他一两件实际嘱咐，不作姐弟和解大戏。
4. 王夫人/贾母分别来或召见；长辈话里既有体面又有真实舍不得。
5. 姐妹送到二门前，真正分手发生在空间门槛上。
6. 车内/江岸继续写箱笼、侍书晕船、行李清点，避免‘一登船即终局’。
7. 夜泊后探春第一次离开贾府规矩，自行重整小小生活秩序。
8. 回末预留家书接口。

## 五、章法配置

空间递降；同事多角色变奏；办事掩情；顿挫。

## 六、L层

- **L1可直接增加：** 箱笼、衣物、车轿、船舱、晕船、食盒。
- **L2写后复审：** 赵姨娘/贾环短戏；家书接口。
- **L3禁止：** 和亲、政治任务、夫家大篇幅、途中奇遇。

## 七、诗词/书信/文书接口

不写临别诗；可准备后续家书。

## 八、验收条件

- 不少于5个完整场景；核心回按卡中实际场数执行；
- 至少2条线在主事件之外仍有自己的行动逻辑；
- 至少1处生活闲笔不是为了推进硬节点；
- 至少1处物件或动作能够在相邻回继续回声；
- 主要人物对白必须可区分身份与关系；
- 不修改R/P硬锁；
- 不以L3新增重大事故解决章法问题；
- 写成后即使删去回目，读者仍能从人物和生活读出本回中心。
