# 第30-C步｜81—100人物声音去署名测试矩阵 v1.0

## 方法

不是检查“台词像不像古人”，而是把说话人名字遮掉后，测试能否凭以下特征辨认：

- 句子长短；
- 是否爱反问；
- 是先说情还是先说事；
- 是否把抽象问题落到衣、饭、钱、门、药、路；
- 是否爱讥诮；
- 是否说半句；
- 对上、对下、对同辈时有没有换口气；
- 同一人物败前/败后声音是否仍是同一个人，而不是统一成“克制短句”。

评分：
- `A`：去署名仍高度可辨；
- `B`：基本可辨，少数泛化句；
- `C`：明显互换风险，需要修；
- `D`：人物声音失守。
