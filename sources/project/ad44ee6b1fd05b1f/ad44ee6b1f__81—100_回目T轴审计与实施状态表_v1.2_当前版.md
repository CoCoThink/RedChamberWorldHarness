# 0. T轴定义

| T级 | 定义 |
|---|---|
| **T0** | 完整未来回目文字有直接强见证 |
| **T1** | 明说“正文标目曰”，但只保存局部标目 |
| **T2** | 稿名/稿件称呼/批者称“某某一回”；具有标题相关性但不能证明正式回目 |
| **T2-W2** | 只有靖藏等弱见证中的回称 |
| **T3** | 纯事件、场景、残语、未来事实；**没有正式回目证明力** |
| **TG** | 本工程生成的工作回目 |

# 1. 关键源证裁定

## T0｜第21回脂批的后回对举
批语：

> 此曰“娇嗔箴宝玉”“软语救贾琏”，后曰“薛宝钗借词含讽谏，王熙凤知命强英雄”。

其句法明确把本回两半与“后曰”的两半对举。

因此：
> `薛宝钗借词含讽谏　王熙凤知命强英雄` = **T0**

但：
> “这是第90回”仍只是当前百回模型的PC安置。

## T1｜袭人
批语明说：

> “袭人正文标目曰‘花袭人有始有终’。”

因此：
> `花袭人有始有终` = **T1**

它不是完整双联。

## T2｜狱神庙慰宝玉
同一条批语写：

> “余只见有一次誊清时，与‘狱神庙慰宝玉’等五六稿……”

这里没有第二次说“正文标目曰”。

所以：
> `狱神庙慰宝玉` = **DRAFT-LABEL / T2**

## T2｜悬崖撒手
批语：

> “故后文方有‘悬崖撒手’一回。”

说明这是批者用来称呼一个后回的短语。

所以：
> `悬崖撒手` = **CHAPTER-CALL / T2**

仍不能推出完整回目为“贾宝玉悬崖撒手去……”。

## T3｜三个最典型误升格
- `凤姐扫雪拾玉`：原文“这便是……之处”
- `寒冬噎酸虀，雪夜围破毡`：原文“后数十回……等处”
- `甄宝玉送玉`：点戏批“伏甄宝玉送玉”

都只属于：
> **EVENT / SCENE / T3**
