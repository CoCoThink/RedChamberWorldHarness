# 第28D-T步｜现实文书群总验收与跨回一致性审计 v1.0

## 总判定

**PASS WITH TWO FIXES → FIXED → PASS。**

第28D现实文书系统可以锁定。

本轮发现的两处真实连续性问题已经定点修复：

1. **第93回**：凤姐正文死于“酉初”，报丧帖原写“酉后”；同时后文又写“帖子等贾琏回来再定”，与贾琏当时仍在场、近亲素帖已经开始书写冲突。现改为：
   - “本日酉初病故”；
   - “远处的帖子叫明日再定”。

2. **第98→99回**：98首访时原写甄家“两册书已经包回”，但后文又说甄宝玉有一册留在宝玉处，下回自取；99更明确承接“甄宝玉下回要取的那册书”。现改为：
   - 甄宝玉首访时只带回另一册；
   - 用来比字的一册旧钞明确暂留宝玉处；
   - 次日继续比字后，米数纸夹入该旧钞；
   - 99“甄宝玉下回要取的那册书”因此有明确前因。

另外，98书札包外签写“回帖三封、转书札二封”，错包内容同步改成明确“五封书札”，不再写“四五封”。

# 一、84—93纸张称谓审计

## 1. 家内文字

84—90使用：
- 饭单；
- 旧例单；
- 小纸；
- 人数单；
- 急用名目；
- 取物名目。

这些称呼不是互相冲突，而是按用途自然变化。

其中“名目”主要出现在：
> 要向旧府报什么、准取什么。

“单/单子”主要用于：
> 厨房、针线、人数、旧日领物等已有条目。

“小纸”主要用于：
> 临时传递、短时办事。

这三类用法目前可以区分，不需要统一成一个术语。

## 2. 官面文字

91—92使用：
- 失物纸；
- 园中旧单 / 收领单；
- 传话折纸；
- 到名窄纸；
- 别人供词；
- 送物窄条。

官面并没有突然出现一套长篇制度术语，而仍从人物实际看见的纸张写起。

**结论：PASS。**

# 七、文书密度审计

## 84—90：中密度
- 84文书略多，但因元春死后事务骤增，合理；
- 85—88并未继续大篇文书化；
- 89再次升高，符合抄没核心回；
- 90作为迁居后的家务核算过桥。

没有出现“连续七回都像档案汇编”的问题。

## 91—96：高密度
这是计划中原本就应当最高的一段：
- 91认旧；
- 92问讯/送物；
- 93药方/丧帖；
- 95当票；
- 96湘云长信。

但文体彼此不同：
- 官面；
- 家务；
- 商业票据；
- 私人长信。

所以“文字多”并未变成“同一种纸”。

## 97—99：主动降密
- 97只有短札、庵中小账；
- 98短暂回升为书札回；
- 99刻意没有告别信、偈、遗诗。

尤其99的“无文本”现在更有力量，因为前面读者已经习惯人人生活在纸张中。

**结论：密度曲线符合第28步设计，不需删大块。**

# 八、人物识字/经手行为审计

目前不同人物对纸的关系仍可区分：

- **凤姐**：看最要紧的一项，立刻决定谁去办；
- **平儿**：写、汇总、保存、重新核数；
- **麝月**：关心纸上的东西到底能不能拿、能不能穿、有没有被退；
- **宝钗**：把票据收好、算日子、避免拆别人信；
- **宝玉**：认得字，却常不知道纸背后的办事系统；
- **小红**：把行动步骤压进极短清单；
- **李纨**：把报丧帖压到只够通知；
- **甄宝玉**：把书札当来往杂务，不把它神秘化。

没有出现“所有人一见文书都像现代项目经理”的同声问题。

**结论：PASS。**
