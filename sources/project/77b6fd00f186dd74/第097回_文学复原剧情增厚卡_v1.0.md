# 《第097回：文学复原剧情增厚卡》v1.0

**工作回目：** 史湘云独膳收双箸　妙玉入尘惜春落发  
**软目标：** 8000—9000字  
**前80参照簇：** 第45、第74、第76、第77回

## 一、硬约束

卫湘采用长期生离但原因开放；妙玉失独立与被迫俗务；惜春正式为尼。

## 二、本回真正的戏剧问题

> 怎样让三个女子走向不同的‘离世/离家’方式，而不读成三个判词条目？

## 三、三线结构

- **A线：** 湘云：共同生活被抽空，生活物件仍按两个人旧习摆。
- **B线：** 妙玉：仍嫌俗，却越来越没有拒绝俗务的资本。
- **C线/闲笔：** 惜春：主动把‘不回去’变成一个现实选择。

## 四、场景展开

1. 先湘云家中：婆子仍摆两副碗筷，湘云只叫收一副。
2. 换季晒衣，若兰衣物/金麒麟出现；湘云不哭，只处理。
3. 收到/写出一封更短的信，回来日期再次推迟，原因仍不明。
4. 转妙玉：小庵日常先写共食、米油、房间，不马上去俗家。
5. 住持通知明日佛事，妙玉拒一层，住持以米油/已应人家压回去。
6. 俗家佛事现场：家人催、问何时完、器物并不合她意，写她失自主。
7. 回庵后她换衣/洗手/收经，仍想维持洁净秩序。
8. 转惜春：宝玉得知她正式留尼庵，去看。
9. 惜春短谈，宝玉劝不动；老尼只做日常添灯，不作导师。
10. 三线最后不并成总结；回末落惜春翻经，前两线留在读者心里。

## 五、章法配置

三线三调；空位侧写；被迫应俗 vs 主动断返；不作总评。

## 六、L层

- **L1可直接增加：** 双碗筷、衣箱、米油、经卷、灰衣、灯油。
- **L2写后复审：** 湘云短信；俗家佛事细节。
- **L3禁止：** 若兰死亡、瓜州受辱、绑架卖身、神僧点化。

## 七、诗词/书信/文书接口

可有信札，不新作《乐中悲》续词。

## 八、验收条件

- 不少于5个完整场景；核心回按卡中实际场数执行；
- 至少2条线在主事件之外仍有自己的行动逻辑；
- 至少1处生活闲笔不是为了推进硬节点；
- 至少1处物件或动作能够在相邻回继续回声；
- 主要人物对白必须可区分身份与关系；
- 不修改R/P硬锁；
- 不以L3新增重大事故解决章法问题；
- 写成后即使删去回目，读者仍能从人物和生活读出本回中心。
