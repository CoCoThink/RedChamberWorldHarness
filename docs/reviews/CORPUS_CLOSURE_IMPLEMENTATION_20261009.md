完整候选有12,241个片段、624,776个 MAIN_TEXT 字符。每个片段都保留原件与确定性提取中的有序 Unicode 范围，文字不作隐含繁简、异体、标点或空白修正；正文、脂批、编辑文字、另一录文及附录分别保存。批语按见证标识断开，关联正文只表示临近上下文。章回 JSON 由 segments 派生。没有应用文字校订。

非空未分类片段为0；完整候选覆盖全部20条汇校本 Source 的原始范围。未知见证162条，未取得唯一跨载体匹配的片段7497条，均如实保留；后者包含未参与对齐的编辑文字、附录和空白。并非7497条正文一定有异文。pilot 对应未知见证18条、未唯一对齐854条。

构建 manifest 固定主／比较输入、R0.4 盘点、配方、代码、Source记录摘要和逐文件产物摘要。`two-independent-builds.json` 记录两个全新进程的离线逐字节重建；两份 dataset 的所有规范产物完全一致。构建环境沿用已登记 CPython 3.12.13／PyMuPDF 1.27.2.3。

`closure_roots.json` 由当前 project owner 显式选择，Source selector 固定 ALL_LOADED，并沿类型化文件／资产引用和 derived_from 验证所选材料。URL和旧接收路径只供出处审计，不作内容回退。代码、schema、配置及正式产物均要求纳入 Git；CI 对确切三条 Source 缺口施加仅能缩小的豁免基线，而严格闭包继续失败。

旧五份 Markdown 索引的88条表格项均记录原件范围；1条有确切引文命中，87条主题或概括项目保持未解析。命中不确认研究解释。pilot 到完整候选的原件范围映射另存文件，段号不承担跨版本同一性。

已固定第89回研究范例与写作包，绑定 corpus／segment、理由、Source、核心资产、六份世界输入及选定规划；任一绑定变化会失效。生产准入另要求来源闭包、真实语料层次审查和 P9。当前返回 FAIL，四项 blocker 是语料审查待评、写作 Source 未定位、声明闭包未完成及 P9 待评。
