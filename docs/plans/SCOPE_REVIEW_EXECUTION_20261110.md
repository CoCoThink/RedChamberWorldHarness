## 3. 独立审读的实际执行条件

本轮启动子代理须取得用户明确授权。未授权期间只准备任务和主 agent 草案，所有独立任务仍为 NOT_STARTED。若授权，按 contract-01～03、contract-04～06、projection/context-01 三批运行，每批最多3名原生子代理，不调用外部 API。子代理不继承主 agent 讨论、不读取协调者草案、不改仓库、不创建分支，也不再派生子代理。

每项完整读取原 manifest 指定文件及本轮短协议；以 UTF-8 字节核对外部指令不超过16384预留、原始意见不超过8192预留，总量不超过131072。不能把字节预算写成实测 token 容量。真实身份、启动返回、原始意见、读集声明和失败记录分开保存。503/启动故障最多重试3次，新尝试另存；没有返回或阅读不全记 NOT_CHECKED，不能登记 PASS。

意见须引用原片段及 typed JSON 路径，说明共享值如何同时填入 task 与 plan；分别回答未来知识不能回灌、请求不等于执行、世界存在不等于知情的问题。局部任务不得宣称读过完整作者请求。读集摘要及读者声明不是 provider 实际消费证明；原生 AI 审读不冒充独立人类意见。

执行中补充：第一批原始意见超过8192字节，逐字保留并记为失败。允许同一读者仅压缩自己的意见后重交，记为 FORMAT_REPAIR，不新增独立读者或阅读完成票数；修复启动消息与前次原始输出一并计入后续上下文，总字节上限仍为131072。初次输出预留超支事实不被修复抹去。COMPLETE仅表示已分配文件的阅读声明，分配外未读限制原样保留，不要求读者删去真实限制来通过校验。平台系统指令、工具封装和实际 token 上下文仍未实测。
