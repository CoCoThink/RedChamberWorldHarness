# 第86回实体范围与共享视图审读准备

基线 c43790ec71a08169a7987afc7214de7bb862063b。先核对已冻结的共享请求，再进行范围诊断；不改原两个投影、请求、合同、正文或历史。实现独立只读模块及工具，诊断结果不写入正文依赖，不增加全局绑定。

1. 分开报告传输完整性与语义范围。调用既有请求核验，展开实际payload后核对完整task。已注册参与人、状态目标、物件及事实ID与所选投影逐项交叉检查，输出JSON路径。遗漏明确ID为FAIL；本来UNKNOWN、缺局部时点、知情入口或未注册角色仍为PENDING，不填充状态。
2. 六个AGENT_SCENE_CONTRACT与单个可执行场景ID不是同一命名空间。只有明确相同ID才可报告同名场景存在，不能根据章节、顺序或文本推断映射。即使同名，也不因此宣称状态时点、对象转换或事件已证实。每个合同保留entry_checkpoint、knowledge_binding、未决事项、所有UNKNOWN及participants_status。全回入口值不能覆盖种子局部UNKNOWN。
3. 范围审查还须阅读全文：章节卡中的人物等自由文本保持原文交付，不按名字猜实体ID。李纨/王夫人的世界记录不等于具备知情入口；独立legacy药碗和网络药碗不能合并；共有事实目录不等于人物已知。范围读者必须决定哪些角色/物件需要登记、哪些只作为不具状态保证的叙事角色，以及每个局部状态边界。
4. 分段读包包含全部六份合同、完整章节卡、当前投影及共享指令/绑定索引；每份文件有摘要及UTF-8字节上限，合同不删字段。默认单件上限65536字节，超限拒绝，不只标exceeds_budget。审读角色分为合同范围逐件阅读、投影时点审查、共享引用理解挑战；每项任务声明依赖哪些完整文件，合并计量加指令和输出预留。某项任务超限则拒绝生成而非默许派发。读包不放入完整1.48MB准备包。
5. 共享引用挑战以实际作者payload为读取对象；提供从agent_contracts到共享值和同值plan路径的可核验导航，以及必须回答的未知/知情/时序问题。只读诊断生成问题和结构证据，不生成“读者已理解”的答案或伪造独立意见。原生子代理尚未获本轮明确授权，不自动启动；当前主agent的观察按内部意见保存，不获得独立资格。
6. 验证反例：漏参与人/物件/事实/状态目标必须FAIL；未来获知不能填入口；世界存在但无知情入口应PENDING；未决文本和UNKNOWN完整保留；自由文本角色不自动造ID；读包超过实际字节限额零发布。保存真实第86回结果，默认旧请求和payload摘要不变。必要测试、完整回归、资产/谱系检查后提交推送并核对准确提交CI。

验收：范围缺口可复现且不被传输PASS掩盖；完整分段读集与实际字节预算可检查；独立范围判断及实际理解仍PENDING时不得转入批量写作。
