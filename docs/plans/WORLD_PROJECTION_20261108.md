# World局部依赖试点：设计与执行计划

基线873c768；既有20回、v1/v2请求和发布材料均不重绑。先实现版本化WORLD_PROJECTION材料协议v1，复用现有v2内容快照及请求封装；不改变默认renderer和历史解释。此为研究骨架章回试点，不声称完整world/objects/knowledge局部化。

消费盘点：LiteraryInputs先校验包world整文件；PromptRenderer把这些文件全部放入task；可执行SceneStateAdapter另外加载所有人物/物件。因此新材料须同时有当前语义复算和仅包含投影的实际提示词。试点只允许无可执行scene的包，遇scene拒绝，不以删除摘要掩盖全局消费。

投影规则固定版本并绑定算法文件摘要；选择章回、ENTRY=前一回末、显式人物集合。保存人物定义、基线选中人物、相关效果及事件元数据、计算后的入口状态，保留UNKNOWN原值。每次复算扫描完整事件集合，新增相关事件亦导致失配；未来事件不消费。chapter presence/body/resource只选当前章；知识规则按人物及其组且不晚于当前章选择。关系、制度、地点、全局基线、来源及长线先保守全量，明确仍可能导致多个请求失配，不能称所有world字段均已局部化。新字段/未知effect根/重号事件失败关闭。

历史材料保存选中事实及原字段，不声称保存全部原始world。另存创建时载体摘要审计回执，回执不进入作者提示词或当前相容性依据。投影文件是不可变内容寻址JSON，创建时写入查询及实际值；当前包校验先验证投影自身绑定，再按冻结规则重查，差异报STALE。原文件字节变化但投影语义相同则当前仍有效。投影规则升级也使当前失配。新材料不得与原始world全文件混用。

执行：1设计先落盘；2投影生产/复核API及包、renderer接入；3真实87包另版试点，只生成请求不冒充新正文；4临时副本执行无关人物/治理变动、相关状态、相关新事件、未来事件、删除实体、规则变化及未知字段变动矩阵；5验证原请求快照历史仍可读取、相关变化阻断新导入与当前发布；6运行必要测试和真实包检查，提交可评审成果。后续对象/知识场景局部化和更细关系范围另版，不把本试点当生产、文学、人工或P9准入。
