# 评估与采用契约 v1

状态：沿用既有评估和人工门禁；新统一评审工作流待实施。

## 四类评估

| 类别 | 内容 | 权限 |
|---|---|---|
| 来源与证据 | 原件、摘要、定位、支持范围、OPEN | 阻止违反证据边界 |
| 世界与连续性 | 时间、知识、物件、资源、关系 | 阻止当前版本内部冲突 |
| 文学诊断 | 声音、行动、节奏、叙述、文化功能 | 提供分项修订意见 |
| 独立阅读 | 可读性、人物、章回与整体效果 | 为采用裁决提供依据 |

报告绑定准确的输入版本、上下文摘要与评审协议。硬拒绝不得由文学高分抵消；文学意见不汇总成自动决定所有取舍的总分。

## 盲评

导出匿名受限材料包。评审者不接触路线、模型、作者、检索 lineage 和映射键；有完整仓库访问权时仅改名不能保证盲性。解盲后固定映射和原始意见。

## 采用

Adoption 明确采用范围、对象版本、裁决依据和未决项。场景采用不等于全书发布；模型评价或实验 PASS 不自动构成采用。

输入正文变化后，旧评审不能为新版本提供未重新确认的授权。正文语义与结构化状态的复杂一致性需要编辑核对。

## 效果验证

同材料、相近预算下比较新旧流程和直接写作基线。保留实际输入输出、独立阅读意见和分歧，验证错误减少、修订有效与成文质量改善。阶段通过数和词语命中减少不单独证明文学进步。

## 实际诊断与阅读问题

文学反模式包括自我解释、教科书话语、文化配额、情绪同调和过度整齐的象征。现有评估器对自我解释提供 WARN；具体禁止项、诊断阈值和硬阻断以实际 profile、规则数据与代码为准，不通过未加载的 YAML 自报 FAIL。

盲评应检查：去掉证据标签后场景是否仍值得读；隐藏人物姓名后声音能否区分；删除文化细节后人物或戏剧是否变薄；应保留的未决处是否仍成立。回答形成阅读意见，不能伪装成自动门禁。

机器评估分别输出各层实际结果；目前各命令尚未统一为一个 PASS/WARN/FAIL 协议，统一报告属于后续实施工作。

## 已实现的文学筛查接口

文学 suite 的文化删除试验区分附着行动、物质用途、人物摩擦和对白的细节，与陈列式文化词语；`FLAG_MUSEUM_RISK` 交给人工判断。结构诊断输出段句数量、长度变异、重复开头等观察，`FLAG_STRUCTURE_RISK` 不自动淘汰候选。

suite 对高置信度的作者解说或强行封闭未决问题返回 `FAIL_EXPLICIT_EXPOSITION`、`FAIL_AMBIGUITY_CLOSURE`，可阻止候选进入盲读。守卫包括《十独吟》作者／形制、情榜正式榜名／人数、未来是否必读《续庄子》等未决接口；普通连接语不自动构成违规。此 suite 与基础评估器的 WARN、人工充分性评审分别报告。

现有诗文接口比较 A/B/C 三案，检查证据标签污染、显性解说、套语、重复句和长度观察。`READY_FOR_BLIND_READ` 只表示可以提交阅读，`automatic_winner` 与 `automatic_literary_pass` 始终为 false。诗文 screen 是内部机器视图；blind 输出隐藏内部路线标签。

正式章回盲评包从候选原字节生成，先核对 competition 中登记的内容摘要。默认命令输出包含匿名 token、正文、SHA 和阅读问题的 JSON；指定输出目录时写入匿名 Markdown 与 `packet.json`，只包含包内相对文件名，不输出候选路径、映射、来源、证据标签、门禁结果或裁决资格。输出目录必须尚不存在，避免混入已有身份材料；正文发生变化时拒绝沿用旧身份导出。

匿名导出仅生成评审输入。原始阅读意见、人工 P-Lock 与裁决分别保存；解盲映射从受控实验或竞争记录中的身份绑定生成，不维护独立副本。只有受限材料交付和实际独立阅读才支持盲性声明。

微稿评审绑定实验记录 ID 与快照摘要。快照覆盖完整结构化记录和每份正文的原字节 SHA256；结构化记录按键排序后计算摘要，不受 JSON 排版或换行变化影响。修订实验同时绑定该微稿快照和原评审记录摘要，通过校验后才按基线 token 解析场景、probe、cell 和基线路径。输入漂移会阻断使用；此实现覆盖 P6—P8，统一评审失效机制仍待扩展。

P7 的原始逐稿 verdict 与工程感判断、cell 排序、说明和修订目标是评审记录；rank、top2 及方案统计为投影。解盲后的 cell 只从绑定的微稿快照解析。统计分类显式声明，保留 `EDGE(偏弱)` 等原始措辞；未分类 verdict、重复或缺失排名、跨 cell 错绑均拒绝生成有效结果。

2026-10-08 的结构清理在逐项核对原稿、映射、排序、评语和统计等价后，迁移了 P6—P8 的记录摘要。迁移前后摘要和核对结果见清理执行报告 round 5。该次变更不产生新的评审授权；今后语义或正文变化仍须建立新版本并重新评审。

2026-10-08 的第八轮清理移除了机器输入的顶层手填 PASS，未变更原稿、微稿实验控制、人工评审判断、排序或修订目标。由于 P6 快照覆盖完整记录，该格式调整同步迁移了 P7/P8 的输入绑定。执行报告 round 8 记录原文件摘要、逐字段逆向恢复信息及旧／新绑定；迁移不产生新的评审、采用或发布授权。未来正文、身份、实验控制或评审内容变化仍触发输入漂移阻断。
