# Controlled Microdraft Lab v0.12 — P6

Status: **PASS_CANDIDATE / SHADOW_ONLY**

P6 is the first upgrade stage that contains newly written prose. It deliberately stops far short of full-chapter generation.

P6 takes all twenty P5 discourse cards and writes exactly one controlled microdraft for each card. The twenty drafts are arranged into five blind cells W1–W5, each containing four anonymous variants, one from each surviving route.

A microdraft may realize its P5 discourse card in syntax, gesture, dialogue, pacing and local image. It may not add a new fabula event, resolve withheld information, close OPEN, announce its route identity, alter Evidence/World authority, become canonical prose, affect the Chapter 89 competition, or eliminate a route by machine score.

Before human review each draft must remain inside the controlled length range, hit three declared life/object anchors, avoid route-specific closure terms and Harness metadata, pass the v0.5 literary-suite hard blockers, and stay bound to the P5 primary focalizer.

Machine PASS means only **ready for blind microdraft review**.

Reviewers should read only `artifacts/p6_microdraft/blind/REVIEWER_INSTRUCTIONS.md` and the anonymous W1–W5 token files. They must not open `artifacts/p6_microdraft/MAPPING.json` or `data/microdraft/v012.json` before review. Anyone who generated these drafts or saw the mapping is not an independent reviewer.

P6 has no automatic literary PASS, no automatic winner, and no route-elimination authority.

Next gate after PASS: **P7_BLIND_MICRODRAFT_REVIEW**.
