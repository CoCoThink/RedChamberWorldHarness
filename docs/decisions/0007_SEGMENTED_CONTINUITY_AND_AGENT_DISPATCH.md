# ADR 0007：连续性分段审读与主 agent 派发

状态：已实现；修订 ADR 0006 的整书阅读和执行入口。

## 问题

571,468 字节的当前整书读本不能只标记 `exceeds_budget: true` 就交给两位读者。模型上下文还要容纳指令、推理和意见；全文被截断后不能称为整书审读。原 runner 要求仓库未提供的本地适配器；恢复扫描只覆盖 runner 留下的 assignment/stdout，不能代替主 agent 的正式领取和登记协议。

## 连续性按接缝覆盖

prepare 对当前发布使用的精确正文按 UTF-8 字节贪心分段，默认每段最多 197 KiB，相邻段重叠一整回。每个接缝的两回必须同处一段；若最小的两回都放不下，准备或计划失败，要求重新设计阅读预算，不能截断正文冒称读完。

当前生成四段：81–87、87–92、92–97、97–100；每段两位独立声明的读者，共八位。BOOK packet 每个 subject 绑定段落原字节及有序章回，campaign 的 continuity 明列接缝。prepare、计划加载和发布评估分别检查段内完整字节、重叠、章回顺序、全部接缝覆盖及每段两份分派。超预算或伪报体量的任务拒绝运行。

197 KiB 是文件字节预算，不是实测 token 数或上下文保证。每位读者若仍读不全，必须返回 NOT_CHECKED 并交代未读部分；不能拿读取文件、意见 JSON 合法或任务 COMPLETE 代替实际阅读。段内还应查时间、物件、称谓、人物知识及伏笔；分段不能证明任意距离的所有呼应都经过逐对比较。

manifest 在 `advisories.book_continuity` 逐段展示阅读覆盖和意见。全部段均有有效审读才算覆盖完整；负面意见保留，固定 ADVISORY，不增加门控。旧单本 packet 仍可验证历史，但超预算单本 campaign 不再允许派发。

## 当前 agent 环境是执行入口

`review-dispatch PLAN` 在本地写锁下领取最多五项任务（允许通过 `--limit` 降至环境实际槽位），输出不可变 assignment。每份含准确的 scaffold、身份、当前阅读清单及指令。主 agent 使用环境提供的子代理工具启动独立读者，原样保存实际返回意见，以 `review-register PLAN JOB --opinion FILE --origin TEXT` 串行登记。仓库不自行启动 API、寻找密钥、花费新增预算或把空 scaffold 转成意见。

已领取任务显示 ASSIGNED，并占用并发槽位；再次派发或进程恢复不会重派。runner 与已领取任务不能同时启动。原子代理丢失或超时时，先停原任务，再以 `review-fail --interrupted` 记实。

也支持主 agent 直接使用既有 `agent-panel register`。`review-status` 只在意见身份、packet、subject 集与 assignment 一致，且原始字节、登记 record 和 receipt 全部有效时计入该任务。读状态不会生成意见或修改证据；无关意见、缺回执、空骨架、漏读声明都不能伪装为审阅通过。恢复后不重复登记已完成任务。

`review-fail` 保留实际故障；仅 429/500/502/503/504 或明确中断允许自动进入下次领取，默认最多三次，退避 5、10 秒。达到重试时刻才派发；每次新会话，旧 assignment、错误和意见原件保留。永久错误终止该任务。主 agent 负责使用环境工具启动及回收任务，CLI 不假装拥有子代理运行时。

## 迁移与验证

正文、作者链、章回/来源/语料 packet 保留。新分段 packet、读本索引和 campaign 使用 v2 路径；当前 request 改指向新 BOOK subjects，旧 request 不可变快照与旧计划仍保留。因为审读依据已变，旧计划拒绝继续派发，不能把旧的整书两项任务计为新八项任务。

回归覆盖全部 19 处接缝、重叠错误、正文失配、超预算拒绝、主 agent 领取/登记、直接 panel 登记纳入进度、无关身份不计、回执损坏拒绝、并发占位、中断恢复及临时失败退避。真实二十回评估和克隆 build smoke 继续由 CI 验证。本次只验证 harness，不启动正式审阅或生成正式意见。
