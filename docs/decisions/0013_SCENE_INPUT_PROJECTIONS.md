2026-11-08，接受为研究试点。实施与验证顺序见[事前计划](../plans/SCENE_PROJECTION_20261108.md)。

保留WORLD_PROJECTION v1及原请求字节解释，另加SCENE_INPUT_PROJECTION v1，内嵌world投影和明确场景查询。物件按关系闭包选择，保存独立网络与legacy登记状态；知识按场景及明确检查点选择事件前缀和全部引用事实。当前校验重新查询完整载体，新增相关事件、桥接、边或场景也必须被发现。载体观察摘要仅入创建回执；算法及消费者规则摘要进入材料。
