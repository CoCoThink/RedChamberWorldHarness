# ADR 0010 — 跨回审读上下文属于显式输入

状态：已实现。研究轨，不授予人工资格。

92-S6要求核查93中的实际出门、归家及迁句，但原分派只附92候选。一位实际读者因缺93材料提交NOT_CHECKED。合同已读完不等于跨回义务已核证；原意见不可改为PASS。

选择行及发布请求的章回行可声明 `review_context_chapters`，例如 `{"contract-92-6": [93]}`。prepare按当前选择将93候选的精确字节绑定加入该subject的context。评价时重新按当前请求求预期context，拒绝漏附、旧候选或未声明额外上下文；被引用章回的作者、编辑和保管者也不能充当相关章回同行。声明错误、非选中章回及同回自引用拒绝。

campaign按整项subject与其全部context的去重字节并集拆分预算，不拆合同，也不只计合同自身。单项连上下文仍过大则拒绝派发。来源、语料和BOOK原有预算规则不变。

本次另建r4请求与campaign，仅改92的审阅上下文，无正文、作者、写作输入或world改动。保留r3请求、分派、失败和NOT_CHECKED记录。其余19回及相同分段读本仍可按实际完整输入复用；92补读须绑定新输入、通过输入CI后另派。不能用额外材料口头补读而省掉依赖记录，也不将此次实现称为world事件投影。
