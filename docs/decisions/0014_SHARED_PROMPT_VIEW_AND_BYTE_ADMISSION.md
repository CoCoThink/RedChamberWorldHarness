# ADR 0014：显式共享视图与有单位的预算

2026-11-08，接受为研究试点，详见[事前计划](../plans/PROMPT_VIEW_BUDGET_20261108.md)。

完整task仍是冻结、反馈及语义依据；新增独立PROMPT_SHARED_VIEW v1只改变显式选择的新会话请求的传输表示。完全相同的JSON容器以共享值及不重叠位置表表示，展开必须与原task精确相等。历史校验使用已保存视图，不以今天压缩器覆盖旧请求；当前准备重新计算。另绑定共享说明模板，模型阅读能力和文学资格另审。

预算以UTF-8字节明示：请求＋外部指令预留＋输出预留不超过声明上限；真实候选导入受输出字节预留约束。token容量和session实际开销未实测，不能把字节准入写成模型上下文保证。限额内嵌于显式请求，不依赖全局治理文件；旧默认请求不改。新协议暂只用于会话DRY_RUN/导入，不给provider执行路径添加隐式开关。

准备包另存完整task，只能作为保管材料。派发使用独立导出的实际request；其回执核对准备包身份和计量报告，正文导入强制绑定该回执及payload，两者进入历史快照。回执保留consumption_proof=false，不把导出动作记成作者实际读取证明。

修订任务选择与共享视图编码是两层独立协议。显式 `revise-v3` 选择完整基础约束、直接父稿全文、当前选定反馈和notes；不把前轮修订包装中的旧全文、旧notes和旧feedback逐轮嵌套。`history_selection`声明剥离层数及未纳入/未复评边界，旧记录保留在绑定父稿谱系中；当前及历史校验均按这个规则重建任务。只剥离已知四字段wrapper或带已知history_selection的wrapper，未知附加字段必须拒绝。旧v1/v2不改变。此选择不把历史负面结论升级为PASS，不声称消费未提供的历史记录；新反馈仍可能增长，超限拒绝规则不变。
