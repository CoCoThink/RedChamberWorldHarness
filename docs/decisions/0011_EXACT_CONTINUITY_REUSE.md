# ADR 0011：正文未变时复用实际整书审阅

状态：实现。2026-10-28。

问题：单回合同另版未改正文，prepare仍为新edition生成版本目录下的整书packet与分段文件。旧BOOK意见绑定旧packet，新campaign因此重新要求八位读者。版本目录变动不应被误认成正文或审读任务变动。

决策：显式指定`--reuse-request`时，prepare核对旧、新分段BOOK输入。只有以下条件全部满足，才把新请求中的`book_review`指回旧packet：

- subject选择、全部分段ID与回次范围相同；不迁移旧单文件整书格式。
- packet除显示用ID、subject列表外的全部元数据相同，包含协调者、研究用途与权限边界。
- 对应subject除正文文件binding外全部字段相同，包含ADVISORY政策、context、samples等任何审读要求。
- 所有新旧绑定都通过原摘要核验；对应正文完整字节相同。只容许同字节正文所在路径不同。

保留的是原packet、原材料及真实登记意见，不复制意见到新packet，不改作者、读者、结论、原始notes或读取声明。campaign仍按原有规则核对真实记录及两位读者覆盖。新请求的reading索引和prepare返回值使用实际保留的packet；组装读本再次逐段核对，确保与当前选择一致。

任一分段正文、范围、上下文或协调者变化，整组不复用；坏摘要直接报错，不降为“可复用”。没有前版意见时，复用同一输入也不意味着任务完成。按同一原则，CHAPTER意见不能因整书复用而跨越合同或写作包变化。

验证：包含路径迁移成功，以及修改末段正文、范围、context、协调者、subject选择和破坏旧材料摘要的反例。真实v6-r2数据的82项任务中，80项沿用真实意见，仅第87回新版合同所属的两项待审；其19处接缝仍各有两份原始逐缝说明。新正文不发生，不能据此称文学比较胜出或授予人工/P9准入。

限制：这是整组相同的BOOK输入复用。局部改正文后逐段保留意见、world语义投影，以及任意治理改动后的自动相容性，均未由本决策实现。
