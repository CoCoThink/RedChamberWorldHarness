# ADR 0015: 局部编辑模型与偏序检查点

状态：研究实现；不授予production或stable。

第86回范围审读发现，六个种子不能共用旧“最后一夜”的入口与终态。来源卡的六段、七箭头项、五压力段也不是一条可靠事件钟。直接把整回死亡、药温或知情终态复制到各种子，会提前死亡、提前知情或把“再温”当成已经加热。

新增 `LOCAL_EDITORIAL_SCENARIO`，通过现有写作包的world字段显式选择，六份 `LOCAL_SCENE_CONTRACT` 由plan字段选择。现有session准备入口和CLI识别该kind后调用独立局部渲染器；原renderer v1/v2和既有scene/world projection算法、原字节及规则摘要不改。普通 `PromptRenderer.draft` 不是此协议的调用入口，使用 `prepare_request` 或 `rcwh write draft`。局部模型只支持session dry-run/import；production入口明确拒绝。

局部actor/object登记区分已有身份与新局部身份。新ID限定在 `local:ch86:` 命名空间；已有身份仅选择id/name，鲜度校验只比较这些字段，观察全局载体不形成其整文件prompt依赖。不会继承baseline、世界整回终态、legacy知识场或未选伏线。网络药碗和legacy药碗维持两个节点；稿夹包含稿页，G01是诗文接口，永不注册成器物。

事件采用有向无环图。每个检查点先回放祖先及自身；不对兄弟支线人为排序。同一状态目标若有互不排序的写入则拒绝模型。某写入与当前检查点未确定先后时，显示 `UNKNOWN_AT_UNORDERED_CUT` 并列出相关事件，不把“尚未在祖先中回放”误认为“同时刻尚未发生”。显式未排序的协调约束也禁止被悄悄线性化。

知情更新只能由本地观察或消息送达产生。消息记录发送者、接收者、内容、发送节点和送达节点，发送时须已知所传事实；送达必须因果晚于发送，并有相同内容的接收者更新。宝玉的死时知识限定到场问药之后。请求节点不允许写状态。G01空字、紫鹃未翻稿、药碗未尽和legacy未知是恒定约束。药温降为冷另建节点，不以对话请求推导加热。

模型的每一检查点均标为 `EDITORIAL_MODEL_ONLY_NOT_OBSERVED` / `NOT_OBSERVED`，表示可执行的计划运算。原30条声明、25项UNKNOWN、52条未决逐项保存，局部编辑值另列，不构成它们的Evidence Truth解决。具体日期、路线、房间、旧场挂接、医者真正到场和身体行动能力仍未知。热水、衣物等叙事道具与劳务角色保留用途；若需要受检消息、持有、移动或跨段状态，必须先升格局部登记。

请求保留完整章节卡、全部原必写/禁写描述及精确引用。检查点用ENTRY基值加逐键覆盖的无损视图，仍能重建每一个值和未定项。实际request的UTF-8字节与外部指令、输出预留共同受门控，超限拒绝、不截断，token容量未实测。原始范围审读、协调文件与全局载体仅进入准备回执的审计链，不把它们重新整文件绑进作者请求。

通用正文反馈把这六项作为研究骨架并返回PENDING，不调用旧事实状态适配器来“证明”新模型已写成。下一步需单回真实试写、逐项引用正文核查偏序/知识/器物义务，再作独立文学审读；模型回放PASS不提供正文语义PASS。
