# ADR 0012：显式研究world投影材料

接受为试点，2026-11-08。详细设计见../plans/WORLD_PROJECTION_20261108.md。

问题并非只有输入摘要：包先核验整world文件，renderer消费整文，可执行场景还展开全部状态。因此不能仅忽略摘要。采用独立WORLD_PROJECTION v1材料协议，复用既有v2请求/快照封装，默认renderer仍为2；原包、请求、正文和研究版不迁移。新包显式以一份内容寻址投影替换原world列表。

投影保留查询（章回、前一回末入口、显式人物）、算法摘要、选中人物定义/基线/效果、相关事件元数据、实际入口值及当前章生理/出场/资源行。知识按已知人物/组过滤。每次准备和当前相容性核验重新查询，发现新增相关事件和知识，而不是仅核验旧ID列表。未知值原样保留，不授予world语义回放或历史真伪资格。

关系、制度、地点、来源、全局状态和长线先保守完整消费；这些变化仍可能使全部试点失配。未支持字段/效果根、重号实体/事件和歧义时序拒绝。事件只消费到当前章，入口只执行到前章末，不能提前把本章计划效果当入口事实。角色覆盖核对活动合同明确participants；骨架null仍未知，不能据此宣称全部人物登记完毕。

原world载体摘要放独立创建回执，不放入提示词或当前依赖；投影本身保存选中原字段与规则，进入通常内容快照。当前包校验同时要求不可变投影字节有效及新查询结果完全相同。相关变化使当前STALE、新导入拒绝；历史快照仍能读。无关人物及未来事件变动不改变已选提示词。算法文件任何变化均保守要求新投影，不静默更新旧材料。

可执行SceneStateAdapter暂未局部化，因此发现可执行scene时拒绝试点，旧全局路径不动；混合原world与投影、v1 renderer、错章与遗漏明确参与者亦拒绝。下一版才处理object/knowledge完整场景入口、更细关系和地点范围、场内checkpoint与范围完整性审阅。此试点不能作为20回全迁移、人工、P9或stable准入。

当前试点为ch87-world-projection-pilot-v3.json，材料协议仍v1。v1/v2包是开发中算法变化之前的真实创建快照，保留为历史，当前已失配，未用于起草。没有新增正文或重绑旧正文。
