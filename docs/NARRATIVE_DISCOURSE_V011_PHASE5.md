# Narrative Discourse Runtime v0.11 — P5

Status: **PASS / SHADOW_ONLY**

P5 introduces an explicit **Fabula / Sjuzet split** for the four scenarios that survived P3 and passed P4 literary-stress design.

The problem is no longer merely "what happens?" but:

> Who sees it, from what distance, in what order, through which carrier, with what information withheld, and where does the scene stop?

## What P5 compiles

P5 does not duplicate or rewrite P4 fabula content. For every one of the twenty P4 scene probes it creates a discourse card with two separate parts:

- **fabula_passthrough** — exact ordinary actions, side characters, objects, cultural actions, withheld information, event visibility and ending vector inherited from P4;
- **sjuzet_plan** — focalizer, temporal mediation, event presence, relay channels, narrative distance, reveal policy, narrator access, exit channel and explicit restraint rules.

Any mutation of the P4 fabula is a blocker.

## Eight discourse dimensions

The runtime protects:

1. focalization;
2. temporal mediation;
3. knowledge aperture;
4. narrative distance;
5. relay channel;
6. scene breath;
7. indirection;
8. narrator restraint.

These are downstream literary-planning constraints, not Evidence.

## Visibility is not prose

P5 treats P4 event visibility as a discourse instruction:

- AFTERMATH_FIRST → effects before cause;
- PARTIAL_DIRECT → show only the fragment that constrains characters;
- REPORTED → relay the event instead of replaying it;
- INTERRUPTED_DIRECT → permit direct scene but break thematic closure;
- DIRECT_SCENE → embody action without authorial summary;
- OFFSTAGE → expose only traces/reports.

Every card keeps narrator access at **LIMITED**.

## Four route-specific safeguards

### current-C
Direct Zhen/Jia contact and same-jade return are prevented from becoming a philosophical真假 dialogue or a narrator-declared object identity.

### late marriage
Baochai may not leak into "wife POV" before the E2 marriage window. The wedding must enter through resource actions rather than ritual catalogue or poverty spectacle.

### multi-layer jade
Objects are disambiguated through custody, space, package and relay chain. Narrator labels such as "this jade is not that jade" are prohibited.

### minimal-cause-open
The concrete procedure is visible; only the evidentially open cause remains open. "The reason cannot be told" is explicitly rejected as fake ambiguity.

## Hard P5 boundaries

P5 has no authority to:

- alter Evidence or OPEN;
- change P4 fabula;
- generate prose;
- grant literary PASS;
- rank the four scenarios;
- select a winner;
- modify stable ACTIVE;
- touch Chapter 89 blind/adjudication state.

A P5 PASS means only that the four routes can be expressed through controlled, auditable discourse plans rather than plot-outline narration.
