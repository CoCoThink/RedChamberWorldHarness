# Five provenance canaries

The v0.2-alpha schema is accepted only if it cleanly separates evidence, inference, openness, and implementation in five difficult cases.

## 1. 悬崖撒手

The early comment directly supports a future “悬崖撒手” interface and semantically supports Baoyu ultimately abandoning Baochai/Sheyue and becoming a monk.

It does **not** establish:

- formal original chapter title;
- Chapter 99 placement;
- required exact wording in novel prose.

Current placement in Chapter 99 is `CURRENT`, not `LOCKED`.

## 2. 甄宝玉送玉

The comment directly supports the future event “甄宝玉送玉.”

It does **not** establish:

- that the object must be the identical Tongling jade;
- that the two Baoyus must meet face-to-face;
- Chapter 98 placement;
- formal chapter title.

The current Chapter 98 model is a reversible reconstruction implementation.

## 3. 凤姐扫雪拾玉

The comment directly points to a future “凤姐扫雪拾玉” scene.

It does **not** establish:

- formal chapter title;
- that the found jade is certainly the Tongling jade;
- Chapter 91 placement.

The active prose’s “玉样物” is an implementation strategy for preserving the open object identity.

## 4. 十独吟

The comment directly supports:

- the work title 《十独吟》;
- occurrence after Chapter 64;
- an explicit comparison with 《五美吟》.

It does not uniquely establish:

- author;
- poetic form;
- complete count/text structure;
- subjects;
- Chapter 85 placement.

## 5. 情榜

The comments directly support:

- revelation in the final chapter;
- five layers: 正、副、再副、三副、四副;
- Baoyu rating “情不情”;
- Daiyu rating “情情”;
- source wording containing “警幻情榜”.

They do not establish that “警幻情榜” is necessarily the formal novel-internal total title, nor do they establish twelve names in every layer, sixty total names, or recoverable complete lower rosters.

## Acceptance questions

Every canary must answer:

1. Where is the source?
2. What is the source text?
3. What atomic claim does it support?
4. Is support direct, semantic, contextual, analogical, or secondary?
5. What remains OPEN?
6. What is the current Decision?
7. How is it currently implemented?

If RCWH cannot answer all seven by traversing IDs, the provenance kernel is not ready for bulk R4 import.
