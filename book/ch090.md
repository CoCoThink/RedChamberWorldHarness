# 第九十回　薛宝钗借词含讽谏　王熙凤知命强英雄

话说贾府诸人迁出旧宅，在那借住的小院里挤过两夜，才略略分出个头绪来。两三间屋塞进几房人，谁睡里间，谁的箱子靠墙，谁的药不能近灶，连一只水桶放在井边碍不碍人，都要现商量。惜春出府第二日便求了王夫人，说城边一座尼庵的师父从前常来走动，她愿去那里暂住，省得这里挤。王夫人拗不过，只得依了。临去前，她抱着一卷东西到贾母跟前，打开来，却是那年老太太叫她画的园子：楼台亭馆都起了稿，颜色只上了一半，老太太说要添的人，一个也没有画上。惜春把画重新卷好，放在贾母手边，道：“画不完了。”贾母看了半日，道：“你带着，闲了再画。”惜春道：“不带了。”说着磕了头起来，便跟两个婆子去了。贾母叫鸳鸯收起，半日没有言语。

这日清早，麝月从炕角拖出昨夜拆开的衣包，抖出那件青布夹衣来，道：“昨儿说要补，趁天亮先弄了。再搁两日，只怕袖口自己先走了。”衣裳原是宝玉往年家常穿的，料子不值什么，却厚实，袖口磨得发白，一处针脚也松了。宝钗接过去翻看，道：“外头缝两针，里头再衬一小块。只缝外头，过两日还开。”麝月便去箱底翻那片灰布。

宝玉从院里提水回来，桶只提了半桶，见她二人摊着自己的旧衣，笑道：“这样旧了，还费这个工夫。”麝月头也不抬：“二爷前日还问厚衣在那里，今日倒嫌旧了。”又看那桶，“井边又叫人挤回来了？”宝玉道：“那个穿褐衣的老婆子说咱们桶大，一桶顶她们一桶半，我便只打了半桶。”宝钗道：“你倒会让。明儿她再说，你就提两回。”宝玉一笑。

正说着，小丫头来回：“从前园里看角门的周妈妈来了，说想见二爷奶奶。”宝钗道：“叫她院里说罢，屋子小。”一时那周婆子进来，身上只一件薄棉袄，头上包着旧青帕，搓着手，先说了几句“主子们也受苦”的话，自己觉着不合，便住了嘴，到底又道：“原不该来开这个口。我那儿媳妇上个月才添了孩子，这两日又病着。出来得急，她一件厚衣也没带齐。若有主子们不要的破夹袄，给一件便是恩典；实在没有，也不敢强求。”

麝月先看宝钗。宝玉却先道：“有。这件正好。”说着便来拿宝钗手里的夹衣。

宝钗的手还按在袖口上，道：“这件是给你冬里替换的。”宝玉道：“我还有衣裳。”麝月道：“带出来的就这么几件，厚的那件还锁在旧府里，取不取得出来还不知道。”宝玉道：“我少一件也冻不着。她家有病人，又有孩子。”周婆子忙摆手：“若是二爷要穿的，我再问别处去。”宝玉道：“问什么别处。”

宝钗只把袖口翻过来给他看，道：“这一件给出去，冬里便真少这一件了。”宝玉看看袖口，又看看周婆子，道：“少便少罢。”宝钗便松了手，递给麝月：“先补上。人家拿回去就能穿，别叫病人还替我们缝袖子。”

麝月接了，一面穿针一面道：“奶奶说了半日，二爷还是这一句。”嘴里这样说，针脚却走得又密又匀，衬布衬好，又把下摆一处松线也收了。周婆子在旁看着，越发不好意思，只说：“这可怎么敢当。”宝钗叫小丫头取一小卷剩棉线来，道：“这个也带去。她若嫌肩宽，自己收一收。不是新东西，留在这里一时也用不上。”周婆子又要推，宝钗道：“衣裳都拿了，一卷线倒客气起来。”婆子这才接了。

周婆子抱了衣裳要走，到门口又回来问：“这件原是谁的？我媳妇若问，我好告诉她。”宝玉道：“谁的都一样。”周婆子笑着，千恩万谢地去了。院门一关，麝月回身道：“好了，今冬又少一件。”宝玉道：“不是还有一件厚的在旧府里？”宝钗道：“那件在旧府，今日拿不到。”

那件夹衣前夜挂在门后，并不起眼，如今钉子空着，反叫人一眼看见。麝月顺手拿起另一件想挂上去，嫌薄，仍折回包里。

却说凤姐住的是靠东一间小屋。屋本不大，偏因她病着，床前还要摆药炉、痰盒、热水壶，平儿又在墙边塞了一只从旧府带出的窄箱，越显逼仄。窗纸破了一角，昨夜拿旧纸糊住，风大时仍扑扑作响。凤姐半靠在床上，背后垫着那只嫌矮的靠枕。门外站着三四个婆子媳妇，有回住处的，有回米的，有回铺盖的，都怕落在别人后头，你一句我一句，隔着帘子也听得见。凤姐道：“外头吵什么？一个也不许进来，都站着等。”外头才静了。

贾琏倒先进来了，鞋边全是泥。他问凤姐今日怎样，凤姐道：“还没死，先说你的。”贾琏道：“又胡说。我正为钱来。外头还有三处要跑，车脚昨日欠下一半，两个旧管事又说各有难处，不能再白跑。手上那点现银，我先留一半应外头；里头的，你酌量着办，别等我。”凤姐问：“老太太的药钱？”“留了。”“太太呢？”“也留了。”“车脚？”“先给一半。”凤姐点头，叫平儿把各房报的冬物名目给他。贾琏接过去扫了扫，上头贾母靠褥、王夫人脚炉、宝玉一件厚夹袍，都是前日记下的，便折了揣进怀里，道：“我带出去。只是别报得太多，报多了，人家又说咱们什么都要往外搬。”

说完这些，他却不走，望望平儿，又望凤姐，压低了声音道：“还有一件。旺儿今早叫人传去了，说是问旧账。放出去的那些，还有……那年铁槛寺张家的事，也有人提了。”他顿了一顿，脸上又慌又不明白，“人家说那封信上落的是我的名字。我几时写过这个？”

屋里一时没有声音。药炉上的水滚了，壶盖轻轻跳。凤姐把眼睛从他脸上移开，看着那只药炉，手在被面上掐住一道褶，方道：“你自然没写过。”

贾琏道：“那是——”

凤姐道：“谁问你，你只说不知道，叫他来问我。”

贾琏道：“白纸黑字写着我，谁听你一个病人的？”

凤姐道：“你只照我的话说。”

贾琏又站了一站，像还要问什么，到底没有问。平儿悄悄的道：“要不要叫人去旧府那边——”凤姐道：“叫人做什么？前日我才说的，原来什么样就什么样。谁也不许去动旧账。”

贾琏道：“外头那几个旧相与，从前见了我叫二爷，如今见了先问我吃了没有，倒客气得很。我晚上未必回来吃饭。”凤姐道：“谁等你。你在外头吃得着，倒替家里省一碗。”贾琏笑不出来，摇摇头去了。

门帘才落下，布帘那一边便有人说话。原来邢夫人早起听见旺儿被传，一上午没出声，这会子当着进来送水的婆子，陪着笑道：“论理我不该说。大老爷那边原不过是一把扇子的事，几时又添出放利、人命来了？如今一家子挤在这里，倒不知是谁连累了谁。”那婆子不敢接，提着壶出去了。平儿脸上变了色，回头看凤姐。凤姐靠在枕上，眼也没睁，半日方道：“叫她们都进来。”平儿道：“奶奶先歇一歇——”“叫进来。”几个婆子媳妇进了门，才要开口，凤姐已说起来了：

“你们要回什么，我都知道，一个一个回到晌午也回不完，我替你们说罢。后院那两间，一间住着吴家婆媳三口，一间昨儿又添了浆洗上的李大娘，带着闺女和一个吃奶的外孙，都是旧府里放出来没处去、跟着来的。地下铺不下：带孩子的李家留东边，省得半夜抱着孩子挪；吴家那两个年轻媳妇搬到西屋堆箱子那间去，她们婆婆留下。门鼻子坏了先拿绳拴；窗，问各房要不能穿的旧衣裳糊，能穿的一件也不许拆。铺盖三床只到了两床，一床给带孩子的，一床给吴家婆婆，西屋那两个把旧褥子并一并，今夜先睡。米从明早起按人头下，晚上把人数点一遍；二爷外头使的那两个跑腿的，只算晌午这一顿。病人另留软饭，孩子要粥，从软饭里匀，谁来要，先报是哪个孩子——不然明儿全院都病了。柴不是从前一车一车往里送的，谁也不许另起小灶。还有什么？没有就去。”

一屋子人竟没一个插得进嘴，听到“全院都病了”，有个媳妇没忍住，笑了一声，忙又低下头。末了一个婆子才嗫嚅道：“吴家说老人腿不好，怕风——”凤姐道：“所以叫两个年轻的挪过去，老的留下。你只会整家整家地搬，就不会拆开想？”那婆子不敢再说。平儿道：“奶奶这会子连病也要查名了。”凤姐瞪她一眼，众人便都答应着出去了。

人一散，凤姐那口气像也跟着散了，往后一靠，半日没睁眼。平儿替她把手从被外放进去，见那只手比往日瘦了许多，腕上原戴镯子的地方空空的，只剩一道浅印。凤姐觉察她在看，道：“看什么？”平儿道：“看你手凉不凉。”凤姐道：“方才还发热，这会子又问凉。”平儿道：“方才一屋子人，你说得比谁都响，我还当你好了。”凤姐闭着眼道：“响是响，气可接不上了。”平儿道：“既知道，就省着点。”

门外又有人轻轻叫“平姑娘”。原来管灶的媳妇拿着一只裂了沿的米升，说明日量米怕不准。平儿出去悄悄的吩咐：“去大奶奶那边借那只木升，别进来了。”凤姐在里头已问：“还有事么？”平儿进来道：“有也没有。今儿到此为止。”凤姐闭着眼道：“你倒敢替人截状子。”平儿道：“今儿我就截一回。”说着把药端过来。凤姐瞅着药碗道：“又是这个。”到底皱着眉一口口喝了。

平儿服侍她躺下。才要走，凤姐又道：“先问宝玉他们那边。他们早上不是理旧衣？”平儿笑道：“你连这个也知道。”凤姐道：“院子就这么大，谁家抖一件衣裳我听不见。”平儿便往各房去问旧布。

到了宝玉屋里，宝玉正坐在窗边看书。平儿一进门，先看见门后那只空钉，问：“这里原不是挂一件青衣么？”麝月道：“二爷早起送人了。”平儿“哦”了一声，只说来意：“西屋的窗要糊，二奶奶叫各房拣不能穿的旧衣旧裙，拆一块下来。她说只要不能穿的，不许拆好衣。”又笑道：“我看你们这里东西一日比一日少。”

宝钗打开衣包翻了几件，挑出一条磨破的旧裙幅，平儿比了比，道：“还差一截。”麝月从柜角找出一个旧包袱，那布颜色褪得看不出原样，只中间还结实。她拿剪子比着，忽又停下：“剪了可惜。袭人姐姐从前总拿它包二爷换季的衣裳。”宝玉道：“既要糊窗，就糊罢。”麝月道：“你今日倒什么都肯舍。”宝玉道：“一块布又不是人。”话出口，他自己先怔了，眼睛不由往门后那只空钉上去，又收回来。宝钗只伸手把包袱布摊平，替麝月按住一角，道：“从破的这一边剪，好的那半还可包东西。”

平儿拿了布到西屋，那两个才挪来的年轻媳妇正为谁睡靠窗那边争执，一个说自己怕风，一个说夜里要起来照看婆婆，睡外边方便。平儿听了半日，道：“你们若再争，今晚都睡窗底下，大家公平。”两人都不说了。平儿叫人把破窗纸揭去，将旧裙幅和包袱布拼着钉上。偏一个小丫头钉歪了，上边紧下边松，风一吹鼓起一个大包。一个婆子在旁道：“这倒像挂了个肚子。”那小丫头臊得道：“妈妈来钉！”婆子道：“我眼花，钉得还不如你。”平儿也忍不住笑，叫人把下边重新扯紧。

下午风又大起来。宝玉看书看到一半，忽觉肩上凉，才想起早上那件夹衣已不在了，缩了缩肩。宝钗在旁理针线，只把自己搭在炕边的一件厚披风递过去：“先披这个。你若嫌是女衣，明日就老实在屋里坐着。”宝玉道：“这又不是女衣。”接来披上，仍看书，看了几行，忽道：“早上那周妈妈的儿媳妇，不知穿得合不合。”宝钗道：“衣裳既送出去了，就由人家自己过日子。你还要跟过去看不成？”宝玉道：“我不过白问一句。”宝钗只把那道衣边缝完。

晚饭是一锅稀粥，一碟腌菜，还有中午剩的半碗豆腐。宝钗盛粥，先盛给宝玉，碗里比别人的稠些。宝玉见了，拿勺子拨了一半回锅里，道：“我下午没动，吃不了这许多。”宝钗也不拦，只把那半碗豆腐推到他跟前。麝月看看这个，看看那个，只喝自己的粥。

饭后麝月在灯下补宝玉另一件夹袍，缝了半日，又把针脚翻过来看，忽然“嘶”了一声，原来针尖扎了手。宝玉忙问扎深了没有。麝月把手指在嘴里含了含，道：“不深。”宝玉把披风拢紧些，看她一针一针走着。宝钗在旁收拾碗筷。

到了夜里，北风比前两日更紧，院里那只水桶叫风刮倒了，咕咚一声，滚了半圈才停。门缝下透进一线冷气，贴着地直扫到脚背上。麝月从自己一条旧裙上撕下一截边，卷一卷塞住了，嘴里道：“好的那块叫平姐姐拿去糊窗，咱们只好用这个。”宝玉披着宝钗的披风坐在灯下，道：“这也挡得住。”

宝钗把米瓮抱到灯下，一捧一捧量到小盆里，数明日早饭的米，并不抬头。她量得慢，每一捧都拿手掌抹平了才倒，嘴里不出声，只一根指头在瓮沿上轻轻的点着。宝玉看她点到第七下停住了，又从头点起。量完了，又一捧一捧倒回去，才道：“只够两日。”麝月道：“平姐姐说米未必在准取的名目里。”宝钗道：“我知道。”

屋里便没人说话。麝月仍缝那件夹袍，线从布里抽出来，沙的一声，又一声。宝钗把瓮盖盖上，又压了一块碎砖，手在砖上按了一回才拿开。宝玉一直看着她的手，问道：“若又有人真没有呢？”

宝钗没有就答。她把米瓮往墙角推稳了，回身坐下，拿起针线匣子，开了又合上，抬眼看着麝月。麝月低着头，只当没听见，针却慢了。宝钗把匣子放在膝上，道：“我几时说过不该给？那媳妇才坐了月子，一件夹衣搁在咱们这里是件衣裳，到她身上就是一冬。只是你也看看门缝里那截布，是从谁的裙子上撕下来的。从前你说一声给人，回头柜里自然又有一件；如今给出去一件，眼前便真少一件。”说到这里，她顿了一顿，声气又平下来，“明儿那件厚袍若准取，样子你自己说给麝月听，别又叫人替你记。”

麝月在旁原低着头缝衣，听到说她撕裙子，手上便住了，脸上倒红了，嘟囔道：“奶奶说我做什么，一截破边，又不值什么。”话出口，她把针在头发上抿了抿，仍缝下去。

灯芯哔地一响，又暗下去。宝钗拔下簪子把灯芯挑了一挑，屋里重又亮了。宝玉低头看见身上披着她的衣裳，又看门缝里那截布，布边上还带着一道旧镶线，原是麝月那条裙子的。他伸手过去，把麝月膝上那件夹袍拉过一角来看：针脚一行一行，密得几乎看不出线，补丁四边都折了进去，摸着是平的。他看了许久，问：“方才扎的是这只手？”麝月道：“早好了。”他把那一角仍放回她膝上，抹平了。

又过了一回，他才道：“你说的，我都知道。只是早上若再来一回，我想……还是会给她。”

宝钗半日方道：“我原知道。”说完便去收桌上的针线，线团绕紧，针一根根插回针包，一样一样放进匣里，再没有劝。收了一回，又过来把那件披风滑下的一角替他拢上，道：“这件你先披着，夜里别脱。”宝玉“嗯”了一声。

宝玉便照她的话说那件厚袍：“青灰面，黑边，里头——”说到一半，自己也记不清了。麝月在旁道：“得了，还是我说罢。青灰面，袖里补过一块，右襟下有一点墨，那是你前年写字自己蹭的。”宝玉道：“你怎么什么都记得？”麝月道：“总得有人记。”她把那根空钉指给他看，“等那件拿回来，我头一件事就挂在这里，谁也不许碰。”宝玉道：“连我也不许？”麝月道：“尤其你。”说着自己先笑了，笑完又把门缝那截布塞紧了些。

麝月打着呵欠去外间铺褥子。宝钗把灯拨暗了，自己仍坐在灯边，把麝月没缝完的那半道边接过来，借那一点亮慢慢的缝。宝玉躺在炕里头，看她的影子映在墙上，一低，又一低。看了一回，他翻过身去，把披风的领子拉到下巴底下。

院外忽有人拍门，说旧府那边打发人传话：二爷带去的名目，那边嫌开得不清，仍不许自行取物，叫各房连夜再核一遍，明早一并送去。平儿披衣出来，从门里接过一张纸，北风一卷，纸角掀起来，她忙用手压住，才要应声，东屋里凤姐已隔着窗问出来了：“什么事？叫他进来，我问——”
